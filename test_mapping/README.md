# test_mapping

Runner file/sheet mapping test assets for B2B 0.5.19.

## Files
- actual_sales_2026_06.xlsx: actual input 1. Sheet is ActualSales.
- actual_adjustments_2026_06.xlsx: actual input 2. Sheet is ActualAdjust.
- actual_codes_2026_06.xlsx: actual input 3. Sheet is ActualCodes.
- actual_output_template_2026_06.xlsx: actual output template. Sheet is ActualResult.
- mapping_test_saved_skill.zip: saved skill ZIP, stored without compression for app compatibility.

## Saved skill intentionally references old names
- expected_sales.xlsx / SalesData
- expected_adjustments.xlsx / AdjustData
- expected_codes.xlsx / CodeMap
- expected_output.xlsx / ResultSheet

## Test
1. In Runner, load the three actual input files.
2. Load actual_output_template_2026_06.xlsx as output template.
3. Load mapping_test_saved_skill.zip as skill.
4. Click File Check.
5. Map:
   - expected_sales.xlsx / SalesData -> actual_sales_2026_06.xlsx / ActualSales
   - expected_adjustments.xlsx / AdjustData -> actual_adjustments_2026_06.xlsx / ActualAdjust
   - expected_codes.xlsx / CodeMap -> actual_codes_2026_06.xlsx / ActualCodes
   - expected_output.xlsx / ResultSheet -> actual_output_template_2026_06.xlsx / ActualResult
6. Click Run.
7. Expected result:
   - ActualResult rows 2:5 are filled with sales, adjustment, final amount, category.
   - Validation_Result sheet is created.

Validation_Result is generated by the skill, so it should not appear as a required source mapping target.
