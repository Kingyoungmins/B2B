코드를 몰라도 따라가는 안내서

파일을 올리고, 원하는 엑셀 작업을 말로 만든 뒤, 스킬로 저장합니다.

이 가이드는 실제 프로그램 화면의 버튼 이름과 위치를 기준으로 작성했습니다. 코드를 몰라도 파일 업로드, 스킬 생성, 복붙 캡처, 전체 실행까지 따라갈 수 있습니다.

가장 많이 쓰는 흐름
1입력 파일과 출력 템플릿 업로드
2오른쪽 Excel에서 범위 선택
3채팅으로 작업 요청 후 적용
4전체 실행 또는 스킬 저장

처음 사용하는 순서

작업은 한 번에 크게 만들기보다, 아래 순서대로 작은 단계로 쌓는 것이 가장 안정적입니다.

1

파일 올리기

원본 자료는 입력 파일, 결과 양식은 출력 템플릿에 올립니다.

2

범위 선택

오른쪽 Excel 화면에서 셀, 열, 행, 범위를 선택해 정확한 위치를 잡습니다.

3

채팅 요청

“무엇을 기준으로, 어디에, 어떤 값으로” 작업할지 한 단계씩 적습니다.

4

적용 / 저장

결과를 확인한 뒤 전체 실행, 스킬 저장, 파일 다운로드를 진행합니다.

버튼 레퍼런스

주요 버튼

화면 지도 번호와 같은 번호를 사용합니다.

6
초기화

현재 작업 상태를 정리하고 새 작업을 시작할 준비를 합니다.

9
전체 파일 다운로드결과

작업이 끝난 입력 파일과 출력 템플릿을 내려받습니다. 시스템 저장 창에서 저장 위치와 파일명을 직접 정할 수 있고, 완료되면 화면에 다운로드 완료 안내가 표시됩니다.

10
스킬 저장

현재 파이프라인을 zip으로 저장합니다. 다시 불러와 반복 작업에 사용할 수 있습니다.

11
스킬 불러오기

저장해 둔 스킬 zip을 불러옵니다. 파일을 올린 뒤 전체 실행으로 재사용합니다.

12
자동저장 폴더

스킬 적용 시 자동 백업 스킬이 저장될 폴더를 지정합니다. 지정하지 않으면 실행 위치의 auto_backup 폴더를 사용합니다.

14
복붙 캡처

오른쪽 Excel에서 직접 수행한 복사/붙여넣기를 스킬 단계로 기록합니다. 값만 체크와 함께 쓸 수 있습니다.

자동 저장

자동으로 저장되는 것

자동 백업 스킬

스킬을 적용하면 입력 파일명, 일시, 단계 번호를 기준으로 백업 스킬이 만들어집니다.

저장 위치

자동저장 폴더를 지정하면 그 폴더에 저장됩니다. 지정하지 않으면 실행 위치의 auto_backup 폴더를 사용합니다.

스킬 저장과 차이

스킬 저장은 사용자가 명시적으로 저장하는 파일이고, 자동 백업은 복구와 재현을 위한 안전장치입니다.

요청 예시

이렇게 요청하면 정확합니다

파일명, 시트명, 범위, 조건, 결과 위치를 같이 적을수록 정확합니다. 오른쪽 Excel에서 범위를 선택하면 요청창에 선택 범위가 자동으로 들어갑니다.

값 계산

선택 범위: @범위[청구내역.xlsx/청구내역!E2:E200] E열 값을 1000000으로 나눈 값을 @범위[청구내역.xlsx/청구내역!D2:D200]에 입력해줘

필터 후 새 시트

@시트[원본.xlsx/원본] E열 상품명이 "안전제일"인 행만 필터해서 새 시트 "안전제일_추출"에 넣어줘

매칭 합산

출력 파일 P열의 가입번호를 기준으로 입력 파일 BP열과 매칭하고, 입력 파일 BQ열 금액 합계를 출력 H열에 넣어줘

보존 조건

가입번호, EID, 전화번호처럼 긴 숫자는 텍스트로 유지하고 원본 값을 잃지 않게 처리해줘
한 번에 너무 많은 조건을 넣지 마세요

정렬, 필터, 매칭, 서식 변경을 한 번에 요청하기보다 단계별로 나눠 적용하면 검수와 복구가 쉬워집니다.

실행기

스킬 실행기

저장된 스킬을 불러오고, 입력 파일과 출력 템플릿을 연결한 뒤 한 번에 실행하는 화면입니다.

스킬 실행기 실제 화면 하단 버튼까지 전체 표시

스킬 불러오기

저장된 zip 스킬을 불러옵니다. 스킬과 파일을 연결한 뒤 실행합니다.

결과 편집하기

전체 실행 후 최종 파일을 생성기에서 열어, 결과를 확인하며 추가 수정할 수 있습니다.

실행 후 편집

전체 실행 후 결과 편집하기를 누르면 생성기로 이동해 최종 파일을 보면서 추가 수정할 수 있습니다. 실행기에서 내려받기 전 마지막 확인이나 간단한 수정에 사용합니다.
