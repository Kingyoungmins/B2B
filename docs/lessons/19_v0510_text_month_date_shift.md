정리 기준일: 2026-06-23

> **갱신(2026-06-23): VBA 헬퍼 → 백엔드 ctx.shift_months 로 이전.** 실사용에서 모델(Qwen)이 VBA 헬퍼를
> 베끼며 **정규식과 시트/파일명에 공백을 끼워**(예: `(\d{2,4}) 년`, `Worksheets("2026 년")`) 매번 깨뜨려
> "월 정보를 가진 셀이 없습니다"/시트 못 찾음으로 실패했다. 프롬프트로는 못 막아서, 월/날짜 증감 로직을
> **백엔드 결정적 헬퍼 `ctx.shift_months(시트, 범위, delta)`** 로 옮기고 `monthShiftIntent` 로 **Python 라우팅**한다.
> 시트/워크북 해석도 공백 무시 정규화 매칭(`_ws`/`ctx.book` + 게이트 `exactReferenceFailures`)으로 보강.
> 검증: `test_runs/_test_month_shift.py`(실제 `serve_b2b._shift_months_in_text`) 10/10. 아래 VBA 헬퍼 설명은
> explicit-VBA 폴백/역사 기록이다.

## 증상

"26년 06월 (05월 1일 ~ 05월 31일) 요금확정 내역" 셀에서 "월 정보를 +1 해줘" 하면
"26년 07월 (05월 1일 ~ 05월 31일) ..." 처럼 **맨 앞 06월만** 바뀌고 괄호 안 05월들은 그대로였다.
또 여러 셀을 선택해도 **첫 셀 하나만** 바뀌었다. (VBA 경로로 생성됨)

## 원인

VBA 시스템 프롬프트에 "텍스트 내 월/날짜 증감" 안내가 전혀 없어, 모델이 가장 순진한 형태
(`Replace(s, "06월", "07월")` 한 번, 첫 셀만)로 생성했다. 즉 (a) 셀 순회 없음, (b) 한 셀 안
여러 'N월' 토큰 처리 없음, (c) 12월 롤오버/연도, (d) 말일 보정 개념 자체가 프롬프트에 없었다.

## 처방 (적용)

`scripts/file-schema.js` 의 VBA_SYSTEM_PROMPT 에 "텍스트 내 '월/날짜' 증감(+N개월)" 섹션을 추가했다.
사용자 확정 사양:
- **대상 범위의 모든 셀** 순회(선택 범위 있으면 그 범위, 없으면 데이터 끝까지 한정).
- 한 셀 안의 **모든 'N월' 토큰을 +N**.
- **연도 넘김**: 12월 +1 = 다음 해 01월, 그 월 앞의 'YY년'/'YYYY년'도 +1.
- **말일 보정**: 옮긴 달에 없는 날짜는 그 달 말일로 **내림만**(06월 31일 → 06월 30일, 윤년 02월 고려).
  날짜를 늘리지는 않음(11월 30일 → 12월 30일, 31일로 만들지 않음).
- "N월말"/"N월 말일"처럼 일(日)이 숫자가 아닌 표현은 '월'만 옮기고 '말/말일'은 그대로.
- 0패딩 폭은 월·일·연도 각각 원본 보존.
- **트리거/부호**: "다음달/한 달 뒤/미뤄"=+, "지난달/당겨/앞으로"=−. 부호를 임의 추정 금지.

검증된 참조 헬퍼를 프롬프트에 그대로 박았다: `ShiftMonthsInText`(VBScript.RegExp 로 모든 토큰을
walk 하며 재구성) + `DaysInMonth`(`DateSerial(y, m+1, 0)` 로 말일·윤년 자동). VBScript.RegExp 는
순수 메모리 객체라 VBA 금지 목록에 안 걸린다.

## 검증

자동화 단위테스트는 없다(생성물은 LLM 출력이라 결정적이지 않음). 대신:
- **알고리즘을 VBA 충실 미러(파이썬)로 실행 검증** — 신고 예시 + 12월 롤오버+연도 + 윤년/비윤년 말일보정 +
  비패딩 단독월 + delta=+2 까지 7/7 일치.
- **수동 회귀 자료**: `test_data/시나리오_v0510_월정보_증감.md` + `test_data/v0510_월정보_증감.xlsx`
  (입력→기대 표, 회귀 포인트: 셀 안 모든 월·셀 전부·연도·말일).
- 프롬프트 렌더 확인: 정규식 `\d` 가 JS 템플릿 리터럴에서 깨지지 않게 소스에 `\\d` 로 작성.

## 회귀 방지 기준

"월/날짜를 +1 했는데 일부만 바뀐다" 신고가 다시 오면:
1. 첫 셀/첫 토큰만 바뀌는가 → 프롬프트 섹션이 사라졌거나 모델이 헬퍼를 안 베낀 경우.
2. 12월/말일/윤년 처리 → `ShiftMonthsInText`/`DaysInMonth` 로직(또는 동등물)을 썼는지.
3. "다음달/당겨" 같은 자연어 → 부호 매핑(트리거/부호 규칙)을 따랐는지.
