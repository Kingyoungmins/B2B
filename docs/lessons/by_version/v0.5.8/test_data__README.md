# B2B 테스트 데이터

`make_test_files.py` 가 생성하는 3개의 xlsx 로 기존 ver2.0 의 9가지 기능과 ver0.4.13 의 20개 회귀 케이스를 함께 테스트합니다.

## 파일

| 파일 | 시트 | 용도 |
|---|---|---|
| `input_매출_2026_4월.xlsx` | `매출` (1200행), `고객정보` (20행), `월별집계` (표 3개) | 입력 #1 |
| `input_원가_2026_4월.xlsx` | `원가` (120행) | 입력 #2 - `회사명` 컬럼이 매출 파일과 겹침 |
| `output_청구서_템플릿.xlsx` | `회사별요약` (수식 포함), `월별실적`, `a`, `회귀_원본데이터`, `회귀_수식복사`, `회귀_수식복사_대상`, `회귀_병합복붙`, `회귀_삽입삭제`, `회귀_중복계수`, `회귀_청구항목` | 출력 템플릿 + ver0.4.13 회귀 데이터 |

## 재생성

```bash
cd test_data
python make_test_files.py
```

## ver0.4.13 회귀 테스트 데이터

시연 전 `input_매출_2026_4월.xlsx`, `input_원가_2026_4월.xlsx`, `output_청구서_템플릿.xlsx` 3개 파일을 모두 업로드합니다.
기본 작업 파일은 `output_청구서_템플릿.xlsx`이며, 일반 예시 프롬프트에서 쓰는 `a시트`도 실제 시트로 들어 있습니다.

| 시트 | 용도 |
|---|---|
| `a` | 사용자가 예시로 말하는 `a시트`. C/T/X/G/H/J열 등 20개 회귀 테스트 공통 원본 |
| `회귀_원본데이터` | `a`와 같은 구조의 설명용 원본 데이터 |
| `회귀_수식복사` | 수식 셀 값만 복사, 수식 포함 복사, 수식 문자열화 방지 |
| `회귀_수식복사_대상` | I:K 수식/서식 복사 대상 |
| `회귀_병합복붙` | 병합 셀, 서식, 수식이 포함된 복사/붙여넣기 |
| `회귀_삽입삭제` | J열 앞 열 삽입, 행 삽입, 셀/행/열 삭제 |
| `회귀_중복계수` | H열 금액 중복 개수를 G열에 계산 후 중복 제거 |
| `회귀_청구항목` | `기본료`, `전국대표 포함한 기본료`, `080포함한 기본료`만 합산하는 정확 매칭 테스트 |

### 20개 회귀 시나리오

1. 스킬 미적용인데 `적용됨`으로 표시되는지 확인

```text
a시트에서 C열 값이 123인 행들을 새 시트에 가져와. 시트명은 b라고 해. a시트는 원본데이터니까 건들지 마.
```

확인: `b` 시트가 생성되고 C열 값이 123인 행만 있어야 합니다. `a` 시트는 그대로 남아야 합니다.

2. 열 문자 지정이 헤더 오인식보다 우선되는지 확인

```text
a시트에서 T열 기준으로 오름차순 정렬해줘.
```

확인: T열 `효력발생인자` 기준으로 정렬되어야 하며 X열 `당월매출` 기준이면 실패입니다.

3. 정정 프롬프트가 이전 오해를 버리는지 확인

```text
T열은 효력발생인자야. 너는 X열 당월매출을 보고 작업했어. 기존 스킬은 잊고 T열 효력발생인자 기준으로 다시 정렬해.
```

확인: 수정 후에도 X열을 다시 기준으로 쓰면 실패입니다.

4. 행 단위 정렬인지 확인

```text
a시트에서 청구항목이 기본료, 전국대표 포함한 기본료, 080포함한 기본료인 행을 먼저 나오게 정렬해. 다른 열의 데이터는 같은 행끼리 같이 움직여야 해.
```

확인: `정렬검증ID`와 회사명/금액/청구항목이 서로 섞이지 않아야 합니다.

5. 동일 프롬프트에 LLM 답변이 중복 생성되는지 확인

```text
회귀_원본데이터 시트의 상태별 행 개수를 요약해줘.
```

확인: 같은 답변이나 같은 스킬 카드가 2번 생기지 않아야 합니다.

6. 사용자가 `값`이라고 명시한 수식 셀 복사

```text
회귀_수식복사 시트의 A1:A5 값을 F1:F5에 적어줘. 수식 말고 보이는 값만 복사해.
```

확인: F1:F5에는 계산 결과 값만 들어가야 하며 `=B1+C1` 같은 수식이 들어가면 실패입니다.

7. 별도 명시가 없을 때 수식/서식 포함 복사

```text
회귀_수식복사 시트의 I:K 수식 표를 회귀_수식복사_대상 시트의 I:K에 복사해.
```

확인: J/K열 수식과 표 서식이 유지되어야 합니다.

8. 이전 단계의 삭제 상태가 이후 복붙에서 원복되는지 확인

```text
a시트의 A:B열을 삭제해. 다음 단계에서 현재 작업 상태의 a시트 전체를 새 시트 a_현재상태복사에 복사해.
```

확인: `a_현재상태복사`에도 A:B 삭제 상태가 유지되어야 합니다.

9. 이전 단계 결과 열이 다음 단계에서 전부 지워지는지 확인

```text
회귀_중복계수 시트에서 H열 금액이 같은 값의 개수를 G열에 구해줘. 그 다음 G열에서 중복값을 제거해줘.
```

확인: G열 전체가 빈칸이 되면 실패입니다. 중복 제거 대상만 처리되어야 합니다.

10. think mode 중단 버튼 확인

```text
생각을 길게 해서 회귀_원본데이터의 모든 열 의미를 분석하고 작업 계획만 말해줘.
```

확인: 생각 중에는 `생각 중단`, 요청 실행 중에는 `요청 중단`이 분리되어야 합니다.

11. J열 앞 열 삽입

```text
회귀_삽입삭제 시트에서 J열 앞에 새 열을 하나 삽입하고 헤더는 새삽입열로 해줘.
```

확인: 한 셀만 밀리면 실패입니다. 전체 열이 삽입되어야 합니다.

12. 유사 항목 과포함 방지

```text
회귀_청구항목 시트에서 기본료, 전국대표 포함한 기본료, 080포함한 기본료만 합산해줘.
```

확인: 결과는 37,000이어야 합니다. `월구전화 기본료`, `기본료 할인`, `데이터 기본료`가 포함되면 실패입니다.

13. 같은 파일/스킬 재적용 오류 메시지 확인

```text
방금 만든 스킬을 같은 파일에 다시 적용해보고, 적용되지 않으면 왜 안 됐는지 사람이 알아들을 수 있게 설명해줘.
```

확인: 실패 시 내부 예외만 보여주지 말고 어떤 파일/시트/범위가 문제인지 설명해야 합니다.

14. 시트/셀 데이터 삭제 명령

```text
회귀_삽입삭제 시트의 C4:C6 값을 삭제해. 서식은 유지해.
```

확인: 값만 지워지고 서식/다른 열은 유지되어야 합니다.

15. 행 삽입 명령

```text
회귀_삽입삭제 시트의 6행 앞에 새 행을 하나 삽입해.
```

확인: 한 셀 삽입이 아니라 전체 행 삽입이어야 합니다.

16. 실제 값은 바뀌었는데 실패로 저장되는지 확인

```text
회귀_삽입삭제 시트의 A4 값을 완료검증으로 바꿔.
```

확인: A4가 바뀌었으면 파이프라인도 성공이어야 합니다.

17. 수식이 텍스트로 적히는지 확인

```text
회귀_중복계수 시트의 G4:G15에 H열 금액별 개수를 COUNTIF 수식으로 넣어줘.
```

확인: 셀에 `'=`로 시작하는 텍스트가 아니라 실제 수식으로 들어가야 합니다.

18. 적용 버튼 무반응 확인

```text
회귀_삽입삭제 시트의 B4 값을 적용버튼검증으로 바꿔.
```

확인: 적용 버튼이 눌리지 않는 경우 조용히 무시하지 말고 진행/차단 상태를 표시해야 합니다.

19. 엑셀 작업 중 즉시 중단

```text
회귀_원본데이터 시트 전체에 대해 아주 느린 검증 루프를 돌리는 테스트 코드를 만들어줘.
```

확인: 적용 중 `요청 중단`으로 멈출 수 있어야 하고, 중단 후 오류 상태가 남지 않아야 합니다.

20. 처리 중 채팅 스크롤

```text
회귀_원본데이터 시트의 모든 행을 자세히 설명한 뒤 마지막에 작업 계획을 만들어줘.
```

확인: 처리 중에도 채팅창 스크롤이 막히지 않아야 합니다.

### 복사/붙여넣기 전용 시나리오

```text
회귀_병합복붙 시트의 A1:F7 범위를 H1:M7에 복사해서 붙여넣어. 병합 셀, 서식, 수식을 유지해.
```

확인: H1:M7 쪽에도 병합 구조와 수식/서식이 유지되어야 합니다.

```text
회귀_수식복사 시트의 I11:K15를 회귀_수식복사_대상 시트의 I11:K15에 복사해. 별도 말이 없으니 수식과 서식을 유지해.
```

확인: 수식이 값으로 풀리지 않아야 합니다.

## 대화형 시연 시나리오

이 시나리오는 기능을 하나씩 설명하기보다, 시연자가 실제로 `output_청구서_템플릿.xlsx`를 완성해 가는 흐름입니다.
시연 전 `input_매출_2026_4월.xlsx`, `input_원가_2026_4월.xlsx`, `output_청구서_템플릿.xlsx` 3개 파일을 모두 업로드합니다.

### 1. 회사 목록 채우기

우측 시뮬레이터에서 `output_청구서_템플릿.xlsx`의 `회사별요약` 시트를 선택합니다.
상단에 회사명, 매출, 원가, 마진, 마진율 컬럼이 있는 빈 청구서 템플릿임을 보여줍니다.

채팅 예시:

```text
매출 파일의 회사명 목록을 중복 없이 회사별요약 시트의 회사명 열에 채워줘.
```

확인 포인트:
- `회사별요약` 시트의 회사명 열이 채워지는지
- 기존 템플릿의 수식/서식이 깨지지 않는지

### 2. 회사별 매출 합계 채우기

우측 시뮬레이터에서 `input_매출_2026_4월.xlsx`의 `매출` 시트를 한 번 보여준 뒤, 다시 `output_청구서_템플릿.xlsx`의 `회사별요약` 시트로 돌아옵니다.

채팅 예시:

```text
매출 파일의 회사명별 매출 합계를 회사별요약 시트의 매출 열에 채워줘.
```

적용 후 확인 포인트:
- `회사별요약` 시트의 회사명별 `매출` 열이 채워지는지
- 회사명이 정확히 일치하지 않아도 유사도/정규화 기준으로 매칭되는지
- 코드 적용 후 마진/마진율 수식 열이 깨지지 않는지

### 3. 회사별 원가 합계 채우기

이제 `input_원가_2026_4월.xlsx`의 `원가` 시트를 보여줍니다. `회사명` 컬럼이 매출 파일에도 있고 원가 파일에도 있다는 점을 짧게 설명합니다.

채팅 예시:

```text
원가 파일에서 회사별 원가 합계를 찾아서 회사별요약 시트의 원가 열에 채워줘.
```

적용 후 확인 포인트:
- AI가 매출 파일이 아니라 원가 파일을 대상으로 코드를 작성하는지
- `원가` 열이 채워진 뒤 `마진 = 매출 - 원가`, `마진율` 수식 표시가 갱신되는지

### 4. 월별실적 시트 만들기

출력 템플릿의 `월별실적` 시트를 선택합니다. 이 시트는 최종 보고용 탭이라는 식으로 설명합니다.

채팅 예시:

```text
매출 파일의 월별 데이터를 기준으로 월별 매출 합계를 월별실적 시트에 정리해줘. 월, 총매출, 거래건수 순서로 보여줘.
```

적용 후 확인 포인트:
- `월별실적` 시트에 월별 요약 표가 생성되는지
- 기존 `회사별요약` 시트 내용이 유지되는지
- 한 단계씩 누적되어 output 파일이 완성되는 흐름을 보여줄 수 있는지

### 5. 최종 확인 및 다운로드

완성된 `회사별요약`, `월별실적` 시트를 차례로 보여준 뒤 다운로드합니다.

채팅 예시:

```text
지금까지 만든 결과에서 회사별요약과 월별실적 시트가 모두 채워졌는지 점검하고, 이상한 빈칸이나 음수 마진이 있는지 확인해줘.
```

마무리 확인 포인트:
- 스킬 파이프라인에 단계가 순서대로 쌓였는지
- 시뮬레이터에서 보이는 결과와 다운로드한 xlsx 결과가 일치하는지
- Excel에서 열었을 때 수식과 서식이 유지되는지

## 기능별 테스트 시나리오

### 1. 유사도 매칭 (item 1)

입력 매출/원가 파일을 모두 업로드. 채팅에 일부러 약간 다른 이름으로 요청:
- "**원가표**의 단가를 1.1배 해줘" -> `원가표` ≈ `원가` 시트로 fuzzy 매칭
- "**매출_시트**의 금액 컬럼을 천 단위로 잘라줘" -> `매출_시트` ≈ `매출` 시트로 매칭
- "**거래처명**별로 합계를 구해줘" -> `거래처명` ≈ `회사명` 컬럼

### 2. 같은 컬럼이 2개 파일에 있을 때 (item 2)

매출/원가 파일 모두 `회사명` 컬럼이 있음. 채팅에 파일 안 적고:
- "**회사명별로** 정렬해줘" -> LLM 이 "어느 파일을 의미하시나요?" 라고 되묻는지 확인

### 3. 기본 대상 = 선택된 시트 탭 (item 3)

1. 매출 파일을 우측에 띄우고 `매출` 시트 탭 클릭
2. **Ctrl+click** 으로 `고객정보` 시트도 추가 선택 (✓ 표시 떠야 함)
3. 채팅에 파일/시트 명시 없이 "이 시트들의 회사명을 비교해줘"
4. system 프롬프트에 두 시트가 "기본 대상"으로 들어가는지 확인 (LLM 응답에 그 시트들만 다뤄져야 함)

### 4. 한 파일의 여러 시트 (item 4)

매출 파일은 시트 3개 - 시트 탭 전환 시 각각 보이는지, schema 설명에 모두 노출되는지 확인.

### 5. 한 시트에 여러 표 (item 5)

`월별집계` 시트는 `상반기 집계`, `하반기 집계`, `분기별 요약` 3개 표가 빈 행으로 분리됨. 채팅에:
- "**월별집계의 표를** 정렬해줘" -> LLM 이 "표 3개 중 어느 것?" 또는 범위(A2:C8 등)를 되묻는지 확인
- 우측 입력 패널에서 `월별집계` 탭 선택 후 채팅하면 schema 에 `⚠️ 표 3개 감지됨` 라인이 들어가야 함

### 6. 가상 스크롤 (item 6)

매출 시트는 1200행. 우측 시뮬레이터 진입 -> 처음 300행만 렌더, 아래로 스크롤 시 +300씩 자동 추가. 행번호가 300, 600, 900, 1200 까지 매끄럽게 늘어나는지 확인. 행 1200 도달 후 멈춰야 함.

### 7. Ctrl+F 검색 (item 7)

시뮬레이터 보이는 상태에서 **Ctrl+F** -> 우상단 검색바 -> "ABC통신" 입력 -> ▼/▲ 로 다음/이전 매치 이동. 매치가 가상 스크롤 바깥에 있어도 자동으로 펼쳐서 보여줘야 함. **Esc** 로 닫기.

### 9. 단계 실행 오류 표시 (item 9)

일부러 깨지는 코드를 만들어 적용:

- 적용 시 토스트와 채팅창에 `❌ Step N 실행 실패 - Step N (description) 실행 중 오류 - message` + 스택이 보여야 함

### 10. 수식 실시간 평가 (item 10)

1. 출력 템플릿 업로드 -> 시뮬레이터에서 `회사별요약` 시트 봄
2. `마진` 열(D), `마진율` 열(E) 셀에 우상단 보라 모서리 (`has-formula`) 표식 + hover 시 수식 tooltip
3. 채팅으로 "회사별로 매출 합계를 B열에, 원가를 C열에 채워줘" 같은 단계 적용
4. 적용 직후 D열의 마진(=B-C), E열의 마진율(=IFERROR(D/B,0)), 마지막 행 합계 SUM/AVERAGE 가 모두 **실시간으로 계산된 값**으로 표시돼야 함 (이전엔 빈칸)
5. 다운로드한 xlsx 를 Excel 에서 열면 수식이 그대로 살아있어야 함
