# 0.5.6 버그 검증 시나리오 (0.5.4 보고 18건)

이번 빌드(`B2B_ver0.5.6`)에서 고친 0.5.4 보고 버그들을 직접 확인하는 시나리오입니다.
ver0.4.13 회귀는 기존 `README.md` 를 참고하세요. 이 문서는 0.5.4 버그 전용입니다.

## 준비

1. 앱 실행(`B2B_ver0.5.6.exe` 또는 `B2B_ver0.5.6_single.exe`).
2. 입력 파일 업로드:
   - `input_v056_청구내역.xlsx` — 시트 3개: **청구내역**(12행), **단가표**, **양식**
   - `input_v056_정산서.xlsx` — 시트 1개: **정산**(헤더만 있는 빈 양식)
3. 별도 표기가 없으면 기본 작업 대상은 `청구내역` 시트입니다.

> 데이터 메모
> - `청구내역`: 회사 / 청구일(YYYYMMDD 정수) / 상태 / **가입번호/명**(슬래시 포함 헤더) / 수량 / **단가(F열, 숨김 상태)** / 금액 / 비고
> - 11행은 3행(A통신·1003/이영희)과 **중복** — 중복 제거 테스트용
> - `단가표`: 회사별 기준단가 (VLOOKUP용)
> - `양식`: 매출/원가/마진 × 1~3월 값이 채워진 표 (지우기용)

## 그룹 A — 생성·적용 결과로 바로 확인

### #1 시트명만 변경 (rename_sheet)
- 입력: `청구내역 시트 이름을 "2026청구내역" 으로만 바꿔줘.`
- 기대: 시트 **이름만** 바뀌고 **데이터·시트 위치는 그대로**.
- 0.5.4 증상: 시트 위치가 바뀌거나 시트 내용이 삭제됨.

### #3 필터 — 빈 결과 / 매칭
- 입력(빈결과): `상태가 "프리미엄" 인 행만 새 시트 "프리미엄목록" 으로 추출해줘.`
  - 기대: "프리미엄" 행이 없으므로 **빈 시트를 만들지 않고** "조건을 만족하는 행이 없습니다" 안내. (재요청해도 다운 없음)
- 입력(매칭): `상태가 "안전제일" 인 행만 새 시트 "안전제일목록" 으로 추출해줘.`
  - 기대: 새 시트에 **헤더 + 안전제일 행(7건, 중복 행 포함)** 이 들어가고 원본 보존.
- 0.5.4 증상: 시트만 생기고 데이터 없음 → 데이터 요청 시 프로그램 다운.

### #5 열 삭제 후 전체 계산 (적용 후 캐시 동기화)
- 1단계 입력: `비고 열을 삭제해줘.` → 적용.
- 2단계 입력: `회사별 금액 합계를 새 시트 "회사별합계" 에 정리해줘.`
- 기대: 2단계가 **삭제 후 구조**(비고 없는 7열)를 기준으로 정확히 계산. "데이터 없음" 오류 없음.
- 0.5.4 증상: 삭제 전 열을 포함해 계산하거나 데이터 없다고 인식.

### #6 중복 행 제거 (루프 삭제 허용)
- 입력: `청구내역에서 회사·가입번호/명·금액이 모두 같은 중복 행을 제거해줘.`
- 기대: 11행(A통신·1003/이영희 중복)이 제거되고 11행 → 정상. **"루프 안 차단" 오류 없이** 적용.
- 0.5.4 증상: 안전 재생성 후 스킬 오류.

### #8 슬래시(/) 포함 헤더
- 입력: `"가입번호/명" 열에서 슬래시 앞의 번호만 뽑아 새 열 "가입번호" 에 넣어줘.`
- 기대: 1001, 1002 … 번호만 추출. **프로그램 다운 없음**, 헤더명을 통째로 인식.
- 0.5.4 증상: 슬래시 헤더에서 앞 값만 입력하라 하면 프로그램 다운.

### #9 같은 행 다른 열 값 채우기 (VLOOKUP류)
- 입력: `각 행의 회사에 해당하는 기준단가를 "단가표" 시트에서 찾아 "비고" 열에 적어줘.`
- 기대: A통신→2700, B텔레콤→3000, C모바일→2520 이 비고에 채워짐. **다운 없음**(루프 내 조회/셀쓰기 폭주 안 함).
- 0.5.4 증상: VLOOKUP 프롬프트로 프로그램 다운.

### #10 한글 값 필터 (normalize)
- 입력: `"안전제일" 상태인 행만 골라 새 시트 "안전제일" 로 모아줘.`
- 기대: 공백·표기 차이를 정규화해 안전제일 행(7건) 매칭, 새 시트 생성. **0건 오인 없음**.
- 0.5.4 증상: 필터 스킬 오류.

### #11 복수 열 정렬 (다중키 + 헤더 보존)
- 입력: `청구내역을 회사 오름차순, 같은 회사 안에서는 금액 내림차순으로 정렬해줘.`
- 기대: A통신(금액 큰 순) → B텔레콤 → C모바일. **헤더 행은 1행에 그대로** 남고 데이터만 정렬.
- 0.5.4 증상: 복수 열 정렬 시 스킬 오류. (이번 빌드에서 헤더가 정렬에 섞이던 잠재 버그도 수정)

### #14 양식 데이터 지우기 (clear 허용)
- 입력: `"양식" 시트의 1~3월 숫자(값)만 지워줘. 항목 이름과 서식은 그대로 둬.`
- 기대: B2:D4 값만 비워지고 항목/헤더/서식 유지. **"루프 차단" 오류 없음**.
- 0.5.4 증상: 양식 데이터 지우기 오류.

### #19 숨김 열 숨김 해제
- 준비: `단가(F열)` 가 숨김 상태입니다.
- 입력: `단가 열 숨김을 해제해줘.`
- 기대: F열이 실제로 보이게 되고, "완료" 보고와 실제 상태가 일치.
- 0.5.4 증상: 완료라고 하지만 실제로는 안 됨(또는 적용 불가). ※ 엔진 동작은 정상 확인됨 — 만약 화면에만 안 보이면 그 상황(어느 열/실제 vs 화면)을 알려주세요.

### (보너스) #12 조건부 값 변경 — 이미 해결 확인
- 입력: `청구일이 20260101 이전이고 단가가 2700인 행의 단가를 2520으로 바꿔줘.`
- 기대: 해당 행만 단가 변경. 다운 없음(루프 셀쓰기는 차단/예산으로 안전 처리).

### (보너스) #13 다른 시트로 복사 — 이미 해결 확인
- 입력: `청구내역의 A1:C5 를 새 시트 "발췌" 의 A1 에 복사해줘.`
- 기대: 값·서식 유지하며 다른 시트에 복사.

## 그룹 B — UI / 안정성 동작 확인

### #2 파일 간 복사·붙여넣기
- 준비: 두 입력 파일 모두 업로드.
- 입력: `청구내역의 회사와 금액을 정산서 파일의 "정산" 시트에 옮겨줘.`
- 기대: 정산서의 정산 시트에 값이 채워짐. (범위 단위 교차 복사는 값 기준으로 처리됨)
- 0.5.4 증상: 파일 간 복붙이 동작하지 않음.

### #4 작업 취소 후 유사 스킬 새로 적용
- 절차:
  1. `금액 기준으로 내림차순 정렬해줘.` 생성 → **적용 도중/직후 작업 취소**.
  2. 이어서 `회사 기준으로 오름차순 정렬해줘.` (유사하지만 다른 스킬) 생성 → 적용.
  3. 또는 `청구내역의 마지막 행을 삭제해줘.` 취소 후 `비고 열을 삭제해줘.` 적용.
- 기대: 2번째 스킬이 **정상 적용**. "이미 수행한 스킬" 오류 없음.
- 0.5.4 증상: 취소 후 유사·다른 스킬을 "이미 수행"으로 오인해 스킬 오류.

### #16 붙여넣기 적용 시 화면 멈춤
- 입력: `청구내역 전체를 새 시트 "백업" 에 통째로 복사해줘.` → 적용.
- 기대: 적용 중에도 **보던 파일 화면이 사라지거나 멈추지 않음**. 적용 후 정상 표시.
- 0.5.4 증상: 붙여넣기 적용 시 화면이 사라지고 멈춤.

### #17 올바른 값인데 적용 불가
- 절차: 대화로 결과를 확인한 뒤 그 스킬을 **적용** 버튼으로 반영.
  - 예: `회사별 금액 합계를 알려줘.` (대화) → 만족스러우면 같은 작업을 새 시트에 적용.
- 기대: 적용이 **정상 완료**. "스킬을 적용하지 못했습니다" 가 부당하게 뜨지 않음.
- 0.5.4 증상: 대화로 올바른 값이 나왔지만 적용 시 적용 불가.

### #18 스킬 저장 후 불러오기 재실행
- 절차:
  1. 아무 스킬(예: #11 정렬)을 만들어 **적용 완료**.
  2. 스킬 **저장**(로직 저장).
  3. **비우기/초기화** 또는 새 세션처럼 만든 뒤, 저장한 스킬 **불러오기**.
  4. 입력 파일 업로드 후 **전체 실행**.
- 기대: 불러온 스킬이 **정상 재실행/적용**.
- 0.5.4 증상: 불러오기 후 재실행 시 "스킬을 적용하지 못했습니다" 에러.

### (#15 참고) 적용 오류 후 파일 표시 — 이미 해결
- 일부러 실패하는 작업(예: `없는시트의 데이터를 정렬해줘.`)을 적용해 오류를 낸 뒤,
- 기대: 오류 후에도 업로드한 파일 내용이 계속 보이고, 채팅에 LLM 이 실패 사유를 쉬운 말로 설명.
