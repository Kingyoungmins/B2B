# 27. 시트명에 작은따옴표(')가 있으면 VBA 게이트가 시트명을 잘라 오탐 (SBAGENT-138, v0.5.13)

## 증상
`@범위[...xlsx/NHN(5분)_'26년04월_사용!Q1]` 처럼 **시트명에 작은따옴표(')** 가 든 요청에서, 모델이
올바른 VBA(`If sh.Name = "NHN(5분)_'26년04월_사용"`)를 만들어도 정적 게이트가
"VBA 시트명이 요청과 다릅니다 — 현재 감지된 시트명은 NHN(5분)_" 로 **거절**. 모델이 `Chr(39)` 로
우회해도 게이트가 리터럴을 못 찾아 또 거절 → 사용자가 강제적용/COM(Python)으로 회피.

## 근본 원인
게이트의 시트명 추출기 `vbaSheetReferenceLiterals`(chat-ui.js)가 리터럴 패턴을
`["']([^"']+)["']` 로 썼다. **'를 문자열 구분자로 보고 [^"']+ 가 ' 에서 끊겨**
`"NHN(5분)_'26년04월_사용"` 를 `NHN(5분)_` 로 오인 → 요청 시트명과 불일치 → 거절.
실제 VBA 문자열은 **큰따옴표(")뿐**이고 '는 문자열 안에서 일반 문자다(주석 '도 게이트 진입 전
_stripVbaCommentsForGate 가 문자열 밖의 것만 제거함). 즉 ' 를 구분자로 본 것 자체가 잘못.

## 수정
추출 정규식 6곳(Worksheets/Sheets("..."), .Name="...", StrComp(..,"..."), VAR="...")을
`["']([^"']+)["']` → `"([^"]+)"` 로 변경 → ' 가 시트명 안에 그대로 보존된다.
(CreateObject 안전검사(@843)의 동일 패턴은 인자에 '가 없어 무관 → 미변경.)

## 검증
- `test_runs/_test_vba_sheet_quote_gate.js`(신규): 신고 케이스(loop + sh.Name="...'..."),
  Worksheets("...'...") 직접접근이 **거절 안 됨** + 멘션 파서가 ' 보존 + **틀린 시트명은 여전히 거절**(회귀). 5/5 PASS.
- node --check OK. 라우팅 함수는 게이트를 호출하지 않아 영향 없음(슬라이스 eval에서 라우팅 코드 바이트 동일).

## 교훈
- VBA 문자열 리터럴 추출은 **큰따옴표만** 구분자로 봐야 한다(VBA 는 ' 가 문자열 구분자가 아니라 주석).
  ["'] 로 둘 다 받으면 ' 가 든 시트명(한국 빌링의 '26년04월 류)을 통째로 잘라 정적검사가 오탐한다.
- 일반화: 이 수정으로 시트명에 ' ( ) & 등 특수문자가 있어도 게이트가 전체 이름을 정확히 잡는다(특정
  케이스 패치가 아니라 추출기 자체의 강건화).
