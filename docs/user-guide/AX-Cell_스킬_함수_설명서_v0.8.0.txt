====================================================================
 AX-Cell 스킬 함수 설명서
 - 스킬 안에서 쓸 수 있는 명령(ctx) 66가지, 용도와 예시
 - 버전 0.8.0 / 2026-08-26
====================================================================

[이 문서는 무엇인가요?]

AX-Cell 이 엑셀 작업을 자동으로 해 줄 때, 뒤에서는 "스킬"이라는 작은
작업 지시서가 돌아갑니다. 그 지시서 안에서 쓸 수 있는 명령어들을
정리한 문서입니다.

이 문서를 보면 좋은 경우
  - AX-Cell 이 어떤 작업까지 할 수 있는지 미리 알고 싶을 때
  - "이런 요청을 하면 되나?" 를 판단하고 싶을 때
  - 만들어진 스킬의 코드를 열어 봤는데 무슨 뜻인지 알고 싶을 때

프로그램을 몰라도 읽을 수 있게 썼습니다. 각 명령마다
  · 무엇을 하나   · 언제 쓰나   · 쓰는 법   · 예시
순서로 적었습니다.


====================================================================
 1. 먼저 알아 둘 것 세 가지
====================================================================

1-1. 스킬 코드는 이렇게 생겼습니다

    def transform(ctx):
        ctx.write("매출", "B2", [["100"]])

  첫 줄은 항상 똑같습니다. 그 아래에 "ctx.무엇무엇(...)" 형태로
  할 일을 한 줄씩 적습니다. ctx 는 "지금 열려 있는 엑셀 파일"이라고
  생각하시면 됩니다.


1-2. 위치를 가리키는 세 가지 방법

  시트    "매출"          시트 탭에 보이는 이름 그대로
  칸(셀)  "B2"            엑셀에서 보이는 그 주소 그대로
  범위    "A1:D20"        시작칸:끝칸

  열(세로줄)을 가리킬 때는 세 가지 다 됩니다.
      "C"          열 문자
      3            왼쪽에서 세 번째
      "청구금액"    머리글(제목) 이름

  ★ 머리글 이름으로 지정하는 것을 가장 권합니다. 파일마다 열 위치가
    조금씩 달라도 알아서 찾아가기 때문입니다.


1-3. 다른 파일을 함께 다룰 때

  실행기에서 파일을 여러 개 올리면 한 화면에서 같이 다룰 수 있습니다.

      ctx.book("정산자료.xlsx").write("Sheet1", "A1", [["값"]])
                              ↑ 다른 파일을 지정

  일부 명령은 시트 이름 자리에 "파일이름!시트이름" 형태도 받습니다.

      ctx.sum_lookup("input.xlsx!Sheet1", ... )

====================================================================
 3. 가. 표 살펴보기
====================================================================

--------------------------------------------------------------------
ctx.sheets()
--------------------------------------------------------------------
 무엇을 하나 : 이 파일에 있는 시트 이름을 전부 알려 줍니다.
 언제 쓰나   : 시트 이름을 모를 때, 시트마다 같은 작업을 반복할 때.
 예시        : for s in ctx.sheets():
                   ctx.clear_filter(s)

--------------------------------------------------------------------
ctx.used_range(시트)
--------------------------------------------------------------------
 무엇을 하나 : 그 시트에서 실제로 쓰고 있는 영역의 크기를
               (행 개수, 열 개수) 로 알려 줍니다.
 언제 쓰나   : 표가 얼마나 큰지 먼저 확인할 때.
 예시        : rows, cols = ctx.used_range("데이터")

--------------------------------------------------------------------
ctx.last_row(시트, col=1)
--------------------------------------------------------------------
 무엇을 하나 : 지정한 열을 기준으로 데이터가 있는 마지막 행 번호.
 언제 쓰나   : 표 맨 아래가 몇 행인지 알아야 할 때.
 주의        : 그 열에 중간중간 빈칸이 많으면 실제보다 짧게 나올 수
               있습니다. 시트 전체 기준이 필요하면 아래 used_last_row.
 예시        : last = ctx.last_row("데이터", col=2)

--------------------------------------------------------------------
ctx.last_col(시트, row=1)
--------------------------------------------------------------------
 무엇을 하나 : 지정한 행을 기준으로 데이터가 있는 마지막 열 번호.
 예시        : n = ctx.last_col("데이터", row=1)

--------------------------------------------------------------------
ctx.used_last_row(시트)
--------------------------------------------------------------------
 무엇을 하나 : 시트 전체 기준 마지막 행 번호.
 언제 쓰나   : "시트 전체를 복사/처리" 하는 작업. 한 열만 보는
               last_row 는 그 열이 비어 있으면 표 아래쪽을 놓칩니다
               (예: A열 기준으로는 22행인데 실제 표는 28행까지).
 예시        : end = ctx.used_last_row("청구내역")

--------------------------------------------------------------------
ctx.used_last_col(시트)
--------------------------------------------------------------------
 무엇을 하나 : 시트 전체 기준 마지막 열 번호.
 언제 쓰나   : 머리글이 병합되어 있어 한 행만으로는 끝 열을 못 잡을 때.

--------------------------------------------------------------------
ctx.first_empty_col(시트, after=None, header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 완전히 비어 있는 첫 열을 찾아 열 문자("N")로 알려 줍니다.
 언제 쓰나   : "옆 빈 칸에 계산해서 넣어 줘" 같은 요청.
 왜 필요한가 : 데이터 바로 옆 칸이 이미 합계 수식으로 차 있는 경우가
               많습니다. 그걸 덮어쓰는 사고를 막아 줍니다.
 예시        : col = ctx.first_empty_col("요금", after="L")   # -> "N"
               ctx.write_cell("요금", col + "8", "행별MAX")

--------------------------------------------------------------------
ctx.find_header_row(시트, 머리글이름, max_scan=30)
--------------------------------------------------------------------
 무엇을 하나 : 그 머리글이 몇 번째 행에 있는지 찾아 줍니다.
 언제 쓰나   : 표 위쪽 안내 문구를 지워야 할 때.
 왜 중요한가 : 시스템에서 뽑은 보고서는 표 위 안내 줄 수가 달마다
               바뀝니다(실제로 9줄이 10줄이 된 적이 있습니다).
               "위에서 9줄 삭제" 처럼 고정해 두면 그 달에 표가 통째로
               어긋납니다. 항상 머리글 행을 찾아서 그 위를 지웁니다.
 예시        : hdr = ctx.find_header_row("청구내역", "가입번호")
               if hdr > 1:
                   ctx.delete_rows("청구내역", "1:" + str(hdr - 1))

--------------------------------------------------------------------
ctx.find_header(시트, 머리글이름, header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 머리글 이름으로 그게 몇 번째 열인지 찾아 줍니다.
 언제 쓰나   : 열 위치를 손으로 정하지 않고 이름으로 잡을 때. 거의 항상.
 참고        : 지정한 행에서 못 찾으면 바로 위/아래 행도 찾아봅니다
               (2줄짜리 병합 머리글 구제).
 주의        : 사용자가 "Q열" 처럼 열 문자를 직접 지정했다면 굳이
               다시 찾지 말고 그 열을 그대로 쓰는 게 가장 안전합니다.
 예시        : c = ctx.find_header("매출", "청구금액")

--------------------------------------------------------------------
ctx.read(시트, 범위)        ※ 범위를 빼면 시트 전체
--------------------------------------------------------------------
 무엇을 하나 : 범위를 표 모양(가로세로)으로 한 번에 읽어 옵니다.
 언제 쓰나   : 값을 가져와서 가공할 때. 범위를 생략하면 시트 전체.
 주의        : 아주 큰 표를 통째로 읽으면 느립니다. 조건에 맞는 값만
               더하는 거라면 ctx.sum_where 를 쓰세요.
 예시        : data = ctx.read("데이터", "A1:D100")

--------------------------------------------------------------------
ctx.read_cell(시트, 칸)
--------------------------------------------------------------------
 무엇을 하나 : 칸 하나의 값을 읽습니다. 빈 칸이면 아무것도 없음(None).
 예시        : v = ctx.read_cell("요약", "B2")

--------------------------------------------------------------------
ctx.read_formulas(시트, 범위)
--------------------------------------------------------------------
 무엇을 하나 : 계산 결과가 아니라 "수식 글자" 를 읽습니다.
               (수식이 없는 칸은 그냥 값)
 언제 쓰나   : 원래 들어 있던 수식을 확인하거나 옮길 때.

--------------------------------------------------------------------
ctx.has_formulas(시트, 범위)
--------------------------------------------------------------------
 무엇을 하나 : 그 범위에 수식이 하나라도 있으면 "있음" 이라고 알려 줍니다.

--------------------------------------------------------------------
ctx.formula_mask(시트, 범위)
--------------------------------------------------------------------
 무엇을 하나 : 칸마다 수식인지 아닌지를 표 모양으로 알려 줍니다.
 언제 쓰나   : "수식 칸은 건드리지 말고 값 칸만 처리" 할 때.
               위의 has_formulas 는 범위 전체에 대한 예/아니오라서
               칸별로 판단하려면 이걸 씁니다.


====================================================================
 4. 나. 값 쓰기·지우기
====================================================================

--------------------------------------------------------------------
ctx.write(시트, 시작칸, 값들)
--------------------------------------------------------------------
 무엇을 하나 : 표 모양의 값 묶음을 시작칸부터 한 번에 씁니다.
 언제 쓰나   : 여러 칸에 값을 넣을 때. 가장 많이 쓰는 명령입니다.
 값 모양     : 대괄호 두 겹입니다. 바깥은 행, 안쪽은 열.
                 [[1, 2], [3, 4]]  →  1  2
                                      3  4
 예시        : ctx.write("요약", "B2", [["서울", 100], ["부산", 200]])

--------------------------------------------------------------------
ctx.write_cell(시트, 칸, 값)
--------------------------------------------------------------------
 무엇을 하나 : 칸 하나에 값을 씁니다.
 주의        : 반복문에서 수백 번 부르면 느려서 중단됩니다.
               많은 칸을 채울 때는 위의 ctx.write 를 쓰세요.
 예시        : ctx.write_cell("요약", "B2", 12345)

--------------------------------------------------------------------
ctx.write_formulas(시트, 시작칸, 수식들)
--------------------------------------------------------------------
 무엇을 하나 : 값이 아니라 "수식" 을 한 번에 넣습니다.
 예시        : ctx.write_formulas("정산", "D2", [["=B2-C2"], ["=B3-C3"]])

--------------------------------------------------------------------
ctx.clear(시트, 범위, keep_formulas=False)
--------------------------------------------------------------------
 무엇을 하나 : 범위의 내용을 지웁니다. 서식(색·테두리)은 남습니다.
 옵션        : keep_formulas=True 로 하면 수식 칸은 그대로 두고
               직접 입력된 값만 지웁니다.
 언제 쓰나   : "데이터만 비우고 수식은 살려 줘" 요청.
 예시        : ctx.clear("양식", "B5:H200", keep_formulas=True)

--------------------------------------------------------------------
ctx.replace(시트, 범위, 찾을값, 바꿀값, match_entire=False)
--------------------------------------------------------------------
 무엇을 하나 : 범위 안 글자를 바꿔치기 합니다. 수식 칸은 건드리지 않습니다.
 옵션        : match_entire=True 면 칸 전체가 똑같을 때만 바꿉니다.
 결과        : 바뀐 칸 개수를 돌려줍니다.
 예시        : ctx.replace("목록", "C1:C500", "(주)", "주식회사")

--------------------------------------------------------------------
ctx.shift_months(시트, 범위, delta=1)
--------------------------------------------------------------------
 무엇을 하나 : 글자 안에 있는 "N월" 을 한꺼번에 몇 달 앞뒤로 옮깁니다.
 예시로 보면 : "2026년 06월 (05월 1일 ~ 05월 31일)" 에 +1 을 하면
               "2026년 07월 (06월 1일 ~ 06월 30일)" 이 됩니다.
 알아서 해 줌: 12월을 넘으면 연도가 바뀌고, 말일(30일/31일/윤년)도
               맞춰 줍니다. 숫자·날짜·수식 칸은 건드리지 않습니다.
 언제 쓰나   : "다음 달 양식으로 바꿔 줘", "월 정보 +1" 요청.
 예시        : ctx.shift_months("표지", "A1:F5", 1)


====================================================================
 5. 다. 복사·붙여넣기
====================================================================

--------------------------------------------------------------------
ctx.copy(원본시트, 원본범위, 대상시트, 대상칸)
--------------------------------------------------------------------
 무엇을 하나 : 엑셀에서 Ctrl+C / Ctrl+V 한 것과 같습니다.
               값·수식·색·테두리·병합이 전부 따라갑니다.
 언제 쓰나   : 그냥 "복사해 줘" 요청의 기본 수단.
 주의        : 수식이 그대로 옮겨지므로 참조 위치가 밀릴 수 있습니다.
               결과값만 필요하면 아래 copy_values.
 예시        : ctx.copy("원본", "A1:F30", "요약", "A1")

--------------------------------------------------------------------
ctx.copy_values(원본시트, 원본범위, 대상시트, 대상칸)
--------------------------------------------------------------------
 무엇을 하나 : "값으로 붙여넣기" 입니다. 계산 결과와 서식은 가져오고
               수식은 가져오지 않습니다.
 왜 필요한가 : 제목이 =다른시트!A2 같은 수식이면 위치를 옮길 때
               =다른시트!J2 로 어긋납니다. 이 명령은 그런 밀림이 없습니다.
 언제 쓰나   : "글자 그대로 복사", "값으로 복사" 요청.
 예시        : ctx.copy_values("원본", "A1:A5", "요약", "J1")

--------------------------------------------------------------------
ctx.paste_copied(...)
--------------------------------------------------------------------
 무엇을 하나 : 사용자가 실제로 했던 Ctrl+C / Ctrl+V 동작을 그대로
               다시 재생합니다.
 언제 쓰나   : "복붙 녹화" 기능으로 만든 스킬에서 자동으로 쓰입니다.
               직접 쓸 일은 거의 없습니다.
 특징        : 추측이 아니라 실제로 눌렀던 좌표로 실행하므로
               "값인지 수식인지" 헷갈릴 일이 없습니다.
               다른 파일 사이 복사도 됩니다.

--------------------------------------------------------------------
ctx.copy_col(시트, 원본열, 대상열, header_row=None)
--------------------------------------------------------------------
 무엇을 하나 : 한 열을 통째로 다른 열에 복사합니다(원본 유지).
               값·수식·서식·세로 병합이 따라갑니다.
 알아서 해 줌: 맨 위 제목처럼 가로로 병합된 부분은 알아서 피해 갑니다
               ("병합된 셀에서는 실행할 수 없습니다" 오류 방지).
 예시        : ctx.copy_col("정산", "D", "K")

--------------------------------------------------------------------
ctx.copy_key_blocks(...)
--------------------------------------------------------------------
 무엇을 하나 : 가입번호처럼 하나의 번호가 여러 행에 걸쳐 병합된 표에서,
               같은 번호 덩어리 "전체" 를 통째로 옮겨 옵니다.
 왜 필요한가 : 단순 검색으로 옮기면 덩어리의 첫 줄 하나만 복사되고
               소계 등 나머지 줄이 사라집니다.
 안전장치    : 원본과 대상의 덩어리 높이가 다르면 기본적으로 건너뛰고
               보고합니다(아래 줄을 덮어쓰는 사고 방지).
 결과        : 복사한 개수 / 원본에 없던 번호 / 높이가 다른 번호를 알려 줍니다.
 예시        : ctx.copy_key_blocks("로우데이터.xlsx!sheet", "콜센터",
                                   "B", "B", "N", "B3:B345", "B4:B89")

--------------------------------------------------------------------
ctx.append_same_format_sheets(파일목록, dest_sheet="통합")
--------------------------------------------------------------------
 무엇을 하나 : 같은 양식의 여러 파일을 새 시트 하나에 이어 붙입니다.
 알아서 해 줌: 첫 파일만 머리글을 포함하고, 나머지는 머리글 다음 줄부터
               붙입니다. 머리글이 몇 행인지도 알아서 찾습니다
               (1행이 비어 있는 청구내역 양식도 처리됩니다).
 특징        : 엑셀 복사를 쓰기 때문에 긴 가입번호·날짜·회계 서식이
               그대로 유지됩니다.
 언제 쓰나   : "여러 파일 합쳐 줘" 요청.


====================================================================
 6. 라. 행·열 다루기
====================================================================

--------------------------------------------------------------------
ctx.insert_rows(시트, 행, count=1)      /  ctx.delete_rows(시트, 행, count=1)
--------------------------------------------------------------------
 무엇을 하나 : 행을 끼워 넣거나 지웁니다.
 쓰는 법     : 행 번호와 개수로 주거나, "3:7" 처럼 범위로 줘도 됩니다.
 예시        : ctx.insert_rows("데이터", 5)          # 5행 위에 1줄
               ctx.delete_rows("데이터", "1:9")      # 1~9행 삭제

--------------------------------------------------------------------
ctx.insert_cols(시트, 열, count=1)      /  ctx.delete_cols(시트, 열, count=1)
--------------------------------------------------------------------
 무엇을 하나 : 열을 끼워 넣거나 지웁니다. 병합이 있어도 안전합니다.
 쓰는 법     : "B" / 2 / "B:D" 다 됩니다.
 예시        : ctx.insert_cols("요금", "B")
               ctx.delete_cols("요금", "Q:AU")

--------------------------------------------------------------------
ctx.delete_rows_where(시트, 조건, header_rows=1)
--------------------------------------------------------------------
 무엇을 하나 : 조건에 맞는 행만 그 자리에서 지웁니다.
 왜 중요한가 : 남는 행의 색·테두리·표시형식·수식·병합이 그대로 유지됩니다.
               "임시 시트에 값만 복사했다가 다시 붙이는" 방식은 서식을
               통째로 깨뜨립니다. 그 대신 쓰는 명령입니다.
 언제 쓰나   : "특정 값인 행만 남기고 나머지 지워 줘" 요청.
 결과        : 지운 행 개수를 돌려줍니다.
 예시        : ctx.delete_rows_where("무선간선망",
                   lambda r: ctx.normalize(r[2]) != ctx.normalize("512102403338"))
               (r[2] 는 왼쪽에서 세 번째 열. 0부터 셉니다)

--------------------------------------------------------------------
ctx.move_cols(시트, 열목록, before열, header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 여러 열을 머리글부터 데이터까지 통째로 다른 위치 앞으로
               옮깁니다(원래 자리는 없어짐).
 쓰는 법     : 열 목록은 머리글 이름이나 열 문자로 줍니다.
 언제 쓰나   : "열 순서 바꿔 줘" 요청.
 예시        : ctx.move_cols("정산", ["단가", "금액"], "J")

--------------------------------------------------------------------
ctx.move_col_clear(시트, 원본열, 대상열)
--------------------------------------------------------------------
 무엇을 하나 : 한 열의 내용을 다른 열로 옮기고 원래 열은 비웁니다.
               열 자체는 그대로 있습니다(삭제·밀림 없음).
 언제 쓰나   : "D열 내용을 K열로 옮기고 D는 비워 줘".
 참고        : 열 순서 자체를 재배치하려면 move_cols 를 쓰세요.

--------------------------------------------------------------------
ctx.swap_cols(시트, 열A, 열B)
--------------------------------------------------------------------
 무엇을 하나 : 붙어 있는 두 열의 자리를 서로 바꿉니다.
 왜 안전한가 : 엑셀의 잘라내기/삽입 기능을 쓰기 때문에 =SUM(D..) 같은
               수식 참조가 자동으로 따라옵니다(#REF! 오류가 안 납니다).
 참고        : 떨어져 있는 열을 재배치하려면 move_cols 를 쓰세요.

--------------------------------------------------------------------
ctx.hide_cols(시트, 범위, hidden=True)  /  ctx.hide_rows(시트, 범위, hidden=True)
--------------------------------------------------------------------
 무엇을 하나 : 열이나 행을 숨기거나 다시 보이게 합니다.
 예시        : ctx.hide_cols("매출", "B:D")            # 숨기기
               ctx.hide_cols("매출", "B:D", False)     # 다시 보이기

--------------------------------------------------------------------
ctx.merge(시트, 범위)  /  ctx.unmerge(시트, 범위)
--------------------------------------------------------------------
 무엇을 하나 : 칸을 병합하거나 병합을 풉니다.
 예시        : ctx.merge("표지", "A1:F1")

--------------------------------------------------------------------
ctx.split_column(시트, 열, 구분자, into=None, header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 한 칸에 붙어 있는 값을 구분자로 잘라 오른쪽 새 열들에
               나눠 넣습니다. 원본 열은 그대로 둡니다.
 예시로 보면 : "1001/홍길동"  →  1001 | 홍길동
 예시        : ctx.split_column("명단", "C", "/", into=["가입번호", "고객명"])

 7. 마. 필터

--------------------------------------------------------------------
ctx.enable_filter(시트, header_row=1)        ※ 시트를 빼면 지금 보고 있는 시트
--------------------------------------------------------------------
 무엇을 하나 : 머리글 줄에 필터 화살표만 켭니다(조건은 걸지 않음).
 언제 쓰나   : "필터 걸어 줘(조건 없이)", "필터 켜 줘".

--------------------------------------------------------------------
ctx.apply_filter(시트, 열, 값들, header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 특정 값만 화면에 보이게 필터를 겁니다.
               데이터를 지우는 게 아니라 "숨기는" 것이라 언제든 되돌릴
               수 있습니다.
 언제 쓰나   : "완료·진행인 것만 보이게 해 줘".
 예시        : ctx.apply_filter("상품번호별", "상태", ["완료", "진행"])
 참고        : 조건에 맞는 행만 "뽑아서 새 시트로" 옮기려면
               ctx.filter_to_sheet 를 쓰세요.

--------------------------------------------------------------------
ctx.clear_filter(시트)        ※ 시트를 빼면 지금 보고 있는 시트
--------------------------------------------------------------------
 무엇을 하나 : 걸려 있는 필터를 모두 풉니다. 숨겨진 행이 다시 보이고
               필터 화살표도 없어집니다.
 언제 쓰나   : "필터 풀어 줘 / 해제해 줘 / 필터 걸린 거 없애 줘".
 참고        : 필터가 하나도 없어도 오류가 나지 않고 그냥 지나갑니다.

--------------------------------------------------------------------
ctx.filter_to_sheet(시트, 조건, 새시트이름, header_rows=1)
--------------------------------------------------------------------
 무엇을 하나 : 조건에 맞는 행만 골라 새 시트에 정리합니다.
               원본 시트는 그대로 둡니다.
 특징        : 엑셀 복사로 옮기기 때문에 색·테두리·표시형식·열 너비가
               그대로 유지됩니다.
 언제 쓰나   : "○○만 뽑아서 새 시트로 정리해 줘".
 예시        : ctx.filter_to_sheet("Sheet1",
                   lambda r: r[2] == "안전제일", "안전제일목록")

--------------------------------------------------------------------
ctx.column_is(열, 값들)
--------------------------------------------------------------------
 무엇을 하나 : 필터 조건을 만들어 주는 보조 명령입니다.
               직접 쓸 일은 거의 없습니다.


====================================================================
 8. 바. 합계·피벗
====================================================================

--------------------------------------------------------------------
ctx.pivot(시트, group_by, value=None, agg="sum", dest_name=None, column=None)
--------------------------------------------------------------------
 무엇을 하나 : "○○별 합계/개수/평균" 요약표를 새 시트에 만듭니다.
               기본은 엑셀의 진짜 피벗테이블로 만들고, 그게 실패하면
               자동으로 값만 있는 요약표로 바꿔서 만듭니다.
 쓰는 법
     group_by  : 기준이 되는 항목(머리글 이름). 여러 개면 목록으로.
     value     : 합칠 값(머리글 이름). 안 주면 "개수" 를 셉니다.
     agg       : sum(합계) / count(개수) / avg(평균) / max / min
     column    : 가로축도 나누고 싶을 때(교차표)
     dest_name : 만들 시트 이름
 언제 쓰나   : "○○별로 합계 내 줘", "요약해 줘", "피벗 만들어 줘".
 예시        : ctx.pivot("매출", group_by="지점", value="금액",
                         agg="sum", dest_name="지점별요약")

--------------------------------------------------------------------
ctx.native_pivot(시트, group_by, value=None, agg="sum", dest_name=None)
--------------------------------------------------------------------
 무엇을 하나 : 엑셀의 "진짜 피벗테이블" 만 만듭니다. 원본과 연결되어
               있어서 새로 고침이 되고 필드를 마우스로 옮길 수 있습니다.
 언제 쓰나   : "새로고침 되는 피벗으로 만들어 줘", "슬라이서 쓸 거야".
 참고        : 보통은 ctx.pivot 하나만 쓰면 됩니다.

--------------------------------------------------------------------
ctx.sum_column(시트, 열, header_row=None, exclude_total_rows=True)
--------------------------------------------------------------------
 무엇을 하나 : 한 열의 숫자를 더한 "값" 을 돌려줍니다.
               (파일에 쓰지는 않습니다. 결과를 write_cell 로 넣으세요)
 알아서 해 줌: 표 안에 이미 있는 합계/총계/소계 행을 자동으로 빼서
               이중 계산을 막습니다. 첫 총계 행 아래의 부가세·검산 같은
               꼬리도 더하지 않습니다.
 예시        : total = ctx.sum_column("요약", "합계", header_row=4)
               ctx.write_cell("요약", "J15", total)

--------------------------------------------------------------------
ctx.sum_where(시트, 값열, 조건목록, header_row=None)
--------------------------------------------------------------------
 무엇을 하나 : 조건을 모두 만족하는 행만 골라 합계를 냅니다(SUMIFS 와 비슷).
 왜 좋은가   : 큰 표를 통째로 읽지 않고 필요한 열만 좁게 읽어서 계산하므로
               대용량에서도 빠릅니다.
 조건 쓰는 법: [(열, 값), ...] 또는 [(열, 비교, 값), ...]
               비교는 == / != / contains(포함) / > / >= / < / <=
               글자 비교는 공백·전각 차이를 알아서 무시합니다.
 예시        : t = ctx.sum_where("SO사업자별요금", "M",
                     [("D", "인터넷"), ("G", "매 출")], header_row=5)
               ctx.write_cell("SO사업자별요금", "AG4", t)

--------------------------------------------------------------------
ctx.fill_sum_col(시트, 대상열, 원본열들, header_row=None)
--------------------------------------------------------------------
 무엇을 하나 : 합계 열을 =SUM(...) 수식으로 채웁니다.
 알아서 해 줌: 대상 열이 여러 행씩 세로로 병합된 표(계정별 그룹)면
               병합 덩어리 단위로 합계를 넣습니다.
               숫자가 아닌 라벨·단위·소제목 행은 건너뜁니다.
 예시        : ctx.fill_sum_col("정산", "합계", ["1월", "2월", "3월"])

--------------------------------------------------------------------
ctx.add_total_row(시트, sum_cols, label_col=None, label="합계", header_row=1)
--------------------------------------------------------------------
 무엇을 하나 : 표 맨 아래에 합계 행을 만들고 =SUM 수식을 넣습니다.
 결과        : 만들어진 합계 행 번호를 돌려줍니다.
 예시        : ctx.add_total_row("매출", ["금액", "수량"], label_col="A")


====================================================================
 9. 사. 다른 표에서 값 가져오기
====================================================================

--------------------------------------------------------------------
ctx.lookup(시트, 키열, 넣을열, 표시트, 표키열, 표값열, header_row=1, default=None)
--------------------------------------------------------------------
 무엇을 하나 : VLOOKUP 과 같습니다. 키를 다른 표에서 찾아 그 행의
               값을 가져와 채웁니다.
 알아서 해 줌: 키를 비교할 때 공백·전각·대소문자·숫자와 글자 차이를
               무시하므로 "분명 같은 값인데 안 찾아짐" 이 잘 안 생깁니다.
 결과        : 찾아서 채운 행 개수를 돌려줍니다.
 예시        : ctx.lookup("청구내역", "상품코드", "단가",
                          "단가표", "코드", "단가")

--------------------------------------------------------------------
ctx.sum_lookup(원본시트, 원본키열, 원본값열,
               대상시트, 대상키열, 대상넣을열, header_row=None)
--------------------------------------------------------------------
 무엇을 하나 : 키가 같은 행들의 값을 "모두 더해서" 가져옵니다.
 특별한 점   : 대상 칸에 가입번호가 여러 개 들어 있으면(줄바꿈·공백·쉼표로
               구분) 각각 나눠서 전부 더합니다. KT/HCN 처럼 한 칸에 번호가
               여러 개인 자료 때문에 만든 기능입니다.
 결과        : 값을 채운 행 수와 원본 키 개수를 알려 줍니다.
 예시        : ctx.sum_lookup("input.xlsx!Sheet1", "BP", "BQ",
                              "SO사업자별요금", "P", "H",
                              header_row=1, dst_start_row=6)

--------------------------------------------------------------------
ctx.match_fill(원본, 대상, columns, key=None, header_row=1, ...)
--------------------------------------------------------------------
 무엇을 하나 : 피벗이나 요약표의 값을 다른 시트에 "이름을 맞춰서" 넣습니다.
 알아서 해 줌: 이름이 정확히 같지 않아도 순서대로 시도합니다.
               정확히 일치 → 공백 무시 → 기호 무시 → 부분 포함
               그래도 확실히 못 맞춘 이름은 후보와 함께 알려 줘서
               한 번에 확정할 수 있게 합니다.
 쓰는 법
     columns   : {원본 값열 : 대상 값열} 형태의 짝
     key       : (원본 키열, 대상 키열). 생략하면 둘 다 A열
     aliases   : 못 맞춘 이름을 직접 짝지어 줄 때
     allow_partial=True : 못 맞춘 건 건너뛰고 맞춘 것만 채우기
 언제 쓰나   : "피벗 결과를 양식에 이름 맞춰 붙여 줘".
 예시        : ctx.match_fill("input.xlsx!MVNO요약", "청구서",
                   {"수납금액_sum": "고객납부금액"},
                   key=("상품명", "구분"), header_row=4)

--------------------------------------------------------------------
ctx.normalize(값)
--------------------------------------------------------------------
 무엇을 하나 : 글자에서 공백·표기 차이를 없애 비교하기 좋게 만듭니다.
 언제 쓰나   : 값을 서로 비교할 때 보조로.
 예시        : if ctx.normalize(a) == ctx.normalize(b): ...

 11. 자. 보기 좋게 꾸미기

--------------------------------------------------------------------
ctx.set_fill(시트, 범위, color=None)
--------------------------------------------------------------------
 무엇을 하나 : 칸 배경색을 칠합니다. color 를 비우면 색을 지웁니다.
 색 쓰는 법  : "노랑" 같은 한글 이름, "red" 같은 영어 이름, "#DDEBF7" 다 됩니다.

--------------------------------------------------------------------
ctx.set_font(시트, 범위, size=None, bold=None, italic=None, color=None, name=None)
--------------------------------------------------------------------
 무엇을 하나 : 글꼴을 바꿉니다. 지정한 것만 바뀌고 나머지는 그대로입니다.
 예시        : ctx.set_font("매출", "A1:C1", bold=True, size=12)
               ctx.set_font("매출", "B2", italic=True, color="빨강")

--------------------------------------------------------------------
ctx.set_border(시트, 범위, style="thin", color=None, edges="all")
--------------------------------------------------------------------
 무엇을 하나 : 테두리를 그립니다.
 굵기(style) : thin(가늘게) / medium / thick(굵게) / double(이중) / none(지우기)
 위치(edges) : all(칸마다 사방+안쪽) / outline(바깥 테두리만) /
               top·bottom·left·right (쉼표로 여러 개, 한글 위·아래·왼쪽·오른쪽도 됨)
 예시        : ctx.set_border("매출", "A1:D20")
               ctx.set_border("매출", "A1:D1", style="thick", edges="bottom")

--------------------------------------------------------------------
ctx.set_number_format(시트, 범위, 형식)
--------------------------------------------------------------------
 무엇을 하나 : 표시 형식을 바꿉니다(천 단위 쉼표, 날짜 모양, 퍼센트 등).
 예시        : ctx.set_number_format("매출", "C2:C100", "#,##0")
               ctx.set_number_format("매출", "A2:A100", "yyyy-mm-dd")


====================================================================
 12. 차. 정리
====================================================================

--------------------------------------------------------------------
ctx.sort(시트, 범위, key_col, ascending=True, has_header=True)
--------------------------------------------------------------------
 무엇을 하나 : 범위를 정렬합니다.
 쓰는 법     : key_col 은 범위 안에서 몇 번째 열인지(1부터) 또는 열 문자.
               여러 기준으로 정렬하려면 목록으로 주고, 오름/내림도
               기준마다 따로 줄 수 있습니다.
 예시        : ctx.sort("데이터", "A1:F200", "B")
               ctx.sort("데이터", "A1:F200", ["B", "C"], [True, False])

--------------------------------------------------------------------
ctx.dedupe(시트, key_cols, header_row=1, keep="first")
--------------------------------------------------------------------
 무엇을 하나 : 지정한 열 조합이 같은 중복 행을 지웁니다.
 옵션        : keep="first" 는 처음 것, "last" 는 마지막 것을 남깁니다.
 결과        : 지운 행 수를 돌려줍니다.
 주의        : 행을 하나씩 지우는 방식이라 중복이 아주 많은 대용량
               파일에서는 느립니다.
 예시        : ctx.dedupe("명단", ["가입번호", "청구월"])


====================================================================
 13. 카. 다른 파일 함께 쓰기
====================================================================

--------------------------------------------------------------------
ctx.book(파일이름)
--------------------------------------------------------------------
 무엇을 하나 : 같이 열려 있는 다른 파일을 가리킵니다. 그 뒤에 앞에서
               본 명령들을 똑같이 붙여 쓰면 됩니다.
 예시        : out = ctx.book("output_검증파일.xlsx")
               out.write("Sheet1", "A1", [["값"]])


====================================================================
 14. 자주 하는 실수와 권장 방법
====================================================================

(1) 열 위치를 숫자로 고정하지 마세요
    파일마다 열이 한두 칸씩 밀립니다.
    권장 : ctx.find_header 로 머리글 이름으로 찾기
    예외 : 요청하신 분이 "Q열" 처럼 직접 지정했다면 그대로 쓰는 게 정확합니다.

(2) "위에서 몇 줄 삭제" 를 고정하지 마세요
    시스템 추출 보고서는 안내 줄 수가 달마다 바뀝니다.
    권장 : ctx.find_header_row 로 머리글 행을 찾아 그 위를 삭제

(3) 서식을 지키고 싶으면 "다시 만들기" 대신 "제자리 편집"
    임시 시트에 값만 복사했다가 되붙이면 색·테두리가 다 깨집니다.
    권장 : ctx.delete_rows_where, ctx.filter_to_sheet

(4) 합계를 직접 계산하지 말고 전용 명령을 쓰세요
    권장 : ctx.pivot(요약) / ctx.sum_where(조건 합계) / ctx.sum_column(열 합계)
    이유 : 표 안의 소계·총계 행을 이중으로 더하는 실수를 막아 줍니다.

(5) 칸 하나씩 반복해서 쓰지 마세요
    ctx.write_cell 을 반복문에서 수백 번 부르면 중단됩니다.
    권장 : 값을 모아서 ctx.write 로 한 번에

(6) 큰 표를 통째로 읽지 마세요
    권장 : 조건 합계는 ctx.sum_where, 값 가져오기는 ctx.lookup / ctx.sum_lookup

(7) 수식이 밀리는 게 싫으면 값으로 복사
    권장 : ctx.copy_values (서식은 유지, 수식은 값으로 고정)
