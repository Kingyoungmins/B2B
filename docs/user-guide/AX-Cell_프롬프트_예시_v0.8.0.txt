 - 스킬 함수 설명서(같은 폴더)의 짝 문서
 - 버전 0.8.0 / 2026-08-26
====================================================================

[이 문서는 무엇인가요?]

  스킬 함수 설명서는 "AX-Cell 이 무엇을 할 수 있는가" 를 명령 이름으로
  정리한 문서입니다. 그런데 사용자는 명령 이름을 치지 않습니다.
  **채팅창에 우리말로 요청**합니다.

  이 문서는 그 사이를 이어 줍니다 — 어떤 말로 요청하면 어떤 명령이
  쓰이는지, 실제로 통하는 문장을 명령마다 하나씩 적었습니다.

[읽는 법]

  · 문장을 그대로 따라 쓰실 필요는 없습니다. 뜻만 같으면 됩니다.
  · 대상 파일·시트는 채팅창에서 @ 로 고르시면 가장 정확합니다.
        예) @시트[정산.xlsx/청구내역] 청구금액 열을 합계 내줘
  · 열은 **머리글 이름**으로 부르는 편이 안전합니다("Q열" 보다 "청구금액").
    다만 위치를 콕 집어야 할 때는 열 문자로 말해도 됩니다.
  · 한 번에 한 가지씩 요청하세요. 한 메시지 = 스킬 한 단계입니다.

--------------------------------------------------------------------
[형식]  명령이름 다음 줄부터 그 명령을 쓰게 하는 요청문
--------------------------------------------------------------------

# sheets
이 파일에 시트가 뭐뭐 있는지 알려줘
모든 시트에 걸린 필터를 풀어줘

# used_range
이 시트에 데이터가 몇 행 몇 열까지 있는지 알려줘

# last_row
A열 기준으로 데이터가 마지막 몇 행까지 있는지 확인해줘

# last_col
1행 기준으로 마지막 열이 어디까지인지 확인해줘

# used_last_row
시트 전체 기준으로 마지막 행까지 포함해서 처리해줘

# used_last_col
시트 전체 기준 마지막 열까지 포함해서 처리해줘

# first_empty_col
표 오른쪽 빈 열을 찾아서 거기에 새 항목을 넣어줘

# find_header_row
머리글 줄을 찾아서 그 위에 있는 안내 행들을 지워줘

# find_header
청구금액 열이 몇 번째 열인지 찾아서 그 열로 작업해줘

# read
A1부터 F200까지 값을 읽어서 확인해줘

# read_cell
B2 칸에 뭐가 들어 있는지 알려줘

# read_formulas
이 범위에 들어 있는 수식을 그대로 보여줘

# has_formulas
이 범위에 수식이 들어 있는지 확인해줘

# formula_mask
어느 칸이 수식이고 어느 칸이 값인지 구분해줘

# write
합계 열에 계산한 값들을 한 번에 넣어줘
B2부터 값을 채워줘

# write_cell
C5 칸에 "합계" 라고 써줘

# write_formulas
G열에 =E2*F2 수식을 아래까지 넣어줘

# clear
D열 내용만 지워줘 (서식은 그대로 두고)
A2:F100 범위 값만 비워줘

# replace
시트에서 "(주)" 를 "주식회사" 로 바꿔줘
전화번호의 하이픈을 없애줘

# shift_months
문서에 있는 3월을 전부 4월로 바꿔줘
월 정보를 한 달씩 뒤로 밀어줘

# copy
A1:F50 을 다른 시트 같은 자리에 서식까지 그대로 복사해줘

# copy_values
계산 결과를 값으로 붙여넣어줘 (수식 말고 값으로 고정)
수식이 밀리지 않게 값만 복사해줘

# paste_copied
내가 방금 복사해서 붙여넣은 그 작업을 그대로 반복해줘

# copy_col
청구금액 열을 J열에 그대로 복사해줘 (원본은 두고)

# copy_key_blocks
가입번호가 병합돼 있는 표에서 번호 단위로 묶어서 옮겨줘

# append_same_format_sheets
같은 양식의 파일 세 개를 새 시트 하나에 이어붙여줘 (머리글은 한 번만)

# insert_rows
5행 위에 빈 행 하나 추가해줘
표 맨 위에 행 3개 넣어줘

# delete_rows
1행부터 9행까지 지워줘
안내 문구가 있는 위쪽 행들을 삭제해줘

# insert_cols
Q열과 R열 사이에 열 1개 추가해줘
청구금액 열 앞에 빈 열 하나 넣어줘

# delete_cols
Q열부터 AU열까지 삭제해줘
쓰지 않는 오른쪽 열들을 지워줘

# delete_rows_where
금액이 0인 행은 지워줘
상태가 "해지" 인 행만 삭제해줘

# move_cols
D열을 G열 앞으로 옮겨줘
열 순서를 청구금액, 할인금액, 합계 순으로 바꿔줘

# move_col_clear
D열 내용을 G열로 옮기고 원래 D열은 비워줘 (열은 지우지 말고)

# swap_cols
D열과 E열 자리를 서로 바꿔줘

# hide_cols
C열부터 E열까지 숨겨줘
숨긴 열을 다시 보이게 해줘

# hide_rows
10행부터 20행까지 숨겨줘

# merge
A1부터 C1까지 병합해줘

# unmerge
병합된 칸을 전부 풀어줘

# split_column
"1001/홍길동" 처럼 한 칸에 붙어 있는 걸 가입번호와 고객명 두 열로 나눠줘

# enable_filter
머리글에 필터 걸어줘 (조건은 없이)

# apply_filter
상품명이 "올인원" 인 것만 보이게 필터 걸어줘

# clear_filter
걸려 있는 필터 전부 풀어줘

# filter_to_sheet
상태가 "정상" 인 행만 골라서 새 시트에 정리해줘
회사별로 해당하는 행만 뽑아서 시트로 만들어줘

# column_is
여러 조건을 함께 걸어서 필터해줘 (지역이 서울이고 상태가 정상인 것)

# pivot
회사별 청구금액 합계를 요약표로 만들어줘
상품별 건수를 그룹별로 집계해줘
행은 지점, 열은 월, 값은 매출로 크로스탭 만들어줘

# native_pivot
엑셀 진짜 피벗테이블로 만들어줘 (나중에 필드 바꿀 수 있게)

# sum_column
청구금액 열 합계가 얼마인지 알려줘

# sum_where
지역이 서울이면서 상태가 정상인 행들의 금액만 더해줘
조건에 맞는 것만 합계 내줘

# fill_sum_col
합계 열에 =SUM 수식으로 각 행 합계를 채워줘

# add_total_row
표 맨 아래에 합계 행 추가해줘

# lookup
단가표에서 상품명으로 단가를 찾아서 단가 열에 채워줘
VLOOKUP 처럼 다른 시트에서 값을 가져와줘

# sum_lookup
한 칸에 가입번호가 여러 개 들어 있어도 전부 찾아서 금액을 더해 채워줘

# match_fill
피벗 결과를 구분명 이름에 맞춰서 대상 시트에 채워줘
이름이 조금 달라도 맞춰서 값을 넣어줘

# normalize
공백이나 표기가 달라도 같은 것으로 보고 비교해줘

# add_sheet
"요약" 이라는 새 시트를 맨 앞에 만들어줘

# rename_sheet
Sheet1 시트 이름을 "청구내역" 으로 바꿔줘

# move_sheet
요약 시트를 맨 앞으로 옮겨줘

# copy_sheet
청구내역 시트를 그대로 복사해서 하나 더 만들어줘

# delete_sheet
임시 시트를 지워줘

# set_fill
머리글 줄에 회색 배경 칠해줘
금액이 0인 칸은 노란색으로 표시해줘

# set_font
머리글을 굵게 하고 글자 크기를 11로 바꿔줘

# set_border
표 전체에 테두리 그려줘

# set_number_format
금액 열에 천 단위 쉼표 넣어줘
날짜 열을 2026-01-31 모양으로 바꿔줘

# sort
청구금액 기준 내림차순으로 정렬해줘
회사명 오름차순, 금액 내림차순으로 정렬해줘

# dedupe
가입번호와 청구월이 같은 중복 행은 지워줘

# book
정산자료.xlsx 파일의 Sheet1 에도 같은 값을 넣어줘
출력 파일에 결과를 써줘

====================================================================
 이렇게 말하면 잘 안 됩니다
====================================================================

  아래는 실제로 자주 어긋났던 표현들입니다.

  (1) 한 메시지에 여러 작업을 몰아넣기
      X  "중복 지우고 정렬하고 합계도 넣어줘"
      O  세 번에 나눠서 요청하세요. 한 메시지 = 한 단계입니다.

  (2) 오류 상황을 그대로 적기
      X  "시트 보호 때문에 오류가 나요"
      O  "청구내역 시트의 D열에 금액을 채워줘" 처럼 **하고 싶은 작업**을
         적으세요. 오류 이야기만 있으면 무엇을 하라는 지시가 없습니다.

  (3) 열을 위치 숫자로만 부르기
      △  "세 번째 열을 지워줘"  (파일마다 열이 밀립니다)
      O  "청구금액 열을 지워줘"  (머리글 이름이 가장 안전합니다)
      ※ "Q열" 처럼 직접 집어야 하는 상황이라면 그대로 말해도 됩니다.

  (4) "사이에" 를 애매하게 쓰기
      X  "Q열과 R열 사이 정리해줘"
      O  "Q열과 R열 사이에 열 1개 추가해줘"  (무엇을 할지 함께)

  (5) 결과가 이상할 때 같은 문장을 그대로 다시 보내기
      O  "아니야, 청구금액 말고 할인금액 기준으로 해줘" 처럼
         **무엇이 틀렸는지**를 붙여 주세요. 훨씬 정확해집니다.
