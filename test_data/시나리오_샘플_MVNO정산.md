# 시나리오 — 샘플_MVNO정산_2026_06.xlsx (피벗·필터 헬퍼 시연)

새 헬퍼들(`native_pivot`, `pivot`, `apply_filter`/`clear_filter`/`enable_filter`, `first_empty_col`, `used_last_row`, 앞자리0 텍스트 보존)을 한 파일로 시연하는 테스트 시나리오.

## 샘플 파일 구조 — 시트 `정산내역`

| 열 | 헤더 | 설명 |
|---|---|---|
| A | 사업자 | A통신 / B모바일 / C텔레콤 (3종) |
| B | 지점 | 서울 / 부산 / 대구 |
| C | 상품 | 요금제1 / 요금제2 / 요금제3 |
| D | 상태 | 완료 / 진행 / 취소 / 보류 |
| E | 전화번호 | **텍스트, 앞자리 0 있음**(010…) |
| F | 기본료 | 숫자 |
| G | 통화료 | 숫자 |
| H | 데이터료 | 숫자 |
| I | **합계** | **`=SUM(F:H)` 수식** (그래서 '빈 보조열'은 **J**) |

- 데이터: 2행 ~ 25행 (24건). 헤더 1행.
- 포인트: **I열이 이미 합계 수식**이라 "빈 보조열" 데모에 적합(J를 골라야 정답), **E열은 텍스트 전화번호**라 앞자리0 보존 데모에 적합.

## 요청 시나리오 (자연어 → 기대 결과 → 쓰이는 헬퍼)

### 1) 값-표 피벗 (기본)
- 요청: **"사업자별 기본료 합계를 새 시트로 요약해줘"**
- 기대: 새 시트에 [사업자, 기본료_sum] 표(A/B/C 3행). 원본 보존.
- 헬퍼: `ctx.pivot("정산내역", group_by="사업자", value="기본료", agg="sum", dest_name="사업자별합계")`

### 2) 다중 키·다중 값
- 요청: **"사업자·지점별 기본료 합계와 건수 개수를 요약해줘"**
- 기대: [사업자, 지점, 기본료_sum, 건수_count].
- 헬퍼: `ctx.pivot(..., group_by=["사업자","지점"], value=["기본료", None], agg=["sum","count"], ...)` (또는 value=["기본료","기본료"], agg=["sum","count"])

### 3) 진짜 피벗테이블 (새로고침 되는)
- 요청: **"사업자별 기본료 합계로 진짜 피벗테이블(새로고침 되는) 만들어줘"**
- 기대: 새 시트에 **엑셀 PivotTable 개체** 생성 → 원본 바꾸고 새로고침하면 반영.
- 헬퍼: `ctx.native_pivot("정산내역", group_by="사업자", value="기본료", agg="sum", dest_name="피벗_사업자")`

### 4) 크로스탭 (행/열/값)
- 요청: **"행은 사업자, 열은 상태, 값은 기본료 합계로 피벗해줘"**
- 기대: 행=사업자, 열=완료/진행/취소/보류, 셀=기본료 합계.
- 헬퍼: `ctx.pivot("정산내역", group_by="사업자", column="상태", value="기본료", agg="sum", dest_name="사업자x상태")` (진짜 피벗이면 `ctx.native_pivot(..., column="상태", ...)`)

### 5) 표시 필터 (특정 값만 눈으로 — 삭제 아님)
- 요청: **"상태가 '완료'인 것만 화면에 보이게 필터 걸어줘"**
- 기대: 완료 아닌 행은 **숨김**(데이터는 그대로), 필터 드롭다운 켜짐.
- 헬퍼: `ctx.apply_filter("정산내역", "상태", "완료")` (여러 값이면 `["완료","진행"]`)

### 6) 필터 해제
- 요청: **"필터 다 풀어줘 / 필터 해제해줘"**
- 기대: 숨은 행 전부 복원 + 필터 드롭다운 제거.
- 헬퍼: `ctx.clear_filter("정산내역")`

### 7) 빈 보조열에 행별 계산 (수식 열 안 건드림)
- 요청: **"F~H(기본료~데이터료) 세 열의 행별 최대값을 빈 보조열에 넣어줘"**
- 기대: **J열**에 행별 MAX(I열의 =SUM 합계 수식은 건드리지 않음). J8이 아니라 J열 헤더+데이터.
- 헬퍼: `col = ctx.first_empty_col("정산내역", after="I")`  → "J"; `ctx.write_cell(...,"J1","행별MAX"); ctx.write(..., f"J2", out)` (범위는 `ctx.used_last_row` 로).

### 8) 데이터만 지우고 헤더 보존 (표 전체)
- 요청: **"데이터(2행~끝)만 지우고 헤더는 남겨줘"**  *(주의: 실행하면 데이터가 지워지니 별도 사본에서 테스트)*
- 기대: 2~25행 전부 clear, 1행 헤더 유지.
- 헬퍼: `last = ctx.used_last_row("정산내역"); ctx.clear("정산내역", f"A2:XFD{last}")` (A열 기준 last_row 금지 — 하단행 누락 위험)

### 9) 전화번호 앞자리 0 보존 피벗
- 요청: **"전화번호별 기본료 합계로 피벗을 새 시트에. 앞자리 0 유지."**
- 기대: 그룹키(전화번호)가 **"010…" 텍스트로 보존**(앞자리0 유지), 합계 정확. 사후 서식 지정 불필요.
- 헬퍼: `ctx.pivot("정산내역", group_by="전화번호", value="기본료", agg="sum", dest_name="전화번호별")`

## 참고
- 실행기/생성기 모두 이 파일로 위 요청을 자연어로 넣으면 해당 헬퍼가 자동 선택됩니다.
- `native_pivot`은 "진짜 피벗/새로고침/슬라이서"를 명시할 때만 쓰이고, 그 외 "~별 합계/요약"은 값-표 `pivot`이 기본입니다.
