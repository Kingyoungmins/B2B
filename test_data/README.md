# ver2.0 테스트 데이터

`make_test_files.py` 가 생성하는 3개의 xlsx 로 ver2.0 의 9가지 새 기능을 테스트합니다.

## 파일

| 파일 | 시트 | 용도 |
|---|---|---|
| `input_매출_2026_4월.xlsx` | `매출` (1200행), `고객정보` (20행), `월별집계` (표 3개) | 입력 #1 |
| `input_원가_2026_4월.xlsx` | `원가` (120행) | 입력 #2 — `회사명` 컬럼이 매출 파일과 겹침 |
| `output_청구서_템플릿.xlsx` | `회사별요약` (수식 포함), `월별실적` | 출력 템플릿 |

## 재생성

```bash
cd test_data
python make_test_files.py
```

## 기능별 테스트 시나리오

### 1. 유사도 매칭 (item 1)
입력 매출/원가 파일을 모두 업로드. 채팅에 일부러 약간 다른 이름으로 요청:
- "**원가표**의 단가를 1.1배 해줘" → `원가표` ≈ `원가` 시트로 fuzzy 매칭
- "**매출_시트**의 금액 컬럼을 천 단위로 잘라줘" → `매출_시트` ≈ `매출` 시트로 매칭
- "**거래처명**별로 합계를 구해줘" → `거래처명` ≈ `회사명` 컬럼

### 2. 같은 컬럼이 2개 파일에 있을 때 (item 2)
매출/원가 파일 모두 `회사명` 컬럼이 있음. 채팅에 파일 안 적고:
- "**회사명별로** 정렬해줘" → LLM 이 "어느 파일을 의미하시나요?" 라고 되묻는지 확인

### 3. 기본 대상 = 선택된 시트 탭 (item 3)
1. 매출 파일을 우측에 띄우고 `매출` 시트 탭 클릭
2. **Ctrl+click** 으로 `고객정보` 시트도 추가 선택 (✓ 표시 떠야 함)
3. 채팅에 파일/시트 명시 없이 "이 시트들의 회사명을 비교해줘"
4. system 프롬프트에 두 시트가 "기본 대상"으로 들어가는지 확인 (LLM 응답에 그 시트들만 다뤄져야 함)

### 4. 한 파일의 여러 시트 (item 4)
매출 파일은 시트 3개 — 시트 탭 전환 시 각각 보이는지, schema 설명에 모두 노출되는지 확인.

### 5. 한 시트에 여러 표 (item 5)
`월별집계` 시트는 `상반기 집계`, `하반기 집계`, `분기별 요약` 3개 표가 빈 행으로 분리됨. 채팅에:
- "**월별집계의 표를** 정렬해줘" → LLM 이 "표 3개 중 어느 것?" 또는 범위(A2:C8 등)를 되묻는지 확인
- 우측 입력 패널에서 `월별집계` 탭 선택 후 채팅하면 schema 에 `⚠️ 표 3개 감지됨` 라인이 들어가야 함

### 6. 가상 스크롤 (item 6)
매출 시트는 1200행. 우측 시뮬레이터 진입 → 처음 300행만 렌더, 아래로 스크롤 시 +300씩 자동 추가. 행번호가 300, 600, 900, 1200 까지 매끄럽게 늘어나는지 확인. 행 1200 도달 후 멈춰야 함.

### 7. Ctrl+F 검색 (item 7)
시뮬레이터 보이는 상태에서 **Ctrl+F** → 우상단 검색바 → "ABC통신" 입력 → ▼/▲ 로 다음/이전 매치 이동. 매치가 가상 스크롤 바깥에 있어도 자동으로 펼쳐서 보여줘야 함. **Esc** 로 닫기.

### 8. (스킵)

### 9. 단계 실행 오류 표시 (item 9)
일부러 깨지는 코드를 만들어 적용:
- "이번 단계는 `inputs['없는파일.xlsx']['시트'][0][0] = 'x'` 같은 코드를 만들어줘" (또는 응답 코드를 수동으로 망가뜨림)
- 적용 시 토스트와 채팅창에 `❌ Step N 실행 실패 — Step N (description) 실행 중 오류 — message` + 스택이 보여야 함

### 10. 수식 실시간 평가 (item 10)
1. 출력 템플릿 업로드 → 시뮬레이터에서 `회사별요약` 시트 봄
2. `마진` 열(D), `마진율` 열(E) 셀에 우상단 보라 모서리 (`has-formula`) 표식 + hover 시 수식 tooltip
3. 채팅으로 "회사별로 매출 합계를 B열에, 원가를 C열에 채워줘" 같은 단계 적용
4. 적용 직후 D열의 마진(=B-C), E열의 마진율(=IFERROR(D/B,0)), 마지막 행 합계 SUM/AVERAGE 가 모두 **실시간으로 계산된 값**으로 표시돼야 함 (이전엔 빈칸)
5. 다운로드한 xlsx 를 Excel 에서 열면 수식이 그대로 살아있어야 함

## 한 번에 검증하는 권장 시나리오

1. 매출/원가 모두 업로드, 출력 템플릿도 업로드
2. 매출 1200행 가상 스크롤 확인 (item 6)
3. Ctrl+F 로 "ABC통신" 검색 (item 7)
4. `월별집계` 탭 선택 후 채팅 "이 시트의 첫 번째 표를 정렬" → LLM 이 표 라벨/범위 묻는지 (item 5)
5. 채팅 "**거래처별로 매출 합계를 청구서_템플릿의 B열에 채워줘**" — fuzzy(거래처≈회사명) + 기본 대상 (item 1, 3)
6. 적용 후 출력 시뮬레이터에서 D/E 열 수식 자동 평가 확인 (item 10)
7. 일부러 잘못된 코드 단계를 추가해 오류 메시지 확인 (item 9)
