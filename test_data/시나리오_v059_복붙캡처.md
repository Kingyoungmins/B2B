# 시나리오 v0.5.9 — 복붙 캡처 + 셀 삭제 캡처 검증

## 목적
사용자가 우측 라이브 Excel에서 직접 한 **복사→붙여넣기**·**셀 삭제(Delete)** 를 앱이 역추적해 스킬 단계로 저장하고,
나중에 **전체실행**할 때 **값·수식·서식을 그대로 재현**하는지 검증한다.
(LLM이 "값이냐 수식이냐"를 추측하지 않고 실제 동작을 캡처 → 복붙 버그 제거. 재생은 Python COM `ctx.paste_copied`/`ctx.clear` → VBA 러너를 안 탄다.)

> ⚠️ 코드가 갱신되었으니 **앱을 완전 재시작**해야 아래 동작(단일 셀 붙여넣기 캡처, 🗑 셀 삭제 캡처 버튼)이 반영됨.

## 테스트 파일
- `v059_복붙캡처.xlsx`
  - **원본** 시트: 품목/단가/수량/**금액(=단가×수량 수식)**/비고, 합계 행(=SUM). `A1:E6`
  - **대상** 시트: 비어 있음(붙여넣기 목적지)
  - **원본2** 시트: 지점/매출 + 합계(=SUM) — 보조
- (교차파일 케이스용, 선택) 기존 `input_원가_2026_4월.xlsx` 등 아무 파일이나 함께 업로드

## 준비
1. 앱 **완전 재시작**(EXCEL.EXE 전부 종료 후 `start_b2b_native.bat`) — 새 백엔드/프론트 로딩.
2. `v059_복붙캡처.xlsx` 업로드 → 우측에 라이브 Excel이 뜬다.

## 케이스 1 — 같은 시트 복붙 (수식 보존)
1. **원본** 시트에서 `A1:E6` 드래그 → **Ctrl+C**.
2. `G1` **한 셀만 클릭** → **Ctrl+V**. (붙여넣기 기준점만 잡으면 됨 — 소스 크기만큼 자동 확장 캡처.)
3. 곧바로 **📋 복붙 캡처** 버튼 클릭.

**기대:**
- 파이프라인에 단계 추가: `복붙: 원본!A1:E6 → 원본!G1`
- 붙여넣은 `J2`(금액 자리) 셀을 클릭하면 수식 바에 **`=H2*I2`**(상대참조가 새 위치로 따라감)가 보임 — 값만이 아니라 **수식이 보존**됨.
- `J6`(합계 자리)에 `=SUM(J2:J5)` 형태.

> 참고: `G1:K6` 처럼 **붙여넣을 범위 전체를 드래그**해서 Ctrl+V 해도 동일하게 캡처된다. 단일 셀·전체범위 둘 다 OK.

### 케이스 1-B — 열 전체 / 행 전체 선택 복붙
1. **열 전체**: 열 머리글 `A`~`E` 드래그(전체 열 선택) → Ctrl+C → `G1` 클릭 → Ctrl+V → **📋 복붙 캡처**.
   - 기대 단계: `복붙: 원본!A:E → 원본!G1` (예전엔 `C1:C5` 로 잘못 잡혀 깨졌음 — 수정됨).
   - `J2`(금액 자리) 수식 `=H2*I2` 보존. 열 전체가 `G:K` 로 붙는다.
2. **행 전체**: 행 머리글 `1`~`6` 드래그(전체 행 선택) → Ctrl+C → `A8` 클릭 → Ctrl+V → **📋 복붙 캡처**.
   - 기대 단계: `복붙: 원본!1:6 → 원본!A8` (예전엔 `R1:R6` 로 잘못 잡혀 아무것도 안 됐음 — 수정됨).
   - `D9` 수식 `=B9*C9` 보존.

> 전체 열/행 복붙은 **되돌리기(롤백) 불가**로 표시된다(시트 전체 범위라 저널 백업을 생략). 전체실행 reset 은 원본에서 다시 시작하므로 재현엔 문제없음.

## 케이스 2 — 시트 간 복붙
1. **원본** `A1:E6` → **Ctrl+C**.
2. **대상** 시트의 `A1` 클릭 → **Ctrl+V**.
3. **📋 복붙 캡처** 클릭.

**기대:**
- 단계 추가: `복붙: 원본!A1:E6 → 대상!A1`
- **대상** 시트에 표가 그대로 들어가고, `대상!D2`가 `=B2*C2`(수식) 로 보존됨.

## 케이스 3 — 저장 후 전체실행 재현
1. 케이스 1·2를 캡처해 단계가 쌓인 상태에서 **💾 스킬 저장**.
2. **↻ 초기화** 후 `v059_복붙캡처.xlsx` 다시 업로드 → **📂 스킬 불러오기**.
3. **▶ 전체 실행**.

**기대:**
- 알림음/디버그창/“매크로 실행 불가” **없이** 실행 완료(복붙은 Python COM 경로라 VBA 러너 미사용).
- `G1:K6`, `대상!A1:E6`이 케이스 1·2와 동일하게 재현되고 **수식 보존**.

## 케이스 4 — 교차파일 복붙 (파일 A → 파일 B)
1. `v059_복붙캡처.xlsx` 와 `input_원가_2026_4월.xlsx`(또는 아무 입력)를 **둘 다 업로드**.
2. `input_원가…`(파일 A) 의 한 범위를 **Ctrl+C** → `v059_복붙캡처.xlsx`(파일 B) 의 빈 곳을 클릭 → **Ctrl+V** → **📋 복붙 캡처**.

**기대:**
- 단계 설명에 **(교차파일)** 표시: `복붙: <파일A시트>!<범위> → <파일B시트>!<셀> (교차파일)`.
- 파일 B에 값/수식 보존되어 붙음.
- **전체실행 재현 시 소스 파일(A)이 닫혀 있어도** 업로드된 파일에서 자동으로 읽어 재현된다(소스를 읽기전용으로 잠깐 열고 닫음).

> 라이브 편집 파일들은 한 Excel 프로세스에 함께 열리므로 교차파일 복사가 성립한다. 만약 소스가 그 인스턴스에 없으면 업로드 경로에서 자동으로 연다.

## 케이스 5 — 셀 삭제 캡처 (🗑 셀 삭제 캡처)
1. **원본** 시트에서 `B2:C5`(단가·수량 영역)를 드래그 → **Delete**(값/수식 지워짐).
2. 곧바로 **🗑 셀 삭제 캡처** 버튼 클릭.

**기대:**
- 단계 추가: `셀 삭제: 원본!B2:C5`
- `B2:C5` 값이 비고, `D2`의 금액 수식 `=B2*C2`는 **그대로**(서식·인접 수식 보존, 선택 범위만 비움).
- 저장 → 초기화/재업로드 → 불러오기 → **전체 실행** 시 `B2:C5`가 다시 비워져 동일 재현.

> 팁: Delete 를 누르지 않고 **범위를 선택만 한 상태**에서 버튼을 눌러도 그 범위를 비우는 단계로 저장된다(버튼이 곧 "이 범위 비우기" 캡처).

## 합격 기준
- [ ] 복붙 캡처 버튼이 `복붙: <소스> → <대상>` 단계를 정확히 추가한다(범위/시트/파일 정확).
- [ ] 붙여넣은 금액/합계 셀이 **값이 아니라 수식**으로 보존된다.
- [ ] 셀 삭제 캡처 버튼이 `셀 삭제: <시트>!<범위>` 단계를 추가하고, 선택 범위만 비운다(인접 수식·서식 유지).
- [ ] 전체실행 재현 결과가 수동 동작 결과와 동일하다.
- [ ] 전체실행 중 “매크로를 실행할 수 없습니다”/디버그창이 **뜨지 않는다**.

## 주의 / 한계
- **붙여넣기 직후 곧바로** 📋 복붙 캡처를 누를 것. 그 사이 다른 것을 복사하거나 Esc 를 누르면 소스 정보가 사라져 캡처 실패한다.
- **일반 Ctrl+V(전체 붙여넣기)** 기준. "선택하여 붙여넣기 > 값만" 등 PasteSpecial 종류 구분은 아직 미지원(전체로 캡처됨).
- 붙여넣을 때 **단일 셀(기준점)** 또는 **소스와 같은 크기의 범위** 선택이면 정상 캡처된다. 소스와 **다른 크기의 다중 셀**을 선택한 채 누르면 "크기가 다르다" 경고 후 저장하지 않는다(오캡처 방지).
- 셀 삭제 캡처는 선택 범위의 **값/수식만 삭제(서식 유지)** = `ClearContents`. 서식까지 지우거나 행/열 삭제는 별도 동작(미포함).
- **비연속 다중 영역(Ctrl-클릭으로 떨어진 여러 묶음 선택) 복사는 캡처 거부**된다("여러 영역을 한꺼번에..." 안내). 한 영역(연속 범위/열 전체/행 전체)씩 복사·붙여넣기 할 것.
- 전체 열/행 복붙은 대상 열/행 ∩ 기존 데이터(UsedRange)만 롤백 백업한다 → 기존에 있던 데이터는 되돌리기로 복원되지만, **원래 비어 있던 칸에 새로 채워진 값은 되돌리기로 지워지지 않는다**(전체실행 reset 은 원본부터라 무관).
- 교차파일은 소스 파일이 **업로드(등록)** 돼 있으면 재현된다(전체실행 때 소스가 닫혀 있어도 자동으로 읽기전용으로 열어 복사). 단, 소스의 *저장 안 된* 라이브 편집분은 같은 인스턴스에 열려 있을 때만 반영된다(자동 열기 경로는 디스크 저장본 기준).
