# 시나리오 v0.5.10 — 텍스트 내 월/날짜 증감(+N개월)

## 배경 / 신고
"26년 06월 (05월 1일 ~ 05월 31일) 요금확정 내역" 셀에서 "월정보를 +1 해줘" → "26년 07월 (05월 1일 ~ 05월 31일) ..."
처럼 **첫 월(06월)만** 바뀌고 괄호 안 05월들은 안 바뀜. 또 여러 셀 중 첫 셀만 바뀜. (VBA 경로)

## 기대 동작 (사용자 확정)
- 한 셀 안의 **모든 'N월' 토큰을 +N**.
- **연도 넘김**: 12월 +1 = 다음 해 01월, 앞의 YY년/YYYY년도 +1.
- **말일 보정**: 옮긴 달에 없는 날짜는 그 달 말일로 내림(늘리지 않음, 윤년 02월 고려).
- **대상 범위의 모든 셀**에 적용.

## 테스트 시트
`test_data/v0510_월정보_증감.xlsx` (시트 `요금내역`, A열)

| 셀 | 입력 | "월정보 +1" 기대 결과 |
| --- | --- | --- |
| A2 | 26년 06월 (05월 1일 ~ 05월 31일) 요금확정 내역 | 26년 07월 (06월 1일 ~ 06월 30일) 요금확정 내역 |
| A3 | 26년 12월 (11월 1일 ~ 11월 30일) 요금확정 내역 | 27년 01월 (12월 1일 ~ 12월 30일) 요금확정 내역 |
| A4 | 26년 01월 (12월 1일 ~ 12월 31일) 요금확정 내역 | 26년 02월 (01월 1일 ~ 01월 31일) 요금확정 내역 |
| A5 | 2026년 02월 (01월 28일 ~ 01월 31일) 사용내역 | 2026년 03월 (02월 28일 ~ 02월 28일) 사용내역 |
| A6 | 6월 매출 요약 | 7월 매출 요약 |

참고(말일 보정 경계): A3의 "11월 30일"은 30일이 12월에도 존재하므로 그대로 30일(31일로 늘리지 않음). A5는 2026년 02월=28일(비윤년)이라 31일/28일 모두 28일로 내려감. (2024년처럼 윤년이면 29일.)

## 검증 절차
1. 위 시트를 업로드하고 A2:A6 을 선택.
2. "선택 범위의 월 정보를 +1 해줘" 요청 → VBA 스킬 생성/적용.
3. A2~A6 결과가 위 "기대 결과"와 정확히 일치하는지 확인.
4. **회귀 포인트**: (a) 한 셀 안의 모든 월이 바뀌는가(첫 월만 X), (b) A2~A6 전부 바뀌는가(첫 셀만 X), (c) A3 연도 26→27, (d) A2/A5 말일 보정.

## 근거
프롬프트 규칙/헬퍼: `scripts/file-schema.js` VBA_SYSTEM_PROMPT 의 "텍스트 내 '월/날짜' 증감" 섹션(`ShiftMonthsInText`/`DaysInMonth`).
알고리즘 검증: VBA 충실 미러 7/7 통과(예시 + 12월 롤오버 + 윤년/비윤년 + 비패딩 + delta=+2).
