## A. 회사별 매출 합계 (1D 그룹요약 → 목표: ctx.pivot)
요청: `매출 시트를 회사별 매출 합계로 요약해줘`
기대: 새 시트에 요약표, 값:

| 회사 | 매출 합계 |
| --- | ---: |
| 가 | 470 |
| 나 | 670 |
| 다 | 80 |

기대 코드(목표): `def transform(ctx): ctx.pivot("매출", group_by="회사", value="매출", agg="sum", dest_name="회사별합계")`
검증: 합계 총합 1220, 원본 시트 보존, (옮긴 뒤엔) Python 라우팅.

## B. 지점별 건수 (count)
요청: `지점별 건수를 세줘`
기대: 서울 = **4**, 부산 = **4**. (agg="count")

## C. 월별 매출 평균 (avg)
요청: `월별 매출 평균 내줘`
기대: 1월 = **132.5**, 2월 = **172.5**. (agg="avg")

## C-2. 사업자번호별 합계 — 식별자(선행 0) 보존
요청: `사업자번호별 매출 합계 요약해줘`
기대: 그룹 키가 **"001" / "002" / "010"** 로 **선행 0 유지**(숫자 1/2/10 로 깨지면 안 됨), 합계:

| 사업자번호 | 매출 합계 |
| --- | ---: |
| 001 | 470 |
| 002 | 670 |
| 010 | 80 |

검증 포인트: 그룹 키 선행 0 보존(원래 VBA를 둔 이유가 '식별자 보존'이었음 — ctx.pivot 으로도 보존돼야 함).

---

## D. 2D 크로스탭 (행=지점, 열=월, 값=매출 합계) → VBA 유지
요청: `행은 지점, 열은 월로, 값은 매출 합계인 피벗표 만들어줘`
기대(크로스탭):

| 지점 \ 월 | 1 | 2 |
| --- | ---: | ---: |
| 서울 | 400 | 420 |
| 부산 | 130 | 270 |

검증 포인트: ctx.pivot 은 1차원 그룹요약만 되므로 **이건 VBA**로 처리(또는 수기 Dictionary 2중 집계). 총합 1220.

---

## 판단 기준
- A/B/C/C-2(1D 그룹요약)가 **VBA로 짤 때 자주 틀리면**(Dictionary 집계 오류·선행0 깨짐 등) → ctx.pivot(Python)으로 옮기는 게 이득.
- D(2D 크로스탭)는 ctx.pivot 불가라 VBA 유지가 맞음.
- "vba로 / python으로" 명시하면 그 엔진 최우선.
