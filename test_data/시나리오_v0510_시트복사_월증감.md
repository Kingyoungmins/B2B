# 시나리오 v0.5.10 — 월/날짜 증감 + 시트복사(같은/교차파일) + 시트작업·정렬

이번 세션(2026-06-23) 수정분 수동 검증용. **먼저 앱 + 서버를 재시작**하세요(프런트 JS + serve_b2b 둘 다 바뀜).
핵심: 이 작업들은 모두 **Python(ctx 헬퍼)** 으로 라우팅돼야 합니다(채팅 입력칸 위 라벨이 "(Python 라우팅)").
모델이 한글 파일명/시트명/정규식에 공백을 끼워도 **공백 무시 매칭**으로 동작해야 합니다.

## A. 월/날짜 증감 (ctx.shift_months) — 신고 케이스 재현
파일: `월증감_요금정산_2026년.xlsx` (시트명 **2026년**)

1. 업로드 후 시트 "2026년"에서 **B2:D3** 선택(또는 실제 신고 위치 **B336:D336**).
2. 요청: `선택 범위의 월 정보를 +1 해줘`
3. 기대: 생성 코드가 `def transform(ctx): ctx.shift_months("2026년", "B2:D3", 1)` 형태(직접 정규식 X), 결과:

| 입력 | 기대 결과 (+1) |
| --- | --- |
| 2026년 06월 (05월 1일 ~ 05월 31일) 요금확정 내역 | 2026년 07월 (06월 1일 ~ 06월 30일) 요금확정 내역 |
| 2026년 12월 (11월 1일 ~ 11월 30일) 청구 내역 | 2027년 01월 (12월 1일 ~ 12월 30일) 청구 내역 |
| 2026년 01월 (12월 1일 ~ 12월 31일) 정산 내역 | 2026년 02월 (01월 1일 ~ 01월 31일) 정산 내역 |
| 2024년 02월 (01월 31일 ~ 01월 31일) 사용내역 | 2024년 03월 (02월 29일 ~ 02월 29일) 사용내역 (윤년) |
| 2026년 02월 (01월 28일 ~ 01월 31일) 사용내역 | 2026년 03월 (02월 28일 ~ 02월 28일) 사용내역 |
| 6월 매출 요약 | 7월 매출 요약 |

**검증 포인트**: ① 한 셀 안의 **모든 'N월'** 이 바뀜(첫 월만 X), ② 12월→다음 해 01월(연도 +1), ③ 말일 보정(31→30/29/28),
④ 선택한 셀 **전부** 바뀜, ⑤ 시트명 "2026년"을 못 찾는 오류가 안 남(공백 끼어도 매칭). "-1 해줘"(지난달)도 확인.

## B. 같은 파일 시트복사 / 복사후 이름변경
파일: `시트작업_샘플.xlsx` (시트: 데이터, 청구금액)

- `데이터 시트 복사해줘` → `ctx.copy_sheet("데이터")` 로 같은 파일에 사본 생성(Python).
- `데이터 시트 복사해서 이름을 백업으로 바꿔줘` → `ctx.copy_sheet("데이터", new_name="백업")`.

**검증 포인트**: VBA 아님(Python 라우팅), 원본 서식/내용 보존, 사본 생성됨.

---

## C. 교차파일 시트복사 (신고 케이스 재현)
파일 **2개 모두 업로드**: `시트복사_원본.xlsx` + `시트복사_대상_기업DW추출(마스킹).xlsx`

1. 요청: `트래픽_데이터 시트복사해서 @파일[시트복사_대상_기업DW추출(마스킹).xlsx] 에 추가해줘`
2. 기대: 생성 코드 `def transform(ctx): ctx.copy_sheet("트래픽_데이터", dst_book="시트복사_대상_기업DW추출(마스킹).xlsx")` (Python).
3. 결과: **대상 파일**에 "트래픽_데이터" 시트가 추가됨. 원본은 그대로.

**검증 포인트**: ① "워크북 ... 이 열려 있지 않습니다" 오류가 **안 남**(모델이 파일명에 공백을 끼워도 `ctx.book` 정규화 매칭이 찾음),
② VBA 아님(Python). ③ 복사 후 이름 지정: `... @파일[...]에 복사하고 이름 트래픽_백업으로` → `new_name="트래픽_백업"`.

## D. 시트 이름변경 / 추가 / 삭제
파일: `시트작업_샘플.xlsx`

- `청구금액 시트 삭제해줘` → `ctx.delete_sheet("청구금액")` (Python). "데이터 삭제"가 아니라 **시트 자체** 삭제임에 주의.
- `데이터 시트 이름을 원장으로 바꿔줘` → `ctx.rename_sheet("데이터", "원장")`.
- `검증 시트 새로 추가해줘` → `ctx.add_sheet("검증")`.

**검증 포인트**: 전부 Python(ctx). "변경 없음" 오류로 막히지 않음(해당 검증 로직은 제거됨).

---

## E. 정렬 (ctx.sort)
파일: `시트작업_샘플.xlsx` 시트 "데이터" (회사/월/매출, 1행 헤더)

- `데이터 시트를 회사 기준으로 정렬해줘` → `ctx.sort("데이터", ..., key_col="회사", has_header=True)` (Python).
- `월 오름차순으로 정렬해줘` → key_col="월".

**검증 포인트**: 헤더(1행)가 정렬에 휩쓸리지 않음, Python(ctx.sort) 사용(수기 파이썬 정렬 X).
