B2B 빌링 Agent — 업데이트 안내 (0.6.1)
====================================================

[ 고친 점 / 바뀐 점 ]
----------------------------------------------------

● 전체실행이 중간에 실패했을 때 '적용됨' 표시가 실제와 정확히 일치해요
   - 예: 6단계 스킬 실행 중 5단계에서 오류가 나면 1~4단계가 '적용됨'으로 표시되는데,
     여러 파일을 다루는 스킬에서는 실제 Excel 에 반영이 안 돼 있는 경우가 있었습니다
     (실패 시 되돌리기가 오류 난 파일 하나만 복원하면서 표시는 전부 '적용됨'으로 남던 문제).
   - 이제 실패 시점의 '관여 파일 전체' 상태를 저장해 두었다가 모든 파일을 그 상태로 복원하고,
     복원이 전 파일에서 확인된 경우에만 '적용됨'을 표시합니다. 복원이 안 된 경우에는
     '적용됨'을 표시하지 않아, 화면과 실제 Excel 이 어긋나지 않습니다.
   - 이전 실행의 낡은 복원 지점이 남아 잘못 복원되던 경우도 함께 막았습니다.

● 클릭이 두 번 실행되거나, Ctrl+클릭 다중선택이 안 되던 문제를 고쳤어요
   - 버튼을 조금 오래 누르고 있으면 같은 동작이 두 번 실행되는 경우가 있었습니다.
   - 시트 탭 등에서 Ctrl(또는 Shift)+클릭으로 여러 개를 고를 때 하나만 선택되던 문제,
     '값만' 같은 체크박스가 원격 환경에서 안 켜지던 문제를 고쳤습니다.
   - 키보드 Enter 로 누르는 버튼이나 화면 구분선(좌우 너비 조절) 드래그가 오작동하던 것도
     함께 고쳤습니다.

● '작업 중단'이 정상 작업을 성급히 끊어버리던 문제를 고쳤어요
   - 되돌리는 작업이 오래 걸릴 뿐인데도 10초가 지나면 무조건 Excel 을 강제 재시작해서,
     느린 PC 에서는 멀쩡한 작업까지 통째로 다시 시작되곤 했습니다.
   - 이제 '시간'이 아니라 '진행 여부'로 판단합니다. 진행 중이면 끝까지 기다리고, 정말로 멈춘
     경우에만 강제 중단합니다. (급할 때 '작업 중단'을 한 번 더 누르면 즉시 강제 중단됩니다.)
   - 강제 중단 뒤 스킬이 자동으로 다시 적용되지 못한 경우, 예전에는 화면만 '적용됨'으로 남아
     이후 계산이 조용히 틀릴 수 있었습니다. 이제 적용 표시를 정확히 풀고 안내합니다.

● 다른 달 파일을 이어 쓸 때 엉뚱한 파일에 실행되던 문제를 고쳤어요
   - 지난달·이번달 파일을 함께 올리면 실행기가 '먼저 올린 지난달 파일'을 조용히 골라
     실행하는 경우가 있었습니다. 이제 어느 것인지 확실하지 않으면 직접 고르도록 물어봅니다.
   - 월·날짜만 다른 파일을 자동으로 이어붙인 경우, 초록색 '정확 매칭'이 아니라
     '확인 필요(다른 달 추정)'로 표시해 한 번 확인하실 수 있게 했습니다.
   - 파일명에 들어간 거래처코드·지점번호(예: 500255, 지점 105)를 날짜로 착각해 서로 다른
     파일을 같은 파일로 취급하던 문제, 'hardcopy' 같은 이름 끝이 잘리던 문제도 고쳤습니다.

● 여러 파일을 다루는 스킬에서 시트가 중복으로 쌓이던 문제를 고쳤어요
   - 다른 파일로 시트를 복사하는 스킬을 '적용' 후 '전체실행' 하면 실행할 때마다
     '원가 (2)', '원가 (3)' 처럼 시트가 계속 늘어나는 경우가 있었습니다.
   - 단계를 끄거나 지우거나, 되돌리기(Ctrl+Z)를 했을 때 붙여넣은 시트가 안 지워지던 경우도
     함께 고쳤습니다.

● 프로그램 종료 시 Excel 이 백그라운드에 남던 경우를 줄였어요
   - 파일이 여러 개 열려 있거나 정리가 오래 걸리면 보이지 않는 Excel 이 남을 수 있었습니다.
   - 정리를 끝까지 기다린 뒤 종료하도록 고쳤습니다(창은 즉시 사라져 체감은 그대로입니다).
