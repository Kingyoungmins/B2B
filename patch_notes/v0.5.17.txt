B2B 빌링 Agent — 업데이트 안내 (0.5.16 → 0.5.17)
====================================================

이번 0.5.17은 "전체 실행한 결과를 불러와 이어서 작업할 때" 생기던 문제를 바로잡은 업데이트입니다.


[ 고친 점 ]
----------------------------------------------------

● 전체 실행 결과를 불러와 이어서 단계를 만들 때 파일·시트를 못 찾던 문제를 고쳤어요  ★
   - 전체 실행을 마치고 "결과 편집하기"로 결과를 불러오면, 파일 이름 뒤에 자동으로 붙는
     관리용 표시(예: 결과_..._날짜)가 실제 파일 이름처럼 잡혀서, 채팅에서 @로 파일/시트를
     골라도 "그 파일을 못 찾는" 일이 있었습니다.
   - 이제 결과를 불러와도 파일은 원래 이름 그대로 유지되어, @ 지정과 단계 추가가 정상 동작합니다.
   - 예) 30단계 스킬을 만들다가 15단계까지 하고 전체 실행 → 다음 날 결과를 불러와 16단계부터
     이어서 만들기가 문제없이 됩니다.

● 이어서 만든 스킬의 전체 실행도 안정적이에요
   - 위 문제로 어긋났던 파일 이름이 바로잡혀, 저장한 스킬을 처음부터 전체 실행할 때도
     끝까지 정확히 실행됩니다.

● 여러 파일을 다루는 스킬은 결과 편집 시 '방금 바뀐 파일'이 항상 보여요
   - 여러 파일을 함께 처리하는 스킬을 전체 실행한 뒤 "결과 편집하기"를 누르면, 마지막 단계가
     바꾼 파일(예: 새 시트를 추가한 파일)이 화면에 확실히 표시됩니다. 이전에는 어떤 파일이
     보일지 실행마다 달라져 방금 만든 변화가 "보였다 안 보였다" 하던 문제를 고쳤습니다.

● 셀에 값을 채우는 단순 작업이 더 정확하게 처리돼요
   - "○○ 열/셀에 값을 채워줘"처럼 계산·조건 없이 값만 넣는 요청이 더 안정적인 방식으로
     처리되도록 개선했습니다. (매칭·조건·합계·행 삭제 같은 복잡한 작업은 기존 방식 그대로예요.)

● 시트 이름 바꾸기도 더 안정적으로 처리돼요
   - "이 시트를 3월로 바꿔줘", "시트 이름을 2026년 5월로 변경"처럼 '이름'이라는 말을 안 붙이거나
     새 이름이 길어도 올바르게 인식되도록 개선했습니다.

● @로 파일·시트를 고를 때 목록이 간결해졌어요
   - @ 자동완성 목록에 컬럼(열 이름)은 더 이상 나오지 않고, 파일과 시트만 보입니다.
     (필요하면 @컬럼[...] 을 직접 입력하는 방식은 그대로 동작합니다.)

● 병합된 셀이 있는 표에서 '열 옮기기'가 안정적으로 처리돼요
   - 제목/헤더가 병합된 표에서 "○○ 열을 △△ 앞으로 옮겨줘"처럼 열을 이동·재배치·맞바꾸는 작업이
     "병합된 셀에서는 실행할 수 없습니다" 오류 없이 정확히 처리되도록, 검증된 안전한 방식으로
     실행되게 개선했습니다.
