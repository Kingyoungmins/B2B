B2B 빌링 Agent — 업데이트 안내 (0.7.0 — 0.6.1.1 포함 통합본)
====================================================

이번 업데이트는 새 기능 '화면 녹화(beta)' 와 그 안정화 작업,
그리고 0.6.1.1 의 'AI 도움' 도우미·장시간 사용 안정화·0.6.1 개선 사항이
하나로 모두 들어 있습니다.


[ 새 기능 — 화면 녹화 (0.7.0, beta) ]
----------------------------------------------------

● 엑셀에서 직접 한 작업을 '녹화'해 스킬로 만들 수 있어요
   - 오른쪽 실제 Excel 화면에서 [● 녹화(beta)] 를 누르고 평소처럼 입력·복사/붙여넣기·
     서식·자동채우기·새 시트 만들기 등을 하신 뒤 [■ 녹화 정지] 를 누르면,
     방금 한 작업들이 스킬 단계로 만들어집니다. 채팅으로 설명하지 않아도 됩니다.

● 한 번의 녹화가 '동작 단위'로 잘게 나뉘어요
   - 예: 값 입력 · 복사/붙여넣기 · 합계 수식 · 자동채우기를 이어서 하면,
     각각이 별도 단계로 나뉘어 나중에 단계별로 켜고/끄거나 수정할 수 있습니다.

● 다음 달·다음 파일에서 확인이 필요한 단계는 다른 색으로 표시해요
   - 녹화에 '3월', '1분기' 같은 월·날짜 값이 들어가면, 그 단계는 보라색으로 표시되고
     "다음 달 재현 시 값 확인 필요" 안내가 붙습니다. 재사용 전에 놓치지 않게 하기 위함입니다.

● 녹화 재현이 중간에 막혀도, 사용자가 손대지 않아도 끝까지 완료돼요
   - 녹화한 작업을 다시 실행하다 한 단계가 실패하면, 프로그램이 자동으로 그 단계를
     안전한 방식으로 다시 만들어 이어서 실행합니다(사용자가 버튼을 누를 필요 없음).
   - 자동 복구가 끝나면 '녹화 시점 결과'와 지금 결과가 같은지 자동으로 대조해,
     일치하면 "녹화와 일치" 로 알려 드립니다(다르면 어느 시트가 다른지 짚어 줍니다).

  ※ 화면 녹화는 아직 beta 입니다. 복잡한 녹화(피벗 등)는 결과를 한 번 확인해 주세요.


[ 화면 녹화 안정화 (0.7.0) ]
----------------------------------------------------

● 녹화 중 '다른 파일로 복사해 붙여넣기'가 제대로 기록·재현돼요
   - 한 파일에서 복사한 뒤 다른 파일 탭으로 넘어가 붙여넣는 동작이, 탭을 옮기는 순간
     복사가 풀려 붙여넣기가 안 되던 문제를 고쳤습니다. 이제 파일을 넘나드는 복사/붙여넣기가
     녹화되고 재현됩니다.

● 긴 녹화도 단계로 잘 나뉘어요
   - 동작이 많은 긴 녹화가 '한 단계'로만 나오거나, 분할이 도중에 끊겨 실패하던 문제를
     고쳤습니다(중간 대기 제한을 없애 끝까지 기다립니다).

● 녹화한 합계·수식이 '실제 마지막 행'에 정확히 들어가요
   - 여러 단계가 이어서 합계 행을 만들 때, 서로 위치 기준이 어긋나 합계 라벨과 숫자가
     한 줄씩 밀리거나 엉뚱한 칸에 들어가던 문제를 고쳤습니다.

● 녹화한 작업이 항상 '올바른 파일'에서 실행돼요
   - 녹화를 어느 파일에서 시작했는지가 재현할 때 헷갈려, 첫 동작이 엉뚱한 파일에서
     실행되던 경우를 고쳤습니다.

● 녹화를 눌러도 NumLock 이 꺼지지 않아요
   - 녹화를 시작할 때 키패드 잠금(NumLock)이 함께 꺼지던 문제를 고쳤습니다.

● 녹화 중에는 '복붙 캡처' 버튼이 잠겨요
   - 녹화는 복사/붙여넣기까지 함께 기록하므로, 녹화 중 복붙 캡처를 누르면 같은 동작이
     두 번 들어갔습니다. 이제 녹화 중에는 캡처 버튼이 잠깁니다(정지 후 이용).

● 녹화 정지 후 파일 전환이 막히거나, 녹화 버튼이 안 눌리던 문제를 고쳤어요
   - 재현이 실패한 뒤 파일 탭을 눌러도 아무 반응이 없거나, 녹화를 다시 누르면 "파일을
     열어 주세요" 로 막히던 경우를 고쳤습니다(끊긴 연결을 자동으로 다시 엽니다).
   - 재현이 완전히 실패하면 '녹화 정지 시점'으로 화면을 되돌려 작업이 사라지지 않게 했습니다.

● 저장한 녹화 스킬이 실행기에서 '올바른 파일만' 요구해요
   - 저장 시점의 실제 파일·시트 목록을 스킬에 함께 담아, 실행기에서 스킬이 요구하는 파일을
     이 목록과 대조합니다. 그 결과 '알 수 없는 이름'을 요구하거나, 엉뚱한 파일/시트를
     요구하던 문제가 줄었습니다(구버전 스킬은 기존 방식대로 동작합니다).

● 안전장치
   - 녹화·재생 과정에서 실행 PC 의 다른 파일을 열거나 저장·삭제하는 위험한 동작은
     실행 전에 차단합니다(문제가 되는 단계는 미리 알려 드립니다).


[ 새 기능 — AI 도움 (0.6.1.1) ]
----------------------------------------------------

● 'AI 도움' 도우미가 생겼어요
   - 화면 왼쪽 위(프로그램 제목 옆)의 [✦ AI 도움] 버튼을 누르면 별도 창이 열립니다.
   - 프로그램 사용법이나 현재 스킬/실행 상태에 대해 자유롭게 물어볼 수 있고,
     실행이 실패했을 때 "방금 왜 실패했어?"라고 물으면 실제 오류 기록을 읽어
     어느 단계가 왜 막혔는지 쉬운 말로 설명해 줍니다.
   - AI 도움은 스킬을 마음대로 바꾸지 않습니다. 코드 수정이 필요한 경우에는
     바꿀 내용을 카드로 보여 주고, 사용자가 확인을 눌러야만 반영됩니다.

● 실패 진단이 '실제로 어느 파일에서 무슨 일이 있었는지'까지 봐요
   - 오류 메시지만으로 부족하면, 실행이 실제로 어느 파일·순서로 진행되다 어디서 멈췄는지
     기록을 읽어 원인을 더 정확히 짚습니다(특히 녹화 스킬 진단에 유용합니다).

● 실패 진단이 '다음에 할 일'까지 안내해요
   - 오류 원인 설명에서 끝나지 않고, 상황에 맞는 구체적 행동
     (오류 카드 메모칸에 적을 문장 예시 + [에러 복구 시도] 버튼 안내,
      또는 요청을 어떻게 바꿔 말하면 되는지)으로 끝맺습니다.

● 큰 작업은 단계별로 나눠서 설계 채팅에 넣어 줘요
   - "이 절차를 단계별로 만들어줘" 같은 여러 단계 작업을 부탁하면,
     단계마다 [이 단계 설계 채팅에 넣기] 버튼이 있는 카드로 나눠 줍니다.
     1번부터 순서대로 넣고 확인·전송하면 스킬이 한 단계씩 만들어집니다.

● 파일명·시트명을 지어내지 않아요
   - AI 도움이 확인하지 않은 파일/시트/열 이름을 추측으로 말하던 것을 막았습니다.
     모르면 먼저 조회 도구로 확인하고, 확인이 안 되면 그렇다고 밝힙니다.

● AI 도움 창이 열리지 않던 문제를 고쳤어요
   - 실행파일(단일 exe)에서 AI 도움 창이 빈 화면으로 뜨거나 열리지 않을 수 있던
     포장 누락을 바로잡았고, 프로그램이 바쁠 때 창이 늦게 떠서 상태가 꼬이던
     문제도 함께 고쳤습니다.


[ 장시간 사용 안정화 (0.6.1.1) ]
----------------------------------------------------

● 아무 작업을 안 해도 사용 자원(메모리)이 조금씩 늘던 문제를 고쳤어요
   - 프로그램은 백그라운드에서 서버 연결 상태를 주기적으로 확인하는데, 그 응답을
     바로 정리하지 않아 아무 작업을 하지 않고 켜 두기만 해도 쓰는 자원(메모리·핸들)이
     천천히 계속 늘어났습니다(화면은 그대로라 눈에 잘 안 띄지만 오래 켜 둘수록 누적).
   - 이제 확인이 끝나면 응답을 즉시 정리해, 오래 방치해도 자원 사용량이 평평하게 유지됩니다.
     (워크북을 연 채로 1시간 넘게 방치해도 더는 늘지 않는 것을 실측으로 확인했습니다.)


[ 0.6.1 개선 사항 ]
----------------------------------------------------

● 전체실행이 중간에 실패했을 때 '적용됨' 표시가 실제와 정확히 일치해요
   - 예: 6단계 스킬 실행 중 5단계에서 오류가 나면 1~4단계가 '적용됨'으로 표시되는데,
     여러 파일을 다루는 스킬에서는 실제 Excel 에 반영이 안 돼 있는 경우가 있었습니다
     (실패 시 되돌리기가 오류 난 파일 하나만 복원하면서 표시는 전부 '적용됨'으로 남던 문제).
   - 이제 실패 시점의 '관여 파일 전체' 상태를 저장해 두었다가 모든 파일을 그 상태로 복원하고,
     복원이 전 파일에서 확인된 경우에만 '적용됨'을 표시합니다. 복원이 안 된 경우에는
     '적용됨'을 표시하지 않아, 화면과 실제 Excel 이 어긋나지 않습니다.
   - 이전 실행의 낡은 복원 지점이 남아 잘못 복원되던 경우도 함께 막았습니다.

● 단계마다 '스킬명' 버튼이 생겼어요
   - 단계 이름을 더블클릭으로 바꾸려면 여러 번 시도해야 열리는 경우가 있었습니다
     (실행 중 화면 갱신이 끼어들면 더블클릭 인식이 끊기고, 열린 입력칸도 사라지던 문제).
   - 이제 단계 이름 옆의 '스킬명' 버튼을 한 번만 누르면 바로 이름을 고칠 수 있고,
     실행 중 화면이 갱신돼도 입력칸이 닫히지 않습니다.
     (오른쪽의 ✎ 버튼은 기존처럼 '스킬 코드 수정'입니다. 더블클릭도 계속 동작합니다.)

● 스킬을 저장하면 '원래 이름' 그대로 저장돼요 (수정 후 저장한 스킬이 재사용 불가해지던 문제)
   - 파일을 연결(파일확인)해서 실행한 뒤 스킬을 수정하고 저장하면, 저장된 스킬에 그때 사용한
     파일명(날짜 포함)과 그 순간에만 유효한 내부 시트명이 통째로 박혀 버렸습니다.
   - 그 스킬을 다시 올리면 원래 이름과 박힌 이름이 둘 다 필요한 것처럼 잡혀 '파일확인'이
     갑자기 복잡해지고(필요 파일이 두 배로 늘어남), 다음 달 파일에는 쓸 수 없었습니다.
   - 이제 저장은 항상 원래(범용) 이름 기준으로 이뤄지고, 수정한 내용은 그대로 보존됩니다.
     실행이 끝난 뒤에도 스킬에 실행 당시 파일명이 남지 않습니다.

● 저장할 때 기본 이름이 예전 스킬명으로 고정되던 문제를 고쳤어요
   - 다른 작업(다른 파일)을 시작했는데도 스킬 저장 창에 예전에 쓰던 저장 이름이
     계속 기본값으로 나오던 문제입니다. 이제 입력 파일 구성이 달라지면 그 이름을
     기본값으로 쓰지 않습니다(같은 작업을 이어서 저장할 때는 기존처럼 기억합니다).

● 스킬을 '수정'했는데 새 단계로 추가되던 문제를 고쳤어요
   - 단계 수정(✎) 후 적용하면 그 단계가 고쳐지는 대신 맨 뒤에 새 단계로 붙어
     단계 수가 늘어나는 경우가 있었습니다(예: 25단계 스킬이 30단계가 됨).
   - 자동 재생성(안전 검사·오류 복구)을 거친 수정도 이제 제자리에서 교체됩니다.

● 실행기에서 '스킬 수정'을 바로 할 수 있어요
   - 실행기에 불러온 스킬을 편집하려면 프로그램을 오가야 했는데, 이제 '파일 수정/다운'과
     같은 방식으로 실행기 안에서 스킬을 제거·교체하고 단계를 편집할 수 있습니다.
   - 이 창에서 스킬을 삭제한 뒤 새 스킬(zip)을 올리면 실제로는 올라갔는데 목록에는
     안 보이던 표시 문제도 고쳤습니다.

● '파일확인'에서 지정한 파일 연결이 유지되고, 생성기 수정 후 실행에도 적용돼요
   - 실행기에서 파일을 직접 골라 연결(파일확인)한 뒤, 전체실행 → '결과 편집하기' → 스킬 수정 →
     다시 실행하면 "워크북 '...' 이 열려 있지 않습니다" 오류가 나던 문제를 고쳤습니다.
   - 원인 두 가지를 함께 고쳤습니다.
     (1) 연결 기록이 지워짐: 스킬 실행으로 시트가 새로 생기거나(결과 편집하기) 스킬 코드를
         한 글자만 고쳐도 직접 지정한 파일 연결이 초기화됐습니다. 이제 유지됩니다.
         (다른 스킬을 불러오거나 파일을 새로 올리면 예전처럼 다시 확인합니다.)
     (2) 수정 후 실행에 연결이 안 쓰임: 파일 연결은 실행기 실행 버튼에서만 적용됐습니다.
         이제 스킬 수정·켜고끄기 후 재실행에도 같은 연결이 적용됩니다.
   - 특히 '도서/시내'처럼 사람만 구분할 수 있는 파일은 자동으로 못 고르므로, 직접 지정한 연결이
     유지되는 것이 중요합니다. 저장된 스킬 코드는 원래대로 보존됩니다.

● 파일확인이 '필요 없는 파일/시트'를 요구하거나 엉뚱한 파일에 붙이던 문제를 고쳤어요
   - 스킬이 스스로 만들어내는 시트(중간 결과)를 '업로드해야 할 시트'로 잘못 요구하거나,
     소스+타겟 두 파일을 쓰는 스킬에서 시트 요구가 반대 파일에 붙던 문제를 고쳤습니다.
   - 파일명을 변수로 다루는 스킬(VBA/Python 모두)에서 대상 파일을 못 알아보던 경우도
     함께 고쳤습니다.
   - 조건식이 복잡한 필터 단계(람다 조건)가 만드는 시트를 '필수 업로드'로 잘못 요구하던 문제,
     시트 이름을 변수로 다루거나 파일명에 괄호가 들어간 경우("... (2).xlsx") 다른 파일의
     시트가 엉뚱한 파일 요구로 붙던 문제도 고쳤습니다.
   - 시트 선택 칸에 '스킬 기본값(그대로 실행)' 옵션이 생겨, 자동 바꿔치기가 오히려
     방해될 때 끌 수 있습니다.
   - 시트가 자동으로 매칭되지 않은 항목은 이제 '시트 선택'(선택 강요) 대신
     '스킬 기본값(그대로 실행)'이 기본으로 선택됩니다 — 실행이 막히지 않고, 스킬에 적힌
     시트명 그대로 실행됩니다(상태 표시는 '스킬 기본값(자동)'으로 구분).

● 파일확인의 시트 이름이 내부 임시 이름으로 보이던 문제를 고쳤어요
   - 일부 파일(다른 프로그램이 만든 .xls 등)의 시트가 "a1b2c3..._파일명" 같은
     내부 이름으로 표시되던 것을 실제 시트 이름으로 보이게 했습니다.

● 따옴표로 지정한 값은 '글자 그대로' 입력해요
   - 예: '시내/시외'라고 따옴표로 지정했는데 슬래시를 후보 구분으로 오해해
     '시내'만 넣는 식의 동작을 막았습니다. 쓸 값은 적어주신 그대로 들어갑니다.

● 피벗이 항상 '진짜 피벗테이블'로 만들어져요
   - 같은 피벗 명령인데 어떨 때는 진짜 피벗테이블(새로 고침 가능), 어떨 때는 값만 채운
     요약표가 만들어지던 문제가 있었습니다. 같은 피벗을 다시 만들면 2번째부터는 값 표로
     바뀌던 것이 원인이었습니다.
   - 이제 몇 번을 다시 만들어도 항상 진짜 피벗테이블입니다(같은 이름의 피벗 시트는 새로
     갱신됩니다). 만들 수 없는 경우에는 값 표로 몰래 바꾸지 않고 이유를 알려드립니다.

● 클릭이 두 번 실행되거나, Ctrl+클릭 다중선택이 안 되던 문제를 고쳤어요
   - 버튼을 조금 오래 누르고 있으면 같은 동작이 두 번 실행되는 경우가 있었습니다.
   - 시트 탭 등에서 Ctrl(또는 Shift)+클릭으로 여러 개를 고를 때 하나만 선택되던 문제,
     '값만' 같은 체크박스가 원격 환경에서 안 켜지던 문제를 고쳤습니다.
   - 키보드 Enter 로 누르는 버튼이나 화면 구분선(좌우 너비 조절) 드래그가 오작동하던 것도
     함께 고쳤습니다.

● '작업 중단'이 정상 작업을 성급히 끊어버리던 문제를 고쳤어요
   - 되돌리는 작업이 오래 걸릴 뿐인데도 10초가 지나면 무조건 Excel 을 강제 재시작해서,
     느린 PC 에서는 멀쩡한 작업까지 통째로 다시 시작되곤 했습니다.
   - 이제 '시간'이 아니라 '진행 여부'로 판단합니다. 진행 중이면 끝까지 기다리고, 정말로 멈춘
     경우에만 강제 중단합니다. (급할 때 '작업 중단'을 한 번 더 누르면 즉시 강제 중단됩니다.)
   - 강제 중단 뒤 스킬이 자동으로 다시 적용되지 못한 경우, 예전에는 화면만 '적용됨'으로 남아
     이후 계산이 조용히 틀릴 수 있었습니다. 이제 적용 표시를 정확히 풀고 안내합니다.

● 다른 달 파일을 이어 쓸 때 엉뚱한 파일에 실행되던 문제를 고쳤어요
   - 지난달·이번달 파일을 함께 올리면 실행기가 '먼저 올린 지난달 파일'을 조용히 골라
     실행하는 경우가 있었습니다. 이제 어느 것인지 확실하지 않으면 직접 고르도록 물어봅니다.
   - 월·날짜만 다른 파일을 자동으로 이어붙인 경우, 초록색 '정확 매칭'이 아니라
     '확인 필요(다른 달 추정)'로 표시해 한 번 확인하실 수 있게 했습니다.
   - 파일명에 들어간 거래처코드·지점번호(예: 500255, 지점 105)를 날짜로 착각해 서로 다른
     파일을 같은 파일로 취급하던 문제, 'hardcopy' 같은 이름 끝이 잘리던 문제도 고쳤습니다.

● 여러 파일을 다루는 스킬에서 시트가 중복으로 쌓이던 문제를 고쳤어요
   - 다른 파일로 시트를 복사하는 스킬을 '적용' 후 '전체실행' 하면 실행할 때마다
     '원가 (2)', '원가 (3)' 처럼 시트가 계속 늘어나는 경우가 있었습니다.
   - 단계를 끄거나 지우거나, 되돌리기(Ctrl+Z)를 했을 때 붙여넣은 시트가 안 지워지던 경우도
     함께 고쳤습니다.
   - 파일명에 괄호나 공백이 들어간 출력 파일(예: "output)_..." )로 시트를 복사하는 스킬은
     중간에 단계를 삽입하고 전체실행하면 시트가 또 추가되던 문제도 고쳤습니다.

● 복붙으로 만든 스킬이 실행기에서 '알 수 없는 파일'을 요구하던 문제를 고쳤어요
   - 복사/붙여넣기 캡처로 만든 단계가 실제 파일 이름 대신 내부 임시 이름(excel_open_... )을
     기억해 버려서, 필요한 파일을 모두 올려도 '파일 선택 필요' 2개가 사라지지 않고
     실행도 실패할 수 있었습니다.
   - 이제 캡처하는 시점부터 실제 파일 이름으로 저장되고, 예전에 저장해 둔 스킬도
     불러올 때 자동으로 고쳐집니다(파일확인 목록이 정상으로 돌아옵니다).

● '조건에 맞으면 처리'하는 스킬이 해당사항 없는 파일에서 오류로 멈추던 문제를 고쳤어요
   - 예: '소계 행이 있으면 삭제' 단계는 이번 달 파일에 소계가 아예 없으면 할 일이 없는 게
     정상인데, "아무 변경도 없습니다" 오류로 전체실행이 그 단계에서 중단됐습니다.
   - 이제 대상 시트의 데이터를 실제로 읽고 확인한 뒤의 '변경 없음'은 정상 완료로 처리합니다.
     (엉뚱한 시트를 읽어 아무것도 못 한 경우는 지금처럼 오류로 알려드립니다.)

● 파일확인에서 '스킬이 찾는 파일' 이름 앞부분이 잘려 보이던 문제를 고쳤어요
   - 파일명이 input)/output) 등으로 시작하고 중간에 공백(날짜·시각)이 있으면,
     마지막 조각(예: "10_02_56_DSMC_260713.xlsx")만 표시되던 문제입니다.
   - 표시만이 아니라 자동 매칭 점수에도 잘린 이름이 쓰였어서 함께 바로잡았습니다.

● 완료된 스킬을 수정해 재실행해도 결과에 반영되지 않을 수 있던 문제를 고쳤어요
   - '수정 직전 상태로 되돌리기'가 실패하면 수정된 코드가 실행되지 않았는데도
     '✓ 수정 적용됨'으로 표시돼, 옛 값 그대로인 산출물이 나갈 수 있었습니다.
     (특히 '빈 칸인 행만 채우기'류 단계는 이전 실행이 채워 둔 값이 남아 있으면
      할 일이 없다고 판단해 조용히 지나가므로 증상이 눈에 띄지 않았습니다.)
   - 이제 되돌리기에 실패하면 스킬 전체를 처음부터 다시 적용해 수정본을 반드시 반영하고,
     되돌릴 지점(스냅샷)이 불완전하면 빠른 이어실행 대신 전체 재적용을 택합니다.

● 프로그램을 최소화해도 Excel 창이 화면에 따로 남던 문제를 고쳤어요
   - 파일 업로드 직후나 '결과 편집하기' 직후에 최소화하면, 뒤늦게 열리던 Excel 창이
     프로그램 없이 화면에 혼자 떠 있는 경우가 있었습니다(위치 갱신이 창을 되띄우는 경우 포함).
   - 이제 최소화 중에는 어떤 경로로도 Excel 창이 화면에 나타나지 않고,
     창을 다시 열면 원래 자리(오른쪽 화면)로 함께 복귀합니다.
   - '결과 편집하기' 후 최소화하면 내용 없는 회색 Excel 창이 남던 경우도 함께 고쳤습니다
     (프로그램이 내부 작업용으로 띄운 Excel 이 목록에서 빠져 안 숨겨지던 문제 —
      직접 열어 두신 개인 Excel 창은 건드리지 않습니다).

● 스킬 저장/다운로드 시 '저장 위치 선택' 창이 안 뜨고 멈추던 문제를 고쳤어요
   - '스킬 저장'을 눌러 "다운로드 시작"까지 떴는데 폴더 선택 창이 나타나지 않아
     저장이 되지 않는 경우가 있었습니다(창이 Excel 화면 뒤에 가려져 안 보이던 문제 포함).
   - 이제 저장 창이 항상 맨 앞으로 떠서 위치를 고를 수 있고, 저장을 취소하거나 창을 열지
     못한 경우에는 그 사실을 알려 드립니다(예전에는 "다운로드 시작"만 뜨고 조용히 끝났습니다).

● 프로그램을 오래(예: 24시간) 켜 두면 점점 무거워지거나 버벅이던 문제를 고쳤어요
   - 채팅 답변이 한 글자씩 타이핑되는 효과가 답변을 다 그린 뒤에도 내부적으로 계속
     돌고 있었습니다. 채팅이 오류나 중단으로 끝나면 이 헛돌기가 꺼지지 않은 채 하나씩
     쌓여서, 프로그램을 오래 켜 둘수록 화면이 점점 무거워졌습니다.
   - 이제 답변을 다 그리면 스스로 멈추고, 오류/중단으로 끝난 경우에도 확실히 정지합니다.

● 프로그램 종료 시 Excel 이 백그라운드에 남던 경우를 줄였어요
   - 파일이 여러 개 열려 있거나 정리가 오래 걸리면 보이지 않는 Excel 이 남을 수 있었습니다.
   - 정리를 끝까지 기다린 뒤 종료하도록 고쳤습니다(창은 즉시 사라져 체감은 그대로입니다).

● 로그 파일이 무한정 쌓이지 않아요
   - 진단용 로그 일부가 재시작 후에도 계속 커지기만 했습니다. 이제 프로그램을 시작할 때
     정리되며, 문제 분석에 필요한 직전 실행 기록 1회분만 남깁니다.
