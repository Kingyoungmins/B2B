AX-Cell — 업데이트 안내 (0.7.5)
====================================================

이 문서는 0.7.3 이후에 바뀐 내용을 정리한 안내입니다
(중간 버전 0.7.4 의 내용도 여기에 함께 담았습니다).
이전 내용은 같은 폴더의 v0.7.3.txt 를 봐 주세요.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 스킬 적용이 예전 버전보다 눈에 띄게 느려졌던 문제를 고쳤습니다.
   전체실행·재적용 모두 원래 속도로 돌아왔습니다.
2) 오래 걸리는 작업(10분짜리 전체실행 등)이 3분쯤부터 멈춘 것처럼 보이던
   문제를 고쳤습니다. 이제 끝까지 진행 표시가 유지됩니다.
3) 마지막 단계 하나만 고쳤는데 전체를 다시 실행하는 것처럼 몇 분씩(실측 5분 5초)
   걸리던 문제를 고쳤습니다. 이제 그 단계만 다시 적용되어 몇 초면 끝납니다.
4) 단계의 [✎ 수정] 버튼이 "가장 최근에 고친 문장"을 기억합니다.
   스킬을 저장했다 불러와도 유지되고, 채팅에서도 정확한 위치로 이동합니다.
5) 보안문서(DRM)가 걸린 엑셀을 올리면 자동으로 풀어서 작업하고,
   내려받을 때 다시 보안을 걸어 줍니다. 사내 보안 형식 인식도 보강했습니다.
6) AI 서버 연결이 끊기면 예비 서버로 자동 전환합니다.
   사용 중 "응답이 없습니다"로 멈추는 일이 줄어듭니다.


────────────────────────────────────────────────────
[ 속도 — 느려졌던 것들이 제자리로 ]
────────────────────────────────────────────────────

● 스킬 적용 속도를 되돌렸습니다
   - 내부 검사 한 곳이 셀을 처리할 때마다 같은 준비 작업을 반복하고 있었습니다.
     한 번만 준비하도록 고쳐서, 실측으로 28배 빨라진 구간이 있습니다.

● 오래 걸리는 작업이 중간에 멈춘 것처럼 보이던 문제
   - 예전에 넣었던 안전장치가 오히려 3분이 지나면 진행 표시를 꺼 버리는
     부작용을 만들고 있었습니다. 그 장치를 걷어내고, 원인이었던 기록(로그)
     유실 문제를 근본에서 고쳤습니다.

● 마지막 단계만 고치면 그 단계만 다시 적용됩니다
   - 결과를 편집한 뒤 마지막 단계를 수정하면 1단계부터 전부 다시 도는
     경우가 있었습니다(실측 5분 5초). 이제 직전 상태로 되돌린 뒤
     그 단계만 다시 적용해 몇 초면 끝납니다.
   - 마지막 단계를 삭제한 직후 오른쪽 엑셀 화면이 회색으로 남아
     파일 탭을 눌러야 보이던 문제도 고쳤습니다(자동으로 다시 표시).


────────────────────────────────────────────────────
[ ✎ 수정 버튼 — 고친 문장을 기억합니다 ]
────────────────────────────────────────────────────

● 무엇이 달라졌나요
   - 예전에는 단계를 여러 번 고쳐도 [✎ 수정]을 누르면 맨 처음 입력했던
     문장이 나오는 경우가 있었습니다. 특히 스킬을 저장했다가 불러오면
     최근에 고친 문장이 사라졌습니다.
   - 이제 가장 최근에 고친 문장이 입력창에 채워지고, 저장/불러오기를
     거쳐도 유지됩니다. 채팅 기록에서도 그 문장의 말풍선으로 정확히
     이동합니다.


────────────────────────────────────────────────────
[ 보안문서(DRM) 자동 처리 ]
────────────────────────────────────────────────────

● 이렇게 동작합니다
   - 보안이 걸린 엑셀 파일을 올리면, 사내 보안 서버를 통해 자동으로 풀어서
     작업합니다. 원본 파일은 그대로 두고 작업용 복사본만 풉니다.
   - 결과를 내려받을 때는 다시 보안을 걸어서 내보냅니다.
     보안 서버에 연결할 수 없으면, 보안 없는 파일이 나가지 않도록
     다운로드를 멈추고 알려 드립니다(안전한 쪽으로 동작).

● 인식 범위를 넓혔습니다
   - 표준 방식(AIP 등)만 인식하고 일부 사내 보안 형식은 그냥 지나치던
     문제를 고쳤습니다. 이제 파일 이름이 아니라 내용으로 판별합니다.
   - 유니코드/한글 CSV 를 보안문서로 잘못 판단해 "보안 해제 실패" 안내가
     뜨던 오탐도 함께 고쳤습니다.


────────────────────────────────────────────────────
[ 스킬 생성 정확도 ]
────────────────────────────────────────────────────

● "값이 0인 행을 삭제해줘" 같은 행 삭제 요청
   - 예전에는 남길 행을 새 시트로 옮기고 원래 시트를 바꿔치기하는 방식의
     코드가 만들어질 때가 있었습니다. 이러면 보고 있던 화면이 깨지고
     시트 순서나 틀고정이 사라집니다(실사용 제보).
   - 이제 엑셀에서 행을 지우는 것(Ctrl+-)과 같은 "제자리 삭제" 방식으로
     만들어지고, 혹시 예전 방식의 코드가 나와도 적용 전에 걸러서
     자동으로 다시 만듭니다.


────────────────────────────────────────────────────
[ 연결 안정성 ]
────────────────────────────────────────────────────

● AI 서버 자동 전환
   - 메인 AI 서버와 연결이 끊기면 예비 서버로 자동 전환해 이어서 동작합니다.
   - 서버의 AI 모델이 교체되어도 자동으로 알아채고 맞춰서 요청합니다
     (예전에는 관리자가 설정을 바꿔 줘야 했습니다).


────────────────────────────────────────────────────
[ 관리자용 ]
────────────────────────────────────────────────────

● F9 관리 대시보드
   - F9 설정 창에 [📊 관리 대시보드] 버튼이 생겼습니다.
     누가 언제 얼마나 사용했는지, 어떤 오류가 있었는지 기간별/사용자별로
     조회하고, 해당 실행의 로그와 스킬 파일을 바로 내려받을 수 있습니다.

● 로그·스킬 자동 수집
   - 프로그램 사용 중 작동 기록(로그)과 만든 스킬 파일이 관리 서버에
     자동으로 쌓입니다. 문제를 제보하실 때 파일을 따로 보내지 않으셔도
     관리자가 바로 원인을 확인할 수 있습니다.
   - 엑셀 파일의 표 데이터 자체를 올리는 것은 아닙니다. 수집되는 것은
     프로그램 동작 기록과 스킬 구성(스킬을 만들 때 입력한 요청 문장 포함)입니다.
