B2B 빌링 Agent — 업데이트 안내 (0.6.0)
====================================================

[ 고친 점 / 바뀐 점 ]
----------------------------------------------------

● 원격(클라우드 PC · VDI) 환경에서 클릭이 잘 안 먹던 문제를 개선했어요
   - 원격 화면에서는 마우스를 '뗀' 신호가 간혹 중간에 사라져(측정상 열 번에 한 번꼴), 버튼을
     여러 번 눌러야 눌리던 현상이 있었습니다.
   - 이제 뗀 신호를 기다리지 않고 누르는 즉시 처리하도록 바꿔, 한 번에 바로 눌리도록 했습니다.
   - 일반 PC 에서도 클릭 동작은 그대로입니다(버튼이 두 번 실행되지 않게 처리했고,
     드래그·더블클릭·글자 입력에는 영향이 없습니다).
   - 원격 환경에서 증상이 계속되면, 마우스 리포트 속도(폴링)를 1000→125Hz 로 낮추거나
     유선 마우스 사용을 함께 권장합니다(신호 누락 자체가 줄어듭니다).

● (참고) 클릭 상태를 눈으로 확인하는 진단 화면을 넣었어요
   - F8 키를 누르면 우측 하단에 클릭 상태(누른/뗀/눌림 횟수, 신호 누락 및 즉시처리 횟수)가 표시됩니다.
   - 클릭이 안 먹는 원인을 지원팀이 빠르게 파악하는 용도이며, 평소 사용에는 영향이 없습니다.

● 프로그램을 켜 두기만 해도 마우스 커서가 주기적으로 '작업 중'(모래시계)으로 바뀌던 현상을 고쳤어요
   - 프로그램이 1초마다 하는 백그라운드 상태 점검이 보이지 않는 점검 프로그램을 매번 새로
     띄웠고, Windows 가 프로그램이 새로 뜰 때마다 '앱 시작 중' 커서를 잠깐 보여 주는 것이
     원인이었습니다.
   - 상태 점검을 프로그램을 새로 띄우지 않는 방식으로 바꾸고, 꼭 띄워야 하는 경우에도 커서가
     바뀌지 않도록 했습니다. 기능 동작에는 변화가 없습니다.
