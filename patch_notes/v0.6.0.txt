B2B 빌링 Agent — 업데이트 안내 (0.6.0)
====================================================

[ 고친 점 / 바뀐 점 ]
----------------------------------------------------

● 원격(클라우드 PC · VDI) 환경에서 클릭이 잘 안 먹던 문제를 개선했어요
   - 원격 화면에서는 마우스를 '뗀' 신호가 간혹 중간에 사라져(측정상 열 번에 한 번꼴), 버튼을
     여러 번 눌러야 눌리던 현상이 있었습니다.
   - 이제 뗀 신호를 기다리지 않고 누르는 즉시 처리하도록 바꿔, 한 번에 바로 눌리도록 했습니다.
   - 일반 PC 에서도 클릭 동작은 그대로입니다(버튼이 두 번 실행되지 않게 처리했고,
     드래그·더블클릭·글자 입력에는 영향이 없습니다).
   - 원격 환경에서 증상이 계속되면, 마우스 리포트 속도(폴링)를 1000→125Hz 로 낮추거나
     유선 마우스 사용을 함께 권장합니다(신호 누락 자체가 줄어듭니다).

● (참고) 클릭 상태를 눈으로 확인하는 진단 화면을 넣었어요
   - F8 키를 누르면 우측 하단에 클릭 상태(누른/뗀/눌림 횟수, 신호 누락 및 즉시처리 횟수)가 표시됩니다.
   - 클릭이 안 먹는 원인을 지원팀이 빠르게 파악하는 용도이며, 평소 사용에는 영향이 없습니다.

● 프로그램을 켜 두기만 해도 마우스 커서가 주기적으로 '작업 중'(모래시계)으로 바뀌던 현상을 고쳤어요
   - 프로그램이 1초마다 하는 백그라운드 상태 점검이 보이지 않는 점검 프로그램을 매번 새로
     띄웠고, Windows 가 프로그램이 새로 뜰 때마다 '앱 시작 중' 커서를 잠깐 보여 주는 것이
     원인이었습니다.
   - 상태 점검을 프로그램을 새로 띄우지 않는 방식으로 바꾸고, 꼭 띄워야 하는 경우에도 커서가
     바뀌지 않도록 했습니다. 기능 동작에는 변화가 없습니다.

● 실행기: "첫 시트 이름을 바꾸는" 스킬이 매핑 때문에 실패하던 문제를 고쳤어요
   - 스킬이 중간에 '만드는' 시트 이름(예: 첫 시트를 sheet1 로 변경)을 실행기 매핑이
     "올려준 파일에 있어야 할 시트"로 잘못 알고 실제 시트명으로 바꿔 넣어, 이름 길이 제한(31자)에
     걸려 실행이 중단되던 문제가 있었습니다(0.5.18에서는 되던 스킬이 0.5.19부터 실패).
   - 이제 스킬이 만들어내는 시트 이름은 매핑 대상에서 제외해 저장했을 때 그대로 실행됩니다.
   - 만약 31자를 넘는 시트 이름으로 바꾸려 해도 중단되지 않고 31자까지로 맞춰 계속 진행합니다.

● 실행기: 실행이 실패할 때 빈 Excel 창이 튀어나오던 문제를 고쳤어요
   - 실행기 전체실행이 중간에 실패하면 내부 작업사본 Excel 창(excel_open_...)이 화면에 뜨던
     문제를 막았습니다. 실행기 화면 안에서만 결과와 오류를 보여줍니다.

● 실행기: '시트 자동'이어도 시트를 직접 고를 수 있어요
   - 복사/붙여넣기 스킬이 실제로 쓰는 시트 이름을 이제 '파일확인'의 왼쪽에 그대로 보여줍니다
     (예전엔 '시트 자동'으로만 떠서 어떤 시트를 쓰는지 안 보였습니다).
   - 스킬이 시트를 이름으로 지정하지 않는 경우(첫/유일 시트 자동 사용)에도 [시트 자동] ↔
     [시트 선택] 짝을 보여줘, 실제로 어떤 시트가 쓰이는지 확인하고 직접 바꿀 수 있습니다.

● '작업 중단'이 어떤 상황에서도 끝까지 동작해요
   - 작업이 멈춘 상태에서 '작업 중단'을 누르면 중단 절차 자체가 "중단 중..."에서
     함께 멈춰버리는 경우가 있었습니다(되돌리기가 멈춘 작업 뒤에 줄을 서는 구조 문제).
   - 이제 10초 안에 정상 중단이 안 되면 자동으로 '초기화'와 같은 강제 중단으로 전환해,
     Excel 세션을 재시작하고 창을 다시 준비합니다. 어떤 경우에도 중단이 끝까지 진행됩니다.

● 스킬 수정할 때 파일이 지난달과 달라도 알아서 이어져요
   - 6월 파일로 만든 스킬을 7월 파일만 올려 둔 채 수정하면, 대상 파일을 못 찾아
     오류가 나거나 엉뚱한 파일에 실행되던 문제를 고쳤습니다.
   - 이제 수정/켜고끄기/삭제 후 재실행에서도 실행기처럼 월·날짜만 다른 파일을
     자동으로 알아보고 연결합니다(같은 종류 파일이 여러 개면 안전하게 직접 선택 요청).
   - 파일명 뒤에 붙는 "(2)"(재다운로드)나 "- 복사본"도 같은 파일로 인식합니다.

● 프로그램 종료(X)가 훨씬 빨라졌어요
   - 예전에는 종료를 누르면 열려 있던 Excel 창들을 하나씩 정리하느라 창이 수십 초 동안
     안 닫히는 경우가 있었습니다(파일이 크거나 여러 개일수록 오래 걸림).
   - 이제 '초기화' 버튼과 같은 방식으로 한 번에 정리해 보통 1~3초 안에 꺼집니다.
   - 작업 내용은 원본이 아닌 작업 복사본에서 처리되므로, 빨라진 종료로 잃는 데이터는 없습니다.
