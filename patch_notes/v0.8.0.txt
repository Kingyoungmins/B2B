AX-Cell — 업데이트 안내 (0.8.0)
====================================================

이 문서는 0.7.5 이후에 바뀐 내용을 정리한 안내입니다.
이전 내용은 같은 폴더의 v0.7.5.txt 를 봐 주세요.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 화면 색이 회사 규정에 맞춰 바뀌었습니다(검정·회색 중심). 기능은 그대로입니다.
   예전 디자인이 편하시면 상단 [테마] 버튼으로 언제든 되돌릴 수 있습니다.

2) 전체실행이 중간에서 실패해도, 고친 뒤 다시 누르면 처음부터 다시 돌지 않습니다.
   저장해 둔 지점부터 이어서 갑니다. (실측: 16분 → 30초)

3) 같은 가입번호인데 "없다"고 나오던 문제를 고쳤습니다.
   중복 확인, 두 열 대조, 값 가져오기가 모두 해당됩니다.

4) [작업 중단]을 눌러도 멈추지 않던 문제를 고쳤습니다.

5) 진행 상황이 한 곳에만 뜹니다. 몇 단계까지 왔는지도 보여 줍니다.

6) "이거 있는지 확인해 줘" 처럼 묻는 요청은 AI 도움으로 바로 연결됩니다.
   AI 도움은 파일을 직접 열어 보고 답할 수 있습니다.

7) 필터 결과를 이미 쓰고 있는 양식에 붙이는 기능이 생겼습니다.
   매달 행 수가 달라져도 같은 스킬을 그대로 쓸 수 있습니다.

8) 보안문서(DRM) 처리를 크게 보강했습니다. 비밀등급 문서를 가려내고,
   원본과 같은 보안 등급으로 되돌려 줍니다.


────────────────────────────────────────────────────
[ 화면 색상 변경 ]
────────────────────────────────────────────────────

● 회사 규정 색으로 맞췄습니다
   - 기존의 분홍·보라 계열을 검정·회색 중심으로 바꿨습니다.
   - 버튼, 강조 표시, 진행 표시 등 색만 바뀌었고 위치와 동작은 그대로입니다.
   - 좌측 상단 U+ 로고는 원래 색을 유지합니다.
   - 상태를 알려 주는 색(주의=주황, 완료=초록, 오류=빨강)은 구분이 필요해 그대로 뒀습니다.

● 예전 디자인으로 되돌릴 수 있습니다
   - 상단 [테마] 버튼을 누르면 0.7.4 때의 화면으로 바뀝니다. 다시 누르면 돌아옵니다.
   - 고른 테마는 기억되어, 프로그램을 다시 열어도 유지됩니다.


────────────────────────────────────────────────────
[ 시간이 오래 걸리던 것들 ]
────────────────────────────────────────────────────

● 전체실행이 실패해도 처음부터 다시 돌지 않습니다  ★ 가장 큰 변화
   - 예전에는 30단계에서 실패해 그 단계를 고친 뒤 다시 실행하면,
     1단계부터 전부 다시 돌았습니다(파일 6개·36단계 기준 16분).
   - 이제는 실행 도중 중간중간 상태를 저장해 두고, 고친 단계 앞까지는 건너뜁니다.
   - 실측: 같은 스킬에서 25단계를 건너뛰고 11단계만 실행 → 30초에 완료.
   - 화면에도 "26/36 단계 실행 중..." 처럼 어디까지 왔는지 표시됩니다.

● 수정 버튼을 눌렀는데 갑자기 실행이 시작되던 문제
   - 실행기에서 [✓ 수정 적용]을 누르면, 묻지도 않고 스킬 전체가 다시 돌기
     시작했습니다. 그동안 화면에는 "실행 중"만 떠서 얼마나 남았는지 알 수 없었습니다.
   - 이제 실행기에서는 코드만 바뀌고, 반영은 [전체실행]을 누르실 때 됩니다.
     그 전체실행은 위에서 설명한 대로 저장된 지점부터 이어서 갑니다.

● 설명(주석)만 고쳤는데 전체가 다시 돌던 문제
   - 단계의 설명 문구나 주석만 바뀌어도 "다른 스킬"로 보고 처음부터 다시 돌았습니다.
   - 이제 실제 동작에 영향이 없는 변경은 이어실행을 깨뜨리지 않습니다.

● 실행하기 전에 미리 막아 줍니다
   - 스킬에 적힌 열 이름이 실제 파일에 없으면, 8분을 돌린 뒤가 아니라
     실행 전에 알려 드립니다.
   - 같은 실수가 다른 단계에도 있으면 한 번에 모아서 고치도록 안내합니다.


────────────────────────────────────────────────────
[ 결과가 틀리던 문제 ]  ★ 중요
────────────────────────────────────────────────────

● 같은 가입번호인데 "없다"고 나오던 문제
   - 엑셀은 같은 번호 512102403338 을 셀마다 숫자로도, 글자로도 저장합니다.
     눈으로는 똑같아 보이지만 안에서는 다른 형태입니다.
     보통 다른 곳에서 복사해 붙인 열은 글자로, 원래 있던 열은 숫자로 들어갑니다.
   - 프로그램이 이 차이를 걸러내지 못해, 사람 눈에는 같은 번호인데
     다른 값으로 판단했습니다. 오류도 안 나고 "없다"고만 나와 더 헷갈렸습니다.
   - 이제 두 형태를 같은 번호로 봅니다. 해당되는 기능:
       · 중복 확인
       · 두 열에 같은 값이 있는지 대조
       · 다른 표에서 값 가져오기(VLOOKUP)
       · 조건에 맞는 값만 합계
   - 곁들여, 숫자 0 이 든 칸과 빈 칸을 구분하도록 고쳤습니다.
     예전에는 둘을 같게 봐서 "금액이 0인 행"을 세면 빈 행까지 딸려왔습니다.

● "Q열과 R열 사이에 열 추가"가 Q 앞에 들어가던 문제
   - "사이에"를 "앞에"로 잘못 알아들어 한 칸 왼쪽에 들어갔습니다.
   - 다시 요청해도 계속 같은 자리에 들어가던 것도 함께 고쳤습니다.


────────────────────────────────────────────────────
[ 진행 상황이 보이게 ]
────────────────────────────────────────────────────

● 알림이 한 곳에만 뜹니다
   - 예전에는 화면 잠금과 별도 상태창이 같은 말을 두 군데서 했습니다.
   - 이제 화면 잠금 한 곳에 모으고, 대신 몇 개까지 됐는지를 함께 보여 줍니다.
       입력 파일 업로드 중... (3/6) · 청구내역.xlsx
       Excel 창 준비 중... (2/4)
   - 보안 해제가 함께 진행되면 같은 줄에 덧붙습니다.
       입력 파일 업로드 중... (3/6) · 문서 보안 해제 중

● [작업 중단]이 실제로 멈춥니다
   - 예전에는 눌러도 반응이 없어 보여 여러 번 누르게 됐습니다.
   - 이제 누르면 "중단 요청됨 · 현재 단계 끝나면 멈춤" 으로 바뀌고,
     진행 중이던 단계가 끝나는 대로 멈춥니다.
   - 한 단계가 길면 조금 기다려야 합니다. 화면이 그 사실을 알려 드립니다.


────────────────────────────────────────────────────
[ 물어보면 답해 줍니다 ]
────────────────────────────────────────────────────

● "확인해 줘" 는 AI 도움으로 연결됩니다
   - "C열과 V열에 같은 번호가 있는지 확인해 줘" 처럼 묻는 요청은
     스킬을 만드는 게 아니라 AI 도움으로 넘어가 바로 답을 드립니다.
     AI 도움은 파일을 직접 열어 보고 확인할 수 있습니다.
   - "삭제해 줘", "정렬해 줘" 처럼 파일을 바꾸는 요청은 종전대로 스킬을 만듭니다.
   - 혹시 잘못 넘어갔다면 [그래도 스킬로 만들기] 버튼을 누르시면 됩니다.


────────────────────────────────────────────────────
[ 새로 생긴 기능 ]
────────────────────────────────────────────────────

● 필터 결과를 쓰던 양식에 바로 붙일 수 있습니다
   - 예전에는 필터 결과를 "새 시트"로만 뽑을 수 있었습니다.
     이미 쓰고 있는 보고서 양식에 채워 넣으려면 방법이 없었습니다.
   - 복사·붙여넣기를 녹화하는 방법도 있었지만, 녹화한 그 순간의 범위가
     그대로 굳어서 다음 달 행이 늘면 맞지 않았습니다.
   - 이제는 조건으로 말씀하시면, 실행할 때마다 해당하는 행을 다시 찾습니다.
     행이 늘든 줄든 같은 스킬을 그대로 쓰실 수 있습니다.
   - 이렇게 요청하세요:
       회선 현황에서 상태가 "정지"인 행을 대상양식 시트 A3부터 붙여 줘.
       붙이기 전에 그 자리 아래 지난달 값은 지워 줘.
   - 서식(음영·테두리·표시형식)도 함께 따라갑니다.
     양식의 다른 열은 건드리지 않습니다.

● 스킬 명령 설명서가 생겼습니다
   - 프로그램이 엑셀 작업에 쓰는 명령 67가지를 정리한 문서입니다.
     무엇을 시킬 수 있는지 미리 보실 때 참고하세요.
   - 위치: docs/user-guide/AX-Cell_스킬_함수_설명서_v0.8.0.txt


────────────────────────────────────────────────────
[ 보안문서(DRM) 처리 ]
────────────────────────────────────────────────────

● 기본 동작
   - 보안이 걸린 엑셀을 올리면 자동으로 풀어서 작업하고,
     내려받을 때 다시 보안을 걸어 줍니다.

● 원본과 같은 등급으로 되돌립니다
   - 예전에는 다시 걸 때 기본 등급으로 걸려, 원본과 다른 보호가 될 수 있었습니다.
   - 이제 올리실 때의 등급을 기억해 두었다가 그대로 다시 겁니다.

● 비밀등급 문서를 가려냅니다
   - 비밀등급 문서는 해제를 시도하지 않고, 그 사실을 알려 드립니다.
     등급을 낮춘 사본으로 다시 시도해 주세요.

● 무슨 일이 있었는지 분명히 알려 드립니다
   - 예전에는 보안 문서가 아닌 파일은 아무 말이 없어서,
     여러 개를 올리면 "이건 어떻게 된 거지"가 됐습니다.
     실패했을 때는 서버 오류 원문이 그대로 떠서 무엇을 해야 할지 알 수 없었습니다.
   - 이제 네 가지로 나눠 지금 상태를 말씀드립니다.
       · 보안 문서를 해제해 열었습니다
       · 비밀등급 문서라 처리할 수 없습니다 (등급을 낮춘 사본으로 다시 시도)
       · 지금은 보안 서버에 연결할 수 없어 원본 그대로 열었습니다
       · 보안 문서가 아니어서 그대로 열었습니다

● 처리 기록을 남깁니다
   - 파일이 올라온 시점의 보안 상태를 기록해 둡니다.
   - 처리 과정에서 보안이 약해지면 그 사실을 기록에 남깁니다.
   - 상태를 확인하지 못한 경우에는 "확인 못 함"으로 남깁니다.
     예전에는 확인 실패를 "보안 없음"과 구분하지 않았습니다.

[ 그 밖에 ]
────────────────────────────────────────────────────

● [✎ 수정] 버튼이 마지막에 쓰신 문장을 채워 줍니다
   - 엑셀 셀을 클릭한 뒤 눌러도 정상적으로 채워집니다.

● [결과 편집하기]가 한 번에 눌립니다
   - 예전에는 화면을 한 번 클릭해 깨운 뒤에야 눌렸습니다.

● AI 도움이 더 많은 것을 봅니다
   - 스킬 실행 밖의 문제(저장 실패, 화면 이상, 연결 문제)도 답할 수 있습니다.

● AI 서버 연결이 끊기면 예비 서버로 자동 전환합니다.

● 실행 중에는 스킬을 수정할 수 없도록 막았습니다
   - 실행과 수정이 겹쳐 상태가 어긋나는 것을 방지합니다.

[ 관리자용 ]
────────────────────────────────────────────────────

● F9 관리 대시보드
   - 실행 기록, 스킬 목록, 로그를 한 화면에서 볼 수 있습니다.

● 로그·스킬 자동 수집
   - 문제 확인에 필요한 기록이 자동으로 모입니다.

● 확인된 문제는 재발 방지 검사로 등록됩니다
   - 지금까지 확인된 337건을 배포 전마다 자동으로 다시 검사합니다.
   - 한 번 고친 것이 다음 버전에서 되살아나지 않게 하기 위해서입니다.

[ 이번 버전에서 알아 두실 점 ]
────────────────────────────────────────────────────

● 전체실행 이어실행에 대해
   - 저장 지점은 실행 속도에 맞춰 자동으로 정해집니다.
     실패한 바로 앞 단계가 아니라, 조금 앞에서 이어질 수 있습니다.
   - 여러 파일을 함께 참조하는 스킬은 안전을 위해 이어실행을 쓰지 않고
     처음부터 실행합니다. 결과가 틀리는 것보다 시간이 더 걸리는 편이 낫기 때문입니다.

● 프로그램을 다시 열면 저장 지점은 지워집니다
   - 다시 연 뒤 첫 실행은 처음부터 돕니다.
