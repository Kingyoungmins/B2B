AX-Cell — 업데이트 안내 (0.8.0)
====================================================

이 문서는 0.7.4 이후에 바뀐 내용을 정리한 안내입니다.
이전 내용은 같은 폴더의 v0.7.3.txt 를 봐 주세요.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 화면 색이 회사 규정에 맞춰 바뀌었습니다(검정·회색 중심). 기능은 그대로입니다.
2) 스킬 적용이 예전 버전보다 느려졌던 문제를 고쳤습니다.
   전체실행·재적용 모두 원래 속도로 돌아왔습니다.
3) 오래 걸리는 작업이 3분쯤부터 멈춘 것처럼 보이던 문제를 고쳤습니다.
4) 마지막 단계 하나만 고쳤는데 처음부터 다시 도는 것처럼 몇 분씩(실측 5분 5초)
   걸리던 문제를 고쳤습니다. 이제 그 단계만 다시 적용되어 몇 초면 끝납니다.
5) [✎ 수정]을 누르면 그 단계를 만들 때 썼던 문장이 입력창에 채워집니다.
   (엑셀 셀을 클릭한 뒤 눌러도 이제 정상적으로 채워집니다)
6) [결과 편집하기]를 한 번만 눌러도 바로 넘어갑니다.
   예전에는 화면을 한 번 클릭해 깨운 뒤에야 눌렸습니다.
7) 보안문서(DRM)가 걸린 엑셀을 자동으로 풀어서 작업하고, 내려받을 때 다시 걸어 줍니다.
8) AI 도움이 "스킬 실행 밖"의 문제(저장 실패, 화면 이상, 연결 문제)도 답할 수 있게 됐습니다.
9) AI 서버 연결이 끊기면 예비 서버로 자동 전환합니다.


────────────────────────────────────────────────────
[ 화면 색상 변경 ]
────────────────────────────────────────────────────

● 회사 규정 색으로 맞췄습니다
   - 기존의 분홍·보라 계열을 검정·회색 중심으로 바꿨습니다.
   - 버튼, 강조 표시, 진행 표시 등 색만 바뀌었고 위치와 동작은 그대로입니다.
   - 좌측 상단 U+ 로고는 원래 색을 유지합니다.
   - 상태를 알려 주는 색(주의=주황, 완료=초록, 오류=빨강)은 구분이 필요해 그대로 뒀습니다.


────────────────────────────────────────────────────
[ 속도 — 느려졌던 것들이 제자리로 ]
────────────────────────────────────────────────────

● 스킬 적용 속도를 되돌렸습니다
   - 내부 검사 한 곳이 셀마다 같은 준비 작업을 반복하고 있었습니다.
     한 번만 준비하도록 고쳐서, 실측으로 28배 빨라진 구간이 있습니다.

● 오래 걸리는 작업이 중간에 멈춘 것처럼 보이던 문제
   - 예전에 넣었던 안전장치가 오히려 3분이 지나면 진행 표시를 꺼 버리고 있었습니다.
     그 장치를 걷어내고, 원인이던 기록(로그) 유실 문제를 근본에서 고쳤습니다.

● 마지막 단계만 고치면 그 단계만 다시 적용됩니다
   - 결과를 편집한 뒤 마지막 단계를 수정하면 1단계부터 전부 다시 도는 경우가
     있었습니다(실측 5분 5초). 이제 직전 상태로 되돌린 뒤 그 단계만 적용합니다.
   - 마지막 단계를 삭제한 직후 오른쪽 엑셀 화면이 회색으로 남아 파일 탭을 눌러야
     보이던 문제도 고쳤습니다(자동으로 다시 표시).


────────────────────────────────────────────────────
[ 손이 덜 가게 — 클릭·입력 관련 ]
────────────────────────────────────────────────────

● [✎ 수정] 버튼이 썼던 문장을 채워 줍니다
   - 여러 번 고쳤다면 가장 최근에 고친 문장이 나오고, 스킬을 저장했다 불러와도
     유지됩니다. 채팅 기록에서도 그 문장의 위치로 정확히 이동합니다.
   - 엑셀에서 셀을 클릭하면 입력창에 '선택 범위: ...' 줄이 자동으로 붙는데,
     프로그램이 이걸 사용자가 쓰던 글로 오해해 문장을 안 채우던 문제를 고쳤습니다.

● [결과 편집하기]가 한 번에 눌립니다
   - 전체실행 중에는 엑셀 창이 화면 앞으로 나오는데, 그러면 프로그램 창이
     잠시 뒤로 물러납니다. 이 상태에서 누른 첫 클릭은 '창 깨우기'로만 쓰여
     버튼이 안 눌린 것처럼 보였습니다.
   - 이제 실행이 끝나면 프로그램 창이 스스로 앞으로 돌아옵니다.
     (다른 업무 프로그램을 보고 계실 때는 뺏어오지 않습니다)


────────────────────────────────────────────────────
[ 보안문서(DRM) 자동 처리 ]
────────────────────────────────────────────────────

● 이렇게 동작합니다
   - 보안이 걸린 엑셀을 올리면 사내 보안 서버를 통해 자동으로 풀어서 작업합니다.
     원본 파일은 그대로 두고 작업용 복사본만 풉니다.
   - 결과를 내려받을 때는 다시 보안을 걸어 내보냅니다. 보안 서버에 연결할 수 없으면
     보안 없는 파일이 나가지 않도록 다운로드를 멈추고 알려 드립니다.

● 인식 범위를 넓혔습니다
   - 표준 방식만 인식하고 일부 사내 보안 형식은 지나치던 문제를 고쳤습니다.
     이제 파일 이름이 아니라 내용으로 판별합니다.
   - 유니코드/한글 CSV 를 보안문서로 잘못 보고 "보안 해제 실패"가 뜨던 오탐도 고쳤습니다.


────────────────────────────────────────────────────
[ AI 도움이 더 많은 것을 봅니다 ]
────────────────────────────────────────────────────

● 무엇이 달라졌나요
   - 예전에는 AI 도움이 '스킬 실행' 관련만 볼 수 있어서, 저장 실패나 화면 이상,
     연결 문제를 물으면 "제보해 주세요" 카드로만 답했습니다.
   - 이제 최근 알림 메시지, 최근 오류 기록, 저장·백업 상태, AI 연결 상태까지
     읽고 답합니다. 3초 만에 사라진 빨간 메시지도 다시 확인할 수 있습니다.
   - 자동 백업이 실패하면 조용히 넘어가지 않고 알려 줍니다.


────────────────────────────────────────────────────
[ 스킬 생성 정확도 ]
────────────────────────────────────────────────────

● "값이 0인 행을 삭제해줘" 같은 행 삭제 요청
   - 예전에는 남길 행을 새 시트로 옮기고 원래 시트를 바꿔치기하는 코드가 만들어질
     때가 있었습니다. 이러면 보고 있던 화면이 깨지고 시트 순서·틀고정이 사라집니다.
   - 이제 엑셀에서 행을 지우는 것(Ctrl+-)과 같은 방식으로 만들어지고,
     예전 방식의 코드가 나와도 적용 전에 걸러 자동으로 다시 만듭니다.


────────────────────────────────────────────────────
[ 연결 안정성 ]
────────────────────────────────────────────────────

● AI 서버 자동 전환
   - 메인 AI 서버와 연결이 끊기면 예비 서버로 자동 전환해 이어서 동작합니다.
   - 서버의 AI 모델이 교체돼도 자동으로 알아채고 맞춰 요청합니다.


────────────────────────────────────────────────────
[ 관리자용 ]
────────────────────────────────────────────────────

● F9 관리 대시보드
   - F9 설정 창에 [관리 대시보드] 버튼이 생겼습니다. 누가 언제 얼마나 사용했는지,
     어떤 오류가 있었는지 기간별·사용자별로 조회하고, 그 실행의 로그와 스킬 파일을
     바로 내려받을 수 있습니다.

● 로그·스킬 자동 수집
   - 사용 중 동작 기록과 만든 스킬 파일이 관리 서버에 자동으로 쌓입니다.
     문제를 제보하실 때 파일을 따로 보내지 않으셔도 됩니다.
   - 엑셀의 표 데이터 자체를 올리는 것은 아닙니다. 수집되는 것은 프로그램 동작
     기록과 스킬 구성(스킬을 만들 때 입력한 요청 문장 포함)입니다.

문의나 이상한 점이 있으면 화면 맨 위 [✦ AI 도움] 을 먼저 눌러 보세요.
