B2B 빌링 Agent — 업데이트 안내 (0.5.19)
====================================================

[ 고친 점 / 바뀐 점 ]
----------------------------------------------------

● 셀 서식(음영·글꼴·테두리)을 스킬로 직접 지정할 수 있어요
   - "이 셀 노랑으로 칠해줘", "제목은 굵게/기울여", "표에 테두리 쳐줘", "글씨 키워줘" 같은 요청을 처리합니다.
   - 색은 "옅은 노랑", "진한 파랑"처럼 뉘앙스로 말해도 알맞은 색으로 채웁니다.

● 스킬 단계 이름을 직접 편집할 수 있어요
   - 파이프라인 카드의 단계 이름(요약)을 더블클릭하면 원하는 이름으로 바꿀 수 있습니다.
   - 바꾼 이름은 스킬 저장(zip)에 함께 담겨, 나중에 그 스킬을 불러오면 편집한 이름으로 보입니다.

● 개별 파일 다운로드가 '스킬 반영본'을 받도록 고쳤어요
   - 예전에는 파일 옆 '다운로드'가 스킬 실행 전 원본을 받는 경우가 있었습니다.
   - 이제 스킬 실행 결과가 반영된 파일을 받습니다. 관련해서 '파일 수정' 버튼은 '파일 수정/다운'으로 이름을 바꿨습니다.

● 오류 자동복구가 더 안정적으로 동작해요
   - Python 방식으로 같은 단계가 반복 실패하면 자동으로 VBA 방식으로 전환해 복구를 시도합니다
     (예전엔 계속 Python 으로만 재시도하던 경우가 있었습니다).
   - '복구'를 눌렀을 때 "적용할 코드가 없습니다"로 막히던 경우를 줄였습니다.

● 실행기에 '파일 확인' 매핑이 생겼어요 (다른 달/이름이 바뀐 파일에 스킬 재사용)
   - 저장한 스킬이 필요로 하는 파일/시트를, 새로 올린 파일에 자동으로 맞춰 줍니다(이름·월·날짜만 달라도 인식).
   - 자동으로 안 잡히면 실행기의 '파일확인'에서 직접 골라(드래그/선택) 연결한 뒤 실행하면 됩니다.
   - 스킬이 중간에 만드는 시트(검증/결과 시트 등)는 '올려야 하는 파일'로 잘못 요구하지 않습니다.
   - 자동으로 잡힌 시트는 '시트 자동' 옆에 실제 시트 이름을 함께 보여줍니다.
   - 스킬이 특정 시트를 다루는데도 시트를 못 알아보고 '시트 자동'으로만 뜨던 문제, 그리고 설명 문장 속 파일명을 잘못 읽어 엉뚱한 '필수 파일' 행이 뜨던 문제를 고쳤습니다.
   - '파일확인'을 파일 단위로 한 줄씩 보여줍니다. 한 파일이 여러 시트를 쓰면 그 시트들을 한 줄 안에 함께 표시해, 실제로 올려야 하는 파일이 몇 개인지 한눈에 보입니다.
   - 파일이 아닌데 '올려야 하는 파일'처럼 잘못 잡히던 항목(스킬이 중간에 쓰는 시트 이름 등)을 목록에서 제외했습니다.
   - 각 파일의 시트를 [스킬이 찾는 시트] ↔ [실제 파일의 시트 선택]으로 짝지어 보여줘, 시트까지 정확히 연결할 수 있습니다(자동으로 맞은 시트는 미리 선택됨).
   - 여러 파일을 오가며 작업하는 스킬(교차파일)에서, 한 파일의 시트가 엉뚱하게 다른 파일에 필요한 것처럼 잡히던 문제를 고쳤습니다. 각 파일이 실제로 쓰는 자기 시트로 표시합니다.
   - 시트 드롭다운에서 값을 골라도 선택이 저장되지 않던 문제를 고쳤습니다(이제 고른 시트가 그대로 반영됩니다).
   - 시트를 아직 못 고른 상태에서도 파일 이름은 매핑한 새 파일로 바꿔 실행하도록 고쳐, "워크북이 열려 있지 않습니다"로 실패하던 경우를 줄였습니다.

● 피벗이 '진짜 엑셀 피벗테이블'로 만들어져요 (새로 고침 가능)
   - 이제 "~별 합계/개수/평균/피벗" 요청은 원본과 연결된 진짜 피벗테이블(PivotTable)로 만들어, 나중에 데이터가 바뀌면 '새로 고침'으로 반영할 수 있습니다. (만약 만들지 못하는 경우엔 예전처럼 값 표로 자동 대체합니다.)
   - "회사·지점별 매출 합계와 건수 개수"처럼 그룹 기준 여러 개·집계 값 여러 개, 그리고 행/열/값 크로스탭도 한 번에 만듭니다.
   - 전화번호·가입번호처럼 앞자리 0 이 있는 값으로 피벗해도 0 이 사라지지 않고 그대로 유지됩니다.

● 필터를 켜고/특정 값만 보이게 하고/푸는 기능이 생겼어요
   - "필터 풀어줘/해제해줘": 시트에 걸린 필터를 해제해 숨은 행을 모두 되살리고 필터 단추를 없앱니다.
   - "상태가 완료인 것만 보이게 필터 걸어줘": 데이터를 지우지 않고, 엑셀 필터 체크박스처럼 특정 값만 화면에 보이게 합니다(원본은 그대로, 언제든 해제해 복원).
   - "필터 켜줘/활성화": 조건 없이 필터 단추만 켭니다.

● 자주 틀리던 계산을 바로잡았어요
   - "데이터만 지우고 헤더는 남겨줘"에서 A열이 비면 맨 아랫줄을 놓쳐 일부가 안 지워지던 문제, 표 전체를 다루는 작업에서 하단 행을 빠뜨리던 문제를 고쳤습니다(실제 사용 범위 기준으로 처리).
   - "옆 빈 열에 계산 넣어줘"에서 이미 합계 수식이 들어 있는 열을 덮어써 표를 망가뜨리던 문제를 고쳤습니다(진짜 빈 열을 찾아 넣습니다).

● CSV 파일을 '새 시트로 필터/정리'할 때 기존 시트가 사라지던 문제를 고쳤어요
   - CSV는 시트를 하나만 담을 수 있어, 새 시트를 추가하면 저장할 때 붕괴(덮어써짐)되던 문제가 있었습니다.
   - 이제 시트가 여러 개가 되면 자동으로 xlsx로 저장해 원본 시트와 새 시트가 모두 남습니다.

● 파일명이 긴 CSV에서 '시트를 찾지 못했다'는 오류를 고쳤어요
   - CSV를 Excel에서 열면 시트 이름이 파일명 앞 31자까지만 남는데, 파일명이 길면 이 차이 때문에 계산할 표를 못 찾고 실패하던 경우가 있었습니다.
   - 이제 시트 이름이 길이가 잘려 조금 달라도 알맞은 시트를 알아서 찾아 처리합니다. 시트가 하나뿐인 CSV는 시트를 따로 말하지 않아도(예: "E열 합산") 바로 처리됩니다.

● 실행기에서 전체실행한 결과를 '결과 편집하기'로 이어서 편집할 수 있어요
   - CSV 등 일부 스킬(Python)을 실행기에서 전체실행하면 결과 파일이 만들어지지 않아 '결과 편집하기' 버튼이 활성화되지 않던 문제가 있었습니다.
   - 이제 실행기 전체실행은 종류와 무관하게 결과 파일을 만들어, 실행 후 '결과 편집하기'로 라이브에 불러와 이어서 수정할 수 있고 개별/전체 다운로드도 결과가 반영됩니다.

● 파일을 여러 개 올릴 때 빈 회색 Excel 창이 뜨던 문제를 고쳤어요
   - 실행기에서 파일을 두 개째부터(또는 여러 개를 한 번에) 올리면 내용 없는 빈 회색 Excel 창이 뜨던 문제가 있었습니다.
   - 실행기는 미리보기를 화면 안에서 보여주므로 실제 Excel 창을 띄울 필요가 없는데, 두 번째 파일부터 창이 새어 나오던 것을 막았습니다.

● 대용량(수십만 행) 작업이 시간/셀 제한 없이 끝까지 실행돼요
   - 60만 행처럼 큰 작업이 제한 시간이나 셀 개수 한도에 걸려 중간에 멈추던 문제를 없앴습니다(Python 처리 무제한).
