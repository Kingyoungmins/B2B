# B2B 빌링 Agent — 업데이트 안내 (0.5.14 → 0.5.16)

이전 버전(0.5.14)에서 0.5.16으로 올라오시는 분들을 위해, 그동안 좋아진 점을 모았습니다.
**스킬 적용이 멈추던 문제와 속도가 크게 개선**되었고, **스킬 실행기 화면과 결과 편집**이 편해졌어요.

---

## 먼저, 속도·안정성이 좋아졌어요

### 스킬 적용이 갑자기 몇 분씩 멈추던 문제를 고쳤어요 ★
- 특정 스킬을 "적용"할 때 화면이 **몇 분씩 멈췄다가** 다운되던 현상을 없앴습니다. 이제 바로 적용됩니다.

### 전체 실행이 더 빠르고 매끄러워졌어요
- 여러 단계를 한 번에 실행할 때 **중간에 멈췄다가 한꺼번에 처리되던** 현상을 줄이고 전체적으로 빠르게 했습니다.
- 느린 PC에서 전체 실행이 **다 끝났는데도 "응답이 지연되어 중단"으로 잘못 멈추던** 문제도 고쳤습니다.

### 스킬 적용 시 검은 창 깜빡임을 없앴어요
- 스킬을 적용할 때 **검은 창(명령 창)이 잠깐 떴다 사라지던 것**을 제거했습니다.

### 결과 파일을 한 번에 받을 수 있어요
- 실행 결과를 **파일 하나(zip)로 모아** 한 번에 내려받습니다(수정된 입력 파일까지 함께).

---

## 그리고, 이번에 새로워진 점

### 1. 스킬 실행기 화면이 깔끔해졌어요
- 실행기에서 전체 실행할 때 **엑셀 창이 화면에 뜨지 않고**, 한 화면을 꽉 채워 보여줍니다.
- 실행이 끝난 뒤에 엑셀 창이 **갑자기 떠오르는 현상**을 없앴습니다.

### 2. 실행 결과를 바로 편집할 수 있어요 — `📝 결과 편집하기`
- 실행기에서 전체 실행을 마치면 **`결과 편집하기`** 버튼이 켜집니다.
- 누르면 생성기 화면으로 넘어오면서 **결과가 그대로 올라와** 단계 켜기/끄기·수정이 바로 됩니다.
- 처음부터 다시 계산하지 않고 **만들어진 결과를 그대로 불러오므로 빠릅니다.**

### 3. 단계 켜기/끄기(ON·OFF)가 안정적으로 동작해요
- 전체 실행 뒤 마지막 단계를 켜고 끌 때 **가끔 반영이 안 되거나 "보류"로 남던 문제**를 고쳤습니다. 이제 한 번에 정확히 반영됩니다.

### 4. 중간 단계를 고칠 때 안내가 명확해졌어요
- 중간 단계를 수정하거나 켜고 끄면 **그 단계부터 다시 실행**됩니다.
- 이때 화면에 **"전체 실행 중"이 아니라 "실행 중"** 으로 표시해 헷갈리지 않게 했습니다.

### 5. 프로그램이 깔끔하게 켜지고 닫혀요
- 프로그램이 실수로 **두 개 켜지지 않도록** 했습니다(이미 켜져 있으면 안내해 드려요).
- 닫을 때 **엑셀 창이 남지 않고 함께 정리**됩니다.

### 6. 스킬에서 안정적으로 쓸 수 있는 작업이 늘었어요
채팅으로 스킬을 만들 때 아래 작업이 더 정확하고 안정적으로 처리됩니다.
- **다른 표에서 값 찾아 채우기** (예: 단가표에서 단가 매칭 — VLOOKUP)
- **표 맨 아래 합계 행 자동 추가**
- **중복된 행 정리**
- **한 칸에 붙은 값 나누기** (예: `1001/홍길동` → 가입번호 / 고객명)
- **범위 안에서 값 찾아 바꾸기**

또한, 이런 작업에 **알맞은 처리 방식이 자동으로 선택**되도록 개선해 결과가 더 안정적입니다.

### 7. 긴 식별번호가 숫자로 깨지던 문제를 막았어요
- EID·가입번호처럼 **아주 긴 번호(16자리 이상)**가 스킬 실행 중 `8.9E+31` 같은 값으로 바뀌어 **서로 구분이 안 되고 정렬이 안 되던** 문제를 고쳤습니다.
- 데이터를 다른 시트로 옮길 때 **원래 번호(텍스트)를 그대로 보존**하도록 했고, 이런 위험이 있는 스킬은 **자동으로 안전한 방식으로 만들어지게** 했습니다.
