AX-Cell — 업데이트 안내 (0.8.3)
====================================================

0.8.2 다음 버전입니다. 이번에는 "지금 쓰는 버전이 최신인지 알려주기" 와
"관리 화면에서 누가 어떻게 쓰는지 보기" 가 크게 좋아졌습니다.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 프로그램을 켤 때 버전을 한 번 확인합니다. 너무 오래된 버전이면
   안내 창이 뜨고 [다운로드 하러가기] 버튼으로 바로 받으러 갈 수 있습니다.

2) 버전 서버가 잠깐 응답하지 않을 때는 "점검중입니다" 안내가 뜹니다.
   프로그램은 그대로 쓸 수 있습니다.

3) 화면 왼쪽 위에 "사용자 : 홍길동" 처럼 본인 이름이 표시됩니다.
   (사내 계정 정보에서 자동으로 가져옵니다)

4) F1 을 누르면 F키에 무엇이 걸려 있는지 한눈에 보는 도움말이 나옵니다.

5) 관리 대시보드가 크게 좋아졌습니다 — 소속(팀)별로 골라 보고,
   AI 에게 "이번 주 가장 많이 쓴 팀은?" 처럼 물어볼 수 있고,
   AI 사용량(토큰)을 사용자·팀·모델별로 볼 수 있습니다.

6) 이름이 한글인 사용자가 관리 화면에서 깨져 보이던 문제를 고쳤습니다.

7) 프로그램을 끈 뒤에도 계속 "수집 중" 으로 남던 표시를 고쳤습니다.


────────────────────────────────────────────────────
[ 버전 확인 ]
────────────────────────────────────────────────────

● 켤 때 한 번만 확인합니다

  프로그램을 시작할 때 서버에 "이 버전 써도 되나요?" 를 한 번 물어봅니다.
  쓰던 중에 갑자기 창이 뜨는 일은 없습니다.

● 오래된 버전이면

  ┌──────────────────────────────────────────┐
  │ 오래된 버전을 사용하고 있습니다.          │
  │ 최신 버전으로 교체 해주세요.              │
  │                                          │
  │        [ 다운로드 하러가기 ]              │
  └──────────────────────────────────────────┘

  [다운로드 하러가기] 를 누르면 사내 배포 페이지가 열립니다.

● 서버가 응답하지 않으면

  "점검중입니다. 문의사항이 있으시면 팀즈로 문의 부탁드립니다" 안내가 뜨고
  [확인] 을 누르면 그대로 사용할 수 있습니다. 작업이 막히지는 않습니다.

  ※ 예전 버전(0.8.2 이하)을 쓰셔도 충돌하지 않습니다. 이 안내는 0.8.3 부터 나옵니다.


────────────────────────────────────────────────────
[ 화면 ]
────────────────────────────────────────────────────

● 내 이름이 보입니다

  왼쪽 위에 "사용자 : 홍길동" 으로 표시됩니다. 마우스를 올리면 마당 아이디와
  소속 팀도 함께 보입니다. (사내 계정에서 자동으로 읽어옵니다 — 따로 입력할 것 없습니다)

● F1 — 단축키 도움말

  F1 을 누르면 F키 목록이 뜹니다. 어떤 키에 무엇이 걸려 있는지 외울 필요가 없습니다.
  한 번 더 누르면 닫힙니다.


────────────────────────────────────────────────────
[ 관리 대시보드 ] ※ 관리자용
────────────────────────────────────────────────────

● 소속별로 볼 수 있습니다

  팀뿐 아니라 그 위 조직(본부·담당 등) 단위로도 골라서 볼 수 있습니다.
  사용자 이름은 "홍길동(마당아이디)" 형식으로 나옵니다.

● AI 에게 묻기

  대시보드 데이터를 근거로 질문에 답합니다.
  예) "이번 주 오류가 가장 많았던 단계는?", "지난주보다 사용이 늘었나?"
  프로그램에서 쓰는 AI 설정을 그대로 쓰므로 따로 설정할 것이 없습니다.

● AI 사용량(토큰)

  누가·어느 팀이·어떤 AI 모델을 얼마나 썼는지 볼 수 있습니다.
  들어간 양(입력)과 나온 양(출력)을 나눠서 보여줍니다.

● 더 보기 좋아진 것들

  - 팀별 사용 순위, 체류 시간 분포, 사용 시간대(요일×시간), 버전 도입률
  - 신규 사용자, 오류율, 구버전 사용자 카드
  - 직전 같은 기간과 비교한 증감 표시
    (예: 이번 주 실행 42회인데 지난주가 30회였다면 "▲12 (+40%)")
  - 60초 자동 새로고침


────────────────────────────────────────────────────
[ 고친 것 ]
────────────────────────────────────────────────────

● 한글 이름이 깨져 보이던 문제

  관리 화면에서 한글 이름이 네모 안 물음표로 보이던 것을 고쳤습니다.

● 끈 뒤에도 "수집 중" 으로 남던 문제

  프로그램을 정상 종료하면 바로 "종료" 로 바뀝니다.
  강제 종료·다운 등으로 신호를 못 보낸 경우에는 10분 뒤 "종료(추정)" 으로 표시됩니다.


────────────────────────────────────────────────────
[ 참고 ]
────────────────────────────────────────────────────

- 이 버전부터 로그에 소속 정보(이름·마당아이디·팀)가 함께 기록됩니다.
  기존과 같은 사내 서버에 쌓이며, 보내는 항목만 늘었습니다.
- 예전 버전과 섞여 있어도 문제없이 동작합니다.
