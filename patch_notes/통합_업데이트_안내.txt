B2B 빌링 Agent — 업데이트 안내(0.5.14->0.5.17)
====================================================

그동안 좋아진 점을 한데 모았습니다. 스킬 적용이 멈추던 문제와 속도가 크게 개선됐고,
스킬 실행기 화면과 결과 편집이 편해졌으며, 채팅으로 스킬을 만들 때의 정확도도 높아졌습니다.


[ 속도·안정성 ]
----------------------------------------------------

● 스킬 적용이 갑자기 몇 분씩 멈추던 문제를 고쳤어요  ★
   - 특정 스킬을 "적용"할 때 화면이 몇 분씩 멈췄다가 다운되던 현상을 없앴습니다. 이제 바로 적용됩니다.

● 전체 실행이 더 빠르고 매끄러워졌어요
   - 여러 단계를 한 번에 실행할 때 중간에 멈췄다가 한꺼번에 처리되던 현상을 줄이고 전체적으로 빠르게 했습니다.
   - 느린 PC에서 전체 실행이 다 끝났는데도 "응답이 지연되어 중단"으로 잘못 멈추던 문제도 고쳤습니다.

● 스킬 적용 시 검은 창 깜빡임을 없앴어요
   - 스킬을 적용할 때 검은 창(명령 창)이 잠깐 떴다 사라지던 것을 제거했습니다.

● 행·열·셀을 선택하면 채팅에 더 빨리 반영돼요
   - 오른쪽 엑셀에서 행/열/셀을 선택했을 때 그 선택이 채팅 입력창에 뜨는 속도를 크게 높였습니다.


[ 실행기 & 결과 편집 ]
----------------------------------------------------

● 스킬 실행기 화면이 깔끔해졌어요
   - 실행기에서 전체 실행할 때 엑셀 창이 화면에 뜨지 않고, 한 화면을 꽉 채워 보여줍니다.
   - 실행이 끝난 뒤에 엑셀 창이 갑자기 떠오르는 현상을 없앴습니다.

● 실행 결과를 바로 편집할 수 있어요 — [📝 결과 편집하기]
   - 실행기에서 전체 실행을 마치면 "결과 편집하기" 버튼이 켜집니다.
   - 누르면 생성기 화면으로 넘어오면서 결과가 그대로 올라와 단계 켜기/끄기·수정이 바로 됩니다.
   - 처음부터 다시 계산하지 않고 만들어진 결과를 그대로 불러오므로 빠릅니다.

● 결과를 불러와 이어서 단계를 만들 때 파일·시트를 못 찾던 문제를 고쳤어요  ★
   - "결과 편집하기"로 결과를 불러오면, 파일 이름 뒤에 자동으로 붙는 관리용 표시(예: 결과_..._날짜)가
     실제 파일 이름처럼 잡혀서, 채팅에서 @로 파일/시트를 골라도 "그 파일을 못 찾는" 일이 있었습니다.
   - 이제 결과를 불러와도 파일은 원래 이름 그대로 유지되어, @ 지정과 단계 추가가 정상 동작합니다.
   - 예) 30단계 스킬을 만들다가 15단계까지 하고 전체 실행 → 다음 날 결과를 불러와 16단계부터
     이어서 만들기가 문제없이 됩니다.

● 이어서 만든 스킬의 전체 실행도 안정적이에요
   - 위 문제로 어긋났던 파일 이름이 바로잡혀, 저장한 스킬을 처음부터 전체 실행할 때도 끝까지 정확히 실행됩니다.

● 여러 파일을 다루는 스킬은 결과 편집 시 '방금 바뀐 파일'이 항상 보여요
   - 여러 파일을 함께 처리하는 스킬을 전체 실행한 뒤 "결과 편집하기"를 누르면, 마지막 단계가 바꾼
     파일(예: 새 시트를 추가한 파일)이 화면에 확실히 표시됩니다. 이전에는 어떤 파일이 보일지 실행마다
     달라져 방금 만든 변화가 "보였다 안 보였다" 하던 문제를 고쳤습니다.

● 단계 켜기/끄기(ON·OFF)가 안정적으로 동작해요
   - 전체 실행 뒤 마지막 단계를 켜고 끌 때 가끔 반영이 안 되거나 "보류"로 남던 문제를 고쳤습니다.
     이제 한 번에 정확히 반영됩니다.

● 중간 단계를 고칠 때 안내가 명확해졌어요
   - 중간 단계를 수정하거나 켜고 끄면 그 단계부터 다시 실행되며, 이때 화면에 "전체 실행 중"이 아니라
     "실행 중"으로 표시해 헷갈리지 않게 했습니다.


[ 스킬 만들기 — 정확도 ]
----------------------------------------------------

● 셀에 값을 채우는 단순 작업이 더 정확하게 처리돼요
   - "○○ 열/셀에 값을 채워줘"처럼 계산·조건 없이 값만 넣는 요청이 더 안정적인 방식으로 처리됩니다.
     (매칭·조건·합계·행 삭제 같은 복잡한 작업은 기존 방식 그대로예요.)

● 시트 이름 바꾸기도 더 안정적으로 처리돼요
   - "이 시트를 3월로 바꿔줘", "시트 이름을 2026년 5월로 변경"처럼 '이름'이라는 말을 안 붙이거나
     새 이름이 길어도 올바르게 인식됩니다.

● 병합된 셀이 있는 표에서 '열 옮기기'가 안정적으로 처리돼요
   - 제목/헤더가 병합된 표에서 "○○ 열을 △△ 앞으로 옮겨줘"처럼 열을 이동·재배치·맞바꾸는 작업이
     "병합된 셀에서는 실행할 수 없습니다" 오류 없이, 검증된 안전한 방식으로 실행됩니다.

● 안정적으로 쓸 수 있는 작업이 늘었어요
   채팅으로 스킬을 만들 때 아래 작업이 더 정확하고 안정적으로 처리됩니다.
   - 다른 표에서 값 찾아 채우기 (예: 단가표에서 단가 매칭 — VLOOKUP)
   - 표 맨 아래 합계 행 자동 추가
   - 중복된 행 정리
   - 한 칸에 붙은 값 나누기 (예: 1001/홍길동 → 가입번호 / 고객명)
   - 범위 안에서 값 찾아 바꾸기
   또한, 이런 작업에 알맞은 처리 방식이 자동으로 선택되도록 개선해 결과가 더 안정적입니다.

● 긴 식별번호가 숫자로 깨지던 문제를 막았어요
   - EID·가입번호처럼 아주 긴 번호(16자리 이상)가 스킬 실행 중 8.9E+31 같은 값으로 바뀌어 서로 구분이
     안 되고 정렬이 안 되던 문제를 고쳤습니다.
   - 데이터를 다른 시트로 옮길 때 원래 번호(텍스트)를 그대로 보존하도록 했고, 이런 위험이 있는 스킬은
     자동으로 안전한 방식으로 만들어지게 했습니다.


[ 편의 & 프로그램 ]
----------------------------------------------------

● @로 파일·시트를 고를 때 목록이 간결해졌어요
   - @ 자동완성 목록에 컬럼(열 이름)은 더 이상 나오지 않고, 파일과 시트만 보입니다.
     (필요하면 @컬럼[...] 을 직접 입력하는 방식은 그대로 동작합니다.)

● 결과 파일을 한 번에 받을 수 있어요
   - 실행 결과를 파일 하나(zip)로 모아 한 번에 내려받습니다(수정된 입력 파일까지 함께).

● 프로그램이 깔끔하게 켜지고 닫혀요
   - 프로그램이 실수로 두 개 켜지지 않도록 했습니다(이미 켜져 있으면 안내해 드려요).
   - 닫을 때 엑셀 창이 남지 않고 함께 정리됩니다.
