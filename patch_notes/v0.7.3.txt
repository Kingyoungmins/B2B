AX-Cell — 업데이트 안내 (0.7.3)
====================================================

이 문서는 0.7.2.1 이후에 바뀐 내용을 정리한 안내입니다.
이전 내용은 같은 폴더의 v0.7.2.1.txt 를 봐 주세요.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 보류된 단계들을 한 번에 다시 켜는 [⏯ 보류 일괄 실행] 버튼이 생겼습니다.
   중간 단계를 고친 뒤 나머지 단계를 하나씩 켜던 수고가 클릭 한 번으로 줄어듭니다.
2) 단계의 [✎ 수정]을 누르면, 그 단계를 만들 때 입력했던 문장이
   채팅 입력창에 미리 채워집니다. 처음부터 다시 쓸 필요 없이 고칠 부분만 고치면 됩니다.


────────────────────────────────────────────────────
[ ⏯ 보류 일괄 실행 — 이런 때 쓰세요 ]
────────────────────────────────────────────────────

● 이런 상황이 있었습니다
   - 10단계 스킬을 쓰다가 5단계를 고치면, 6~10단계는 자동으로 '보류'가 됩니다
     (고친 단계 뒤는 다시 실행해야 정확하니까요).
   - 예전에는 6, 7, 8, 9, 10을 하나씩 켜야 했습니다. 단계가 많으면 번거롭고,
     하나 켤 때마다 기다려야 했습니다.

● 이제 이렇게 하세요
   1. 단계를 고치면 화면 왼쪽 아래(초기화 버튼 옆)에 [⏯ 보류 일괄 실행] 버튼이 나타납니다.
      (보류된 단계가 없을 때는 보이지 않습니다)
   2. 누르면 보류된 단계 목록이 뜹니다. 기본으로 전부 체크되어 있습니다.
   3. 건너뛰고 싶은 단계가 있으면 체크를 해제하세요. (예: 7단계만 빼고 싶을 때)
   4. [선택한 N개 단계 실행]을 누르면, 고친 단계의 결과를 이어받아
      체크된 단계들이 순서대로 한 번에 적용됩니다.

● 알아 두세요
   - 체크에서 뺀 단계는 '보류'로 남습니다. 나중에 그 단계를 켜면
     지금 만들어진 결과 '위에' 적용됩니다(순서가 뒤로 밀립니다).
   - 실행 중에는 다른 단계를 켜고 끄거나 수정할 수 없습니다(끝나면 풀립니다).
     실행 도중 누른 스위치는 무시되지 않고 실행이 끝난 뒤에 처리됩니다.
   - 중간에 어떤 단계가 실패하면: 이미 성공한 단계는 그대로 두고,
     실패한 단계와 그 뒤는 다시 보류로 돌립니다. 오류 창에서 원인을 알려 드립니다.
   - 다른 파일에 값을 쓰는 단계가 섞여 있으면 골라서 실행할 수 없고
     전부 함께 실행됩니다(파일 간 결과가 어긋나는 것을 막기 위해서입니다).
   - 되돌리기(Undo)로 실행 전 상태로 돌아갈 수 있습니다.

● 전체실행 → [📝 결과 편집하기] 흐름에서 특히 유용합니다
   - 결과를 보다가 중간 단계 하나를 고치는 경우, 고침 → [⏯ 보류 일괄 실행] →
     끝. 처음부터 전체를 다시 돌릴 필요가 없습니다.

● AI 도움도 이 버튼을 압니다
   - "보류된 단계들 다시 켜줘" 같은 요청을 하면 단계마다 하나씩 제안하는 대신
     이 버튼 사용을 안내합니다.


────────────────────────────────────────────────────
[ ✎ 수정 버튼 — 원래 썼던 문장이 미리 채워집니다 ]
────────────────────────────────────────────────────

● 무엇이 달라졌나요
   - 예전에는 [✎ 수정]을 누르면 채팅창으로 이동해서 해당 대화가 깜빡이며
     표시될 뿐, 입력창은 비어 있었습니다. 고치려면 처음부터 다시 써야 했습니다.
   - 이제는 그 단계를 만들 때 입력했던 문장이 입력창에 그대로 들어옵니다.
     예: 3단계 수정 → "선택 범위: ... 300써줘"가 입력창에 채워짐
     → 300만 500으로 고쳐서 보내면 끝.

● 알아 두세요
   - 입력창에 이미 쓰던 글이 있으면 지우지 않고 그대로 둡니다.
   - 수정 모드를 해제하면, 손대지 않은 미리 채운 문장만 지웁니다
     (직접 고친 내용은 남습니다).
   - 녹화나 복사/붙여넣기로 만든 단계는 원래 문장이 없어서 채우지 않습니다.

문의나 이상한 점이 있으면 화면 맨 위 [✦ AI 도움] 을 먼저 눌러 보세요.
