B2B 빌링 Agent — 업데이트 안내 (0.5.18)
====================================================

[ 고친 점 / 바뀐 점 ]
----------------------------------------------------

● 스킬 처리 기본 엔진이 Python으로 바뀌었어요  ★
   - 채팅으로 스킬을 만들 때 기본 처리 방식을 Python으로 전환해 정확도·안정성을 높였습니다.
     (같은 작업이 엔진에 따라 결과가 갈리던 경우가 있었는데, 더 안정적인 쪽을 기본으로 삼았습니다.)
   - 매칭·집계·피벗·대량 행 삭제처럼 무거운 작업은 자동으로 안정적인 방식(VBA)으로 처리되니 걱정 없습니다.
   - 예전에 직접 엔진을 VBA로 골라 두신 분은 그 설정이 그대로 유지되며, 언제든 엔진을 바꿀 수 있습니다.

● '열을 옮기고 원래 열은 비우기'가 정확해졌어요
   - "○○ 열을 △△로 옮기고 원래 열은 비워줘" 요청에서, 예전에는 원래 열을 통째로 '삭제'해 뒤 열들이
     밀리며 값·라벨이 어긋나고 합계 수식이 깨지던(#REF!) 경우가 있었습니다.
   - 이제 원래 열은 '내용만 비우고'(열은 그대로 두어) 다른 열과 수식이 밀리지 않도록 바로잡았습니다.
   - 제목/헤더가 병합된 표에서도 "병합된 셀에서는 실행할 수 없습니다" 오류 없이 안전하게 처리됩니다
     (상단 제목의 가로 병합은 자동으로 피하고, 헤더의 세로 병합은 함께 옮깁니다).

● 열 복사/맞바꿈도 더 정확·안전해졌어요
   - "값으로/원문 그대로 복사": 옮긴 셀의 수식이 엉뚱한 곳을 가리키게 어긋나지 않고, 계산된 값 그대로 들어갑니다.
   - "한 열을 다른 열로 복사": 제목/헤더가 병합된 표에서도 오류 없이 서식째 복사됩니다(원본은 그대로 유지).
   - "두 열의 위치를 서로 맞바꿈": 합계·SUMIF 등 수식 참조가 #REF! 로 깨지지 않고 올바르게 보정됩니다.

● '데이터만 비우기'와 '합계 열 채우기'가 정확해졌어요
   - "○○ 열 데이터만 비워줘": 세로 방향으로 정확히 비워지고(수식은 남기고 값만 비우기도 가능), 다른 영역은 그대로 둡니다.
   - "합계 열에 D+E 합계 수식 채워줘": 계정이 2행씩 병합된 표에서 병합 그룹 단위 합계(=SUM(...)+SUM(...))로 채우고,
     제목·단위 같은 라벨 행은 덮어쓰지 않습니다.

● 시트 전체를 복사할 때 아래쪽 행이 빠지던 문제를 고쳤어요
   - 첫 열이 병합/빈칸이 많은 표를 "전체/사용 범위" 복사할 때, 표의 마지막 행을 실제보다 짧게 잡아
     하단 몇 행(합계·검산 등)이 빠지던 경우가 있었습니다. 이제 사용 범위 기준으로 끝까지 정확히 복사됩니다.

● 잘못될 소지가 있는 요청은 '표 구조'를 보고 한 번 되물어 확인해요
   - 예전에는 요청 문구의 단어로만 위험을 판단해, 표현이 조금만 달라도(합계/합/소계 총액/합을 구해 등)
     놓치는 경우가 있었습니다. 이제 요청 문구가 아니라 '실제 시트 구조'를 근거로 판단합니다.
   - 대상 시트에서 합계/총계/소계 행, 부가세 안내 행 같은 '특이 행'의 위치를 먼저 파악한 뒤, 요청의 뜻이
     그 범위를 합산·집계하는 것이면(표현과 무관) "표 안에 이미 있는 합계 행도 포함할까요, 각 항목 행까지만
     더할까요?"처럼 한 번만 되묻습니다. 그대로 포함하면 값이 두 배가 되는 실수를 막아줍니다.
   - 특이 행이 없는 평범한 표의 합산이나, 범위(F5:F19)·포함 여부를 이미 적어 주신 경우엔 묻지 않고 진행합니다.
   - "합계 행은 빼고" 라고 답하면 실제로 정확히 빠집니다. 예전에는 합계 행 라벨이 어느 칸(A열 등)에 있는지
     잘못 찾아 결국 열 전체를 더해 버리는 일이 있었는데, 이제 각 행의 왼쪽 라벨을 스캔해 '합계/총계/소계'
     행과 그 아래 꼬리(부가세·검산 등)를 정확히 제외하고 항목만 더합니다.

● 안전 검사에 막혔을 때 사용자가 손쓸 수 없이 멈추는 상황을 없앴어요
   - 큰 표를 통째로 읽어 가공하는 코드처럼 안전 검사에 걸리는 경우, 이제 자동으로 VBA 방식으로 다시
     만들어 시도합니다(이 계열은 다시 만들어도 Python 으론 잘 안 풀려서, 곧바로 VBA 로 전환).
   - VBA 로도 끝내 안 되면, 막다른 화면에서 "원본 Python 코드로 강제 적용" 버튼으로 한 번에 적용할 수
     있습니다(예전엔 에러 메시지만 뜨고 방법이 없었음).
   - 적용 실패 → '에러 복구'가 Python 으로 다시 짠 코드는 안전 검사를 거치지 않고 곧바로 적용됩니다.
     이 덕분에 VBA↔Python 을 오가며 계속 되돌아가던 무한 반복이 사라졌습니다.

● 가입번호(키) 기준 '병합된 셀 블록 전체'를 서식 그대로 붙여넣기가 정확해졌어요
   - 가입번호처럼 한 값이 여러 행 병합 블록을 이루는 표에서, 예전에는 매칭이 블록의 '첫 행 한 줄'만
     가져와 소계 등 나머지 행이 빠지고 각 블록이 한 행으로 줄어드는 경우가 있었습니다.
   - 이제 소스의 같은 키 블록 '전체(모든 행)'를 값·서식·병합 그대로 대상 블록에 복사합니다. 셀 단위
     루프가 아니라 키 단위 블록 복사라 큰 표에서도 빠르고, 멈추지 않습니다.
   - 소스와 대상의 블록 높이가 다르거나 소스에 없는 가입번호는 아래 블록을 침범하지 않도록 건너뛰고
     '건너뛴 목록'으로 알려 드립니다(그 건만 확인하시면 됩니다).

● 저장한 스킬을 '다른 달' 파일에 그대로 재사용해도 파일/시트를 알아서 찾아요
   - 예: 4월 파일 기준으로 저장한 스킬을 5월 파일에 실행할 때, 파일명·시트명이 월/날짜만 다르면
     (예: "…03. 관악_03월" → "…05. 관악_05월") 자동으로 그 파일/시트에 맞춰 실행됩니다(VBA·Python 공통).
   - 안전장치: '명확히 하나'만 맞을 때만 자동 연결합니다. 후보가 여럿이라 어느 파일인지 모호하면 자동
     연결하지 않아요(엉뚱한 파일에 쓰는 사고 방지). 공백/언더바/괄호 차이는 기존처럼 그대로 매칭됩니다.

● 전용 기능(복사·정렬·피벗·필터·합계 등)으로 처리되는 작업은 불필요하게 VBA로 안 바뀌어요
   - 이런 전용 기능으로 만든 코드는, 요청에 '삭제/중복' 같은 단어가 섞여 있어도(예: "중복이라고
     지우지 마") VBA로 전환하지 않고 그대로 실행합니다. 예전엔 이런 단어 때문에 멀쩡한 작업이
     'VBA로 변환해 다시 생성'되곤 했습니다.
   - "~하지 마"처럼 삭제를 '하지 말라'는 요청을 삭제 작업으로 오해하던 문제도 함께 고쳤습니다.

● 스킬을 저장했다 불러오면 일부 단계 이름이 '스킬 생성'으로 뭉뚱그려지던 문제를 고쳤어요
   - 파이프라인 카드 이름은 제목이 없을 때 '요청 문구'로 대신 표시하는데, 저장 파일에 그 요청 문구가
     빠져 있어 불러오면 일부 단계가 '스킬 생성'으로만 남았습니다.
   - 이제 각 단계의 요청 문구를 함께 저장·복원해, 불러온 뒤에도 만들 때와 같은 이름으로 보입니다
     (에러 복구 시 원래 요청 맥락도 함께 살아나 더 정확해집니다).

● 실행기 화면에서 '생성기로 이동' 버튼을 정리했어요
   - 실행기 하단의 '🧩 생성기로 이동' 버튼을 제거했습니다(결과 편집하기 등 다른 흐름은 그대로).

● 스킬 단계 '수정(✎)'을 누르면 그 단계를 만든 요청으로 채팅이 이동해요
   - 여러 단계 중 특정 단계 수정을 시작하면, 그 단계를 '어떻게 요청했는지' 채팅 말풍선으로 자동
     스크롤되고 잠깐 노랗게 강조됩니다 — 어디를 고치는지 바로 확인하고 이어서 수정 요청을 입력하면 됩니다.

● 저장된 스킬을 불러올 때 채팅이 깔끔해졌어요 (사용자가 친 것만 표시)
   - 예전에는 불러온 대화에 내부용 문구([정확 참조] 블록, "Step X 실행 중 오류…", 실패한 코드/상세 오류/
     스택, 재생성 프롬프트 등)가 그대로 보여 지저분했습니다.
   - 이제 이런 자동 생성 문구는 화면 말풍선에서 감추고 '사용자가 실제로 입력한 요청'만 보여줍니다
     (동작에 쓰이는 내부 프롬프트는 그대로 유지 — 표시만 정리).

● 까다로운 표(병합 헤더·조건 2개 이상·한 셀 다중 가입번호)에서 실패하던 스킬을 고쳤어요
   - 병합/2행 헤더: "K열(국제)"처럼 열을 직접 지정했는데 이름을 못 찾아 오류 나던 문제를 고쳤습니다.
     헤더를 지정 행에서 못 찾으면 인접 행까지 자동으로 찾고, 열 문자를 주면 그대로 씁니다.
   - 조건 2개 이상 합산: "A열이 X이고 B열이 Y인 행의 C열 합계"를 큰 표에서도 멈춤 없이 처리합니다
     (필요한 열만 좁게 읽어 계산).
   - 한 셀에 가입번호가 여러 개(줄바꿈/공백 구분)여도 각각 분리해 매칭·합산합니다. 예전엔 전체
     문자열로만 맞춰 '매칭 0건'이 나던 케이스가 이제 정상 처리됩니다.

● "○○ 파일의 △△ 시트를 복사해줘" 요청을 거부하던 문제를 고쳤어요
   - 업로드해 둔 파일을 이름으로 가리켜 복사(특히 다른 시트로 붙여넣기)를 시켰을 때, 파일이 분명히
     열려 있는데도 가끔 "그 파일이 없습니다 / 업로드해 주세요"라며 작업을 거부하던 문제가 있었습니다.
   - 이제 현재 열려 있는(업로드된) 파일이면 바로 그 파일을 대상으로 복사·작업을 수행합니다.
