AX-Cell — 업데이트 안내 (0.8.2)
====================================================

이 문서는 0.8.1 이후에 바뀐 내용을 정리한 안내입니다.
이전 내용은 같은 폴더의 v0.8.1.txt 를 봐 주세요.
이번 판은 녹화(F10) 기능 실사용 제보 4건을 중심으로 한 안정화 판입니다.


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 스킬을 적용할 때 엑셀 창이 잠깐 내려갔다 올라오던 깜빡임이 없어졌습니다.

2) 녹화로 만든 단계의 켜고/끄기(on/off)가 빨라졌습니다.
   끌 때 스킬 전체를 처음부터 다시 돌리지 않고, 그 단계 하나만 되돌립니다.

3) 단계를 켰는데 "적용됨"인데 엑셀에는 안 보이던 문제를 고쳤습니다.
   이제 단계를 켜면 그 단계가 고친 파일로 화면이 따라갑니다.

4) 전체실행 중 녹화 단계가 실패해도, 고친 뒤 다시 실행하면
   앞 단계를 건너뛰고 이어서 도는 것을 실제 Excel 로 검증했습니다.


────────────────────────────────────────────────────
[ 스킬 적용 시 창 깜빡임 제거 ]
────────────────────────────────────────────────────

● 증상
   - 스킬을 추가하거나 적용할 때마다 오른쪽 엑셀 창이 잠깐 내려갔다
     다시 올라왔습니다. (VBA 방식으로 적용될 때)

● 원인
   - 일부 PC 의 오피스가 "창이 보이는 상태"에서는 매크로 실행을 거부하는
     경우가 있어, 이를 피하려고 매번 창을 숨기고 실행했기 때문입니다.
   - 그런데 거부하는 PC 는 일부인데, 모든 PC 에서 항상 숨기고 있었습니다.

● 이렇게 바뀝니다
   - 창을 그대로 둔 채 실행합니다. 화면이 흔들리지 않습니다.
   - 매크로를 거부하는 PC 에서만 자동으로 예전 방식(숨기고 실행)으로
     전환됩니다. 그런 PC 는 종전과 완전히 동일하게 동작합니다.

● 함께 고친 것들 (같은 뿌리의 문제)
   - 적용 순간 'VBA 편집기' 창이 몰래 포커스를 가져가 프로그램이 뒤로
     밀려 보이던 현상 → 포커스를 원래 창으로 되돌립니다.
   - CSV 파일에 적용할 때 빈 워크북 창이 잠깐 뜨던 현상 제거.
   - 스킬(매크로)이 창 자체를 옮기거나 숨기는 드문 경우에만 제자리로
     되돌립니다. 안 움직였으면 창을 일절 건드리지 않습니다.
   - 예전에 문제가 됐던 회색 화면 / 탭이 다른 곳을 보는 현상은
     재발하지 않는 것을 실제 Excel 로 확인했습니다.


────────────────────────────────────────────────────
[ 녹화로 만든 단계 — 켜고/끄기가 빨라졌습니다 ]
────────────────────────────────────────────────────

● 증상 1: 끄면(OFF) 처음부터 전체실행
   - 녹화로 단계를 추가한 직후 스위치를 끄면, 스킬 전체를 처음부터
     다시 돌렸습니다(파일 여러 개면 수십 초~수 분).

● 이렇게 바뀝니다
   - 그 단계 하나만 되돌립니다. "그 단계를 적용하기 직전" 사본으로
     파일을 바꿔 끼우는 방식이라 몇 초면 끝납니다.
   - 다시 켜면(ON) 되돌린 화면 위에 그 단계 하나만 다시 적용합니다.
   - 켜고/끄기를 반복해도 계속 빠른 방식으로 동작합니다.
   - 다른 파일에 쓰는 녹화 단계라면, 관련된 파일들이 함께 되돌아갑니다.

● 증상 2: 켰는데 "적용됨"인데 엑셀에 안 보임
   - 실제로는 적용되어 있었습니다. 화면이 다른 파일을 보고 있어
     "적용 안 됨"으로 보였던 것입니다.

● 이렇게 바뀝니다
   - 단계를 켜면 그 단계가 고친 파일로 화면(탭 + 엑셀 창)이 자동으로
     이동하고, 어느 파일이 바뀌었는지 안내 문구로도 알려줍니다.
   - 이미 그 파일을 보고 있으면 화면을 흔들지 않습니다.


────────────────────────────────────────────────────
[ 전체실행 중 녹화 단계가 실패하면 — 동작 검증 ]
────────────────────────────────────────────────────

실행기에서 전체실행 중 녹화로 만든 단계가 오류를 내는 상황을
실제 Excel 로 검증했습니다. 확인된 동작:

   - 몇 번째 단계가 왜 실패했는지, 일반 단계와 같은 형식으로
     알려줍니다(원인 + 요청 문구 가이드).
   - 실패한 단계만 고쳐 다시 실행하면, 앞 단계(녹화 단계 포함)는
     건너뛰고 이어서 돕니다.
   - 건너뛴 단계의 결과는 그대로 보존됩니다.
     다른 파일에 써 둔 값까지 포함해서입니다.
   - 안 고치고 다시 실행해도 앞 구간을 다시 돌지 않습니다.


────────────────────────────────────────────────────
[ 내부 개선 ]
────────────────────────────────────────────────────

● 녹화 진단 강화
   - 녹화 시작~정지 사이의 전 과정(수확 단계별 개수 포함)이 로그에
     남습니다. "캡처 0건" 같은 문제가 생기면 어디서 사라졌는지 바로
     짚을 수 있습니다.

● 검증 자동화 보강
   - 녹화 단계 수명주기(수정 / 켜고끄기 / 전체실행 / 파일 교차·시트명·
     파일명) 실측 테스트 추가.
   - 창 동작(깜빡임 / 포커스 / 회색화면 / 탭 어긋남) 실측 테스트 추가.
   - 죽어 있던 회귀 검사 5건(녹화 취소 복원)을 수리해 다시 살렸습니다.

● 명세 문서(OKF) 최신화
   - docs/okf 자동 명세를 0.8.2 코드 기준으로 재생성했습니다.
     (문서 2,302개, 코드와 일치 확인)
