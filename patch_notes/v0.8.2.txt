AX-Cell — 업데이트 안내 (0.8.2 통합본)
====================================================

이 문서는 0.7.4 이후 0.8.2 까지 바뀐 내용을 한 번에 정리한 안내입니다.
(0.7.5 / 0.8.0 / 0.8.1 / 0.8.2 의 내용을 합쳤습니다)


────────────────────────────────────────────────────
[ 핵심 요약 ]
────────────────────────────────────────────────────

1) 화면 색이 회사 규정에 맞춰 바뀌었습니다(검정·회색 중심). 기능은 그대로이며,
   상단 [테마] 버튼으로 예전 디자인으로 되돌릴 수 있습니다.

2) 전체실행이 중간에서 실패해도, 고친 뒤 다시 누르면 처음부터 다시 돌지 않고
   저장해 둔 지점부터 이어서 갑니다. (실측: 16분 → 30초)

3) 같은 가입번호인데 "없다"고 나오던 문제를 고쳤습니다.
   중복 확인, 두 열 대조, 값 가져오기(VLOOKUP), 조건 합계가 모두 해당됩니다.

4) 스킬을 적용할 때 엑셀 창이 잠깐 내려갔다 올라오던 깜빡임이 없어졌습니다.

5) 녹화(F10)로 만든 단계가 안정화됐습니다 — 켜고/끄기가 몇 초 만에 되고,
   단계를 켜면 그 단계가 고친 파일로 화면이 따라갑니다.

6) 보안문서(DRM)를 올리면 자동으로 풀어서 작업하고, 내려받을 때 원본과
   같은 등급으로 다시 걸어 줍니다. 보안 서버가 무응답일 때 파일마다
   오래 기다리던 것도 빠르게 넘어가도록 고쳤습니다.

7) "이거 있는지 확인해 줘" 처럼 묻는 요청은 AI 도움으로 바로 연결되어
   파일을 직접 열어 보고 답합니다.

8) 필터 결과를 이미 쓰고 있는 양식에 붙이는 기능이 생겼습니다.
   매달 행 수가 달라져도 같은 스킬을 그대로 쓸 수 있습니다.

9) 무인 실행을 위한 [E2E 작업 등록] 화면이 생겼습니다(스킬·주기 등록 관리).

10) [작업 중단]이 실제로 멈추고, 진행 상황이 한 곳에서 단계 수와 함께 보입니다.


────────────────────────────────────────────────────
[ 화면 ]
────────────────────────────────────────────────────

● 회사 규정 색으로 맞췄습니다
   - 분홍·보라 계열을 검정·회색 중심으로 바꿨습니다. 위치와 동작은 그대로입니다.
   - 좌측 상단 U+ 로고, 상태 색(주의=주황, 완료=초록, 오류=빨강)은 유지합니다.
   - 상단 [테마] 버튼으로 예전(0.7.4) 화면과 오갈 수 있고, 선택은 기억됩니다.

● 스킬을 적용할 때 엑셀 창이 내려갔다 올라오던 깜빡임 제거
   - 매번 창을 숨기고 실행하던 것을, 창을 그대로 둔 채 실행하도록 바꿨습니다.
   - 적용 순간 다른 창이 앞으로 나와 프로그램이 뒤로 밀려 보이던 것,
     CSV 파일 적용 때 빈 워크북 창이 잠깐 뜨던 것도 함께 고쳤습니다.
   - 일부 PC(매크로 실행이 까다로운 오피스)는 자동으로 예전 방식으로
     동작합니다 — 그 경우만 종전처럼 한 번 깜빡입니다.

● 메뉴 정리
   - 좌측 메뉴에 AX-Cell(스킬 생성기·실행기)만 보입니다.
     준비 중인 메뉴(AX-Trace, E2E 작업 등록)는 F6 키로 표시/숨김을 바꿉니다.
   - 좌측 상단에 로그인 계정이 표시됩니다.
   - 창이 좁을 때 제목·버튼이 세로로 쪼개지던 것을 고쳤습니다.

● 프로그램 아이콘이 새로워졌습니다
   - 흰 배경 테두리를 없애고 로고가 꽉 차게 다듬었습니다(창·작업표시줄).


────────────────────────────────────────────────────
[ 시간이 오래 걸리던 것들 ]
────────────────────────────────────────────────────

● 전체실행 이어실행  ★ 가장 큰 변화
   - 예전에는 30단계에서 실패해 그 단계를 고친 뒤 다시 실행하면 1단계부터
     전부 다시 돌았습니다(파일 6개·36단계 기준 16분).
   - 이제 실행 도중 중간중간 상태를 저장해 두고, 고친 단계 앞까지는 건너뜁니다.
     실측: 25단계 건너뛰고 11단계만 실행 → 30초 완료.
   - 화면에 "26/36 단계 실행 중..." 처럼 어디까지 왔는지 표시됩니다.
   - 실행기에서 [✓ 수정 적용]을 누르면 코드만 바뀌고, 반영은 [전체실행] 때
     이어서 됩니다(예전에는 묻지도 않고 전체가 다시 돌기 시작했습니다).
   - 설명(주석)만 고친 것은 이어실행을 깨뜨리지 않습니다.

● 스킬 적용 속도를 되돌렸습니다
   - 내부 검사가 셀마다 같은 준비 작업을 반복하던 것을 고쳐,
     실측 28배 빨라진 구간이 있습니다.
   - 오래 걸리는 작업이 3분쯤부터 멈춘 것처럼 보이던 문제도 고쳤습니다.

● 마지막 단계만 고치면 그 단계만 다시 적용됩니다
   - 결과 편집 후 마지막 단계 수정이 1단계부터 다시 돌던 것(실측 5분 5초)을
     직전 상태 복원 + 그 단계만 재적용으로 바꿨습니다. 몇 초면 끝납니다.

● "D열 전체 복사"가 가벼워졌습니다
   - 열 전체를 지정하면(엑셀 습관) 안 보이는 104만 행까지 다루느라
     한 단계가 몇 초씩 걸렸습니다. 이제 실행 시점의 실제 데이터 끝까지만
     복사합니다. 다음 달 행 수가 달라져도 그대로 동작합니다.

● 실행 전에 미리 막아 줍니다
   - 스킬의 열 이름이 실제 파일에 없으면 8분 돌린 뒤가 아니라 실행 전에
     알려 드리고, 같은 실수가 여러 단계에 있으면 모아서 안내합니다.


────────────────────────────────────────────────────
[ 결과가 틀리던 문제 ]  ★ 중요
────────────────────────────────────────────────────

● 같은 가입번호인데 "없다"고 나오던 문제
   - 엑셀은 같은 번호 512102403338 을 셀마다 숫자로도, 글자로도 저장합니다.
     눈으로는 똑같아 보여도 안에서는 다른 형태라, 프로그램이 다른 값으로
     판단했습니다. 오류도 안 나고 "없다"고만 나와 더 헷갈렸습니다.
   - 이제 두 형태를 같은 번호로 봅니다. 해당 기능: 중복 확인 · 두 열 대조 ·
     값 가져오기(VLOOKUP) · 조건에 맞는 값 합계.
   - 숫자 0이 든 칸과 빈 칸도 구분합니다(예전에는 "0인 행"에 빈 행이 딸려옴).

● "값이 0인 행을 삭제해줘" 같은 행 삭제
   - 시트를 새로 만들어 바꿔치기하는 방식(화면 깨짐·틀고정 소실)이 아니라
     엑셀의 행 삭제(Ctrl+-)와 같은 제자리 삭제로 만들어집니다.

● "Q열과 R열 사이에 열 추가"가 Q 앞에 들어가던 문제를 고쳤습니다.


────────────────────────────────────────────────────
[ 녹화(F10)로 만든 단계 ]
────────────────────────────────────────────────────

● 켜고/끄기(on/off)가 빨라졌습니다
   - 녹화로 추가한 단계를 끄면 스킬 전체를 처음부터 다시 돌렸습니다.
     이제 "그 단계 적용 직전" 사본으로 되돌리기만 합니다(몇 초).
   - 다시 켜면 그 위에 그 단계 하나만 적용합니다. 반복해도 계속 빠릅니다.
   - 다른 파일에 쓰는 녹화 단계라면 관련 파일들이 함께 되돌아갑니다.

● 켰는데 "적용됨"인데 엑셀에 안 보이던 문제
   - 실제로는 적용돼 있었고 화면이 다른 파일을 보고 있던 것이었습니다.
     이제 단계를 켜면 그 단계가 고친 파일로 화면(탭+엑셀 창)이 이동하고,
     어느 파일이 바뀌었는지 문구로도 알려 줍니다.

● 전체실행 중 녹화 단계가 실패하면
   - 몇 번째 단계가 왜 실패했는지 일반 단계와 같은 형식으로 알려 주고,
     고쳐서 다시 실행하면 앞 단계는 건너뛰고 이어서 돕니다.
   - 건너뛴 단계의 결과(다른 파일에 쓴 값 포함)는 그대로 보존됩니다.


────────────────────────────────────────────────────
[ 물어보면 답해 줍니다 ]
────────────────────────────────────────────────────

● "확인해 줘"는 AI 도움으로 연결됩니다
   - "C열과 V열에 같은 번호가 있는지 확인해 줘" 처럼 묻는 요청은 스킬을
     만드는 게 아니라 AI 도움으로 넘어가 파일을 직접 열어 보고 답합니다.
   - "삭제해 줘", "정렬해 줘" 처럼 파일을 바꾸는 요청은 종전대로 스킬을 만들고,
     잘못 넘어갔다면 [그래도 스킬로 만들기]를 누르시면 됩니다.

● AI 도움이 더 많은 것을 봅니다
   - 스킬 실행 밖의 문제(저장 실패, 화면 이상, 연결 문제)도 답할 수 있습니다.

● AI 서버 연결이 끊기면 예비 서버로 자동 전환합니다
   - 서버의 AI 모델이 교체되어도 자동으로 알아채고 맞춰 요청합니다.


────────────────────────────────────────────────────
[ 새로 생긴 기능 ]
────────────────────────────────────────────────────

● 필터 결과를 쓰던 양식에 바로 붙일 수 있습니다
   - 예전에는 필터 결과를 "새 시트"로만 뽑을 수 있었습니다.
   - 이제 조건으로 말씀하시면 실행할 때마다 해당 행을 다시 찾아
     기존 양식 자리에 채웁니다. 행이 늘든 줄든 같은 스킬 그대로입니다.
   - 이렇게 요청하세요:
       회선 현황에서 상태가 "정지"인 행을 대상양식 시트 A3부터 붙여 줘.
       붙이기 전에 그 자리 아래 지난달 값은 지워 줘.
   - 서식(음영·테두리·표시형식)도 함께 따라가고, 양식의 다른 열은 건드리지 않습니다.

● E2E 작업 등록 (무인 실행 준비)
   - 스킬(.zip)을 올리면 필요한 문서를 자동으로 찾아 보여 주고,
     문서마다 데이터 출처를 연결해 주기(매일/매주/매달/한 번만)·시각과 함께
     등록합니다. 등록한 작업은 [스킬 목록]에서 수정·삭제할 수 있습니다.
   - 이 메뉴는 준비 중 기능이라 기본 숨김이며 F6 으로 표시합니다.

● 스킬 명령 설명서
   - 프로그램이 엑셀 작업에 쓰는 명령 67가지를 정리한 문서입니다.
   - 위치: docs/user-guide/AX-Cell_스킬_함수_설명서_v0.8.0.txt

● [✎ 수정] 버튼이 마지막에 쓰신 문장을 기억합니다
   - 여러 번 고쳐도, 저장했다 불러와도 가장 최근 문장이 입력창에 채워지고
     채팅 기록의 그 말풍선으로 정확히 이동합니다.


────────────────────────────────────────────────────
[ 진행 상황과 중단 ]
────────────────────────────────────────────────────

● 알림이 한 곳에만 뜹니다
   - 화면 잠금 한 곳에 모으고, 몇 개까지 됐는지 함께 보여 줍니다.
       입력 파일 업로드 중... (3/6) · 청구내역.xlsx
       Excel 창 준비 중... (2/4)
   - 보안 해제가 함께 진행되면 같은 줄에 덧붙습니다.

● [작업 중단]이 실제로 멈춥니다
   - 누르면 "중단 요청됨 · 현재 단계 끝나면 멈춤"으로 바뀌고, 진행 중이던
     단계가 끝나는 대로 멈춥니다. 한 단계가 길면 조금 기다려야 하며,
     화면이 그 사실을 알려 드립니다.

● 실행 중에는 스킬을 수정할 수 없도록 막았습니다(상태 어긋남 방지).


────────────────────────────────────────────────────
[ 보안문서(DRM) 처리 ]
────────────────────────────────────────────────────

● 기본 동작
   - 보안이 걸린 엑셀을 올리면 자동으로 풀어서 작업하고(원본은 그대로,
     작업용 복사본만), 내려받을 때 다시 보안을 걸어 내보냅니다.
   - 보안을 다시 걸 수 없으면 보안 없는 파일이 나가지 않도록 다운로드를
     멈추고 알려 드립니다(안전한 쪽으로 동작).

● 원본과 같은 등급으로 되돌립니다
   - 올리실 때의 보안 등급을 기억해 두었다가 그대로 다시 겁니다.

● 비밀등급 문서를 가려냅니다
   - 비밀등급 문서는 해제를 시도하지 않고 그 사실을 알려 드립니다.
     등급을 낮춘 사본으로 다시 시도해 주세요.

● 보안 서버가 무응답일 때 오래 기다리지 않습니다
   - 서버가 답을 안 주는 유형의 장애는 제한시간을 꽉 채워야 실패가 떠서,
     파일을 여러 개 올리면 파일마다 그 시간을 반복했습니다.
   - 이제 한 번 무응답을 확인하면 잠시(30초) 보안 해제 시도를 쉬고
     다음 파일들은 원본 그대로 바로 진행합니다. 서버가 살아나면 자동 복귀합니다.

● 인식 범위와 안내
   - 표준 방식(AIP 등) 외 사내 보안 형식도 파일 내용으로 판별합니다.
     한글 CSV 를 보안문서로 오인하던 문제도 고쳤습니다.
   - 파일마다 지금 상태를 분명히 알려 드립니다:
       · 보안 문서를 해제해 열었습니다
       · 비밀등급 문서라 처리할 수 없습니다
       · 지금은 보안 서버에 연결할 수 없어 원본 그대로 열었습니다
       · 보안 문서가 아니어서 그대로 열었습니다


────────────────────────────────────────────────────
[ 관리자용 ]
────────────────────────────────────────────────────

● F9 관리 대시보드
   - 누가 언제 얼마나 사용했는지, 어떤 오류가 있었는지 기간별/사용자별로
     조회하고, 해당 실행의 로그와 스킬 파일을 바로 내려받을 수 있습니다.

● 로그·스킬 자동 수집
   - 작동 기록과 스킬 구성이 관리 서버에 자동으로 쌓여, 제보 시 파일을
     따로 보내지 않아도 원인을 확인할 수 있습니다.
   - 엑셀 표 데이터 자체를 올리는 것은 아닙니다.
